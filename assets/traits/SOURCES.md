# 백마법 특성 이미지 출처

## 게임 원본 명마 유효 아이콘

- 파일: `undead.png`
- 다운로드: https://yuphastemple.com/images/effective/undead.png
- 확인 페이지: https://yuphastemple.com/?item=seraphim
- 공개 표시 코드: https://yuphastemple.com/data/app.js 의 `getEffectiveList`·`effectiveCell`. 게임 설명의 Effective vs. undead를 해당 이미지로 표시한다.
- 일반 유효 표식이다. Effective+의 별도 그림과 섞지 않는다. 엔젤·스타라이트의 명마 효과에 사용한다.
- 게임 이미지 © Nintendo / INTELLIGENT SYSTEMS. SVG로 다시 그리거나 다른 작품의 몬스터 아이콘을 대신 쓰지 않았다.

## 일반 효과 분류

원거리 회복·이동·보호 같은 설명용 분류는 글자 태그로 표시한다. 원본이 확인되지 않은 그림을 게임 전용 아이콘처럼 표시하지 않는다. 실제 백마술 기능 그림은 기존 `assets/skills/white-magic.webp`를 사용한다.
