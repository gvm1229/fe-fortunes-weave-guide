# 2026-11-13 사용자 수정 실행 계획

정본: `docs/design-spec.md` §3·§7. §7의 우선순위를 따른다.

1. 로컬 초상화 이름·시대·크기와 공개 공식 자산을 확인하고 출처를 남긴다. 잘라 만든 문장 네 개를 삭제한다. 공식 문장이 확인되지 않는 루트에는 문장을 넣지 않는다.
2. 첫 화면 순서를 카이·디트리히·세오도라·레다로 바꾸고 진행 순서 배지를 넣는다. 1·2부의 모든 인물은 타임스킵 전 그림을 쓴다.
3. 파생 자료 생성 단계에서 문장 분리·설명 접기·금액 표·시대별 그림을 처리한다. 원문 문장 보존을 검증한다. 인물 표·얼굴 크기·고정 영역·원본 그림 보기를 구현한다.
4. 명세 색을 다시 생성하고 lint·typecheck·verify를 실행한다. 기존 localhost:3000에서 두 테마와 화면 크기를 검사하고 PNG·수치·증거 한계를 `docs/`에 저장한다.

제약: Git·커밋·빌드·`.next` 삭제·Hive·전역 지식 기록 금지. 모든 실행의 TEMP/TMP는 저장소 `.tmp` 사용. 이미지 편집·생성·합성 금지.

## 완료 결과

1~4번 완료. 한국닌텐도 공식 큰 그림 4개와 클랜 문장 4개를 원본 그대로 저장했다. 잘라 만든 문장과 UI 참조를 삭제했다.

Windows의 lint·typecheck·verify가 통과했다. 기존 개발 서버의 Chrome 검사 240장면·45개 동작과 추가 148장면이 통과했다. PNG는 `docs/screens/`, 출처·변경 파일·각 규격의 수치와 증거 한계는 `docs/corrections-report.md`에 기록했다. 남은 Agent 소유 작업과 질문은 없다. 금지된 명령·전역 지식 저장은 수행하지 않았다.

선물 표는 전체 61명·두 크기·두 테마에서 원본 목록과 별도로 대조했다. 대시보드 hero의 칸별 실제 크기도 두 테마에서 측정했다.
