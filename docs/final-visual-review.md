사용자가 이번 작업의 Claude 전용 역할 제한을 명시적으로 해제했다. Codex가 시각 검토·필요 수정·검증·커밋·푸시·Netlify 재배포를 수행한다. 이 예외는 원본 개인화 앱의 이전 작업에만 적용한다. 선호 정본 `notes/knowledge/guide-workflow.md`와 HANDOFF에도 같은 범위를 기록했다.

## 직접 본 화면과 판정

Windows Chrome에서 만든 실제 화면을 열어 비교했다. 자동 측정값만 보고 승인하지 않았다.

- 다섯 루트의 할 일·인물·준비·재료 화면을 1440×900과 375×812, 밝게·어둡게 각각 확인했다. 20개의 비교 그림 안에 80장면을 배치해 루트 색·본문 대비·표·얼굴 크기·고정 영역을 검토했다.
- 첫 화면의 군주 순서·진행 배지·1·2부 초상화·3부 띠를 확인했다.
- 팀의 편성·백마법·루트 편성·비교 문서와 모바일 문서 시트를 확인했다.
- 수정 후의 실제 인물 화면, 팀 참고 화면, 첫 화면을 다시 열어 확인했다. 세부 자동 결과는 아래 파일을 따른다.

## 발견하여 수정한 문제

| 문제 | 수정과 근거 |
|---|---|
| 접힌 인물 설명의 마지막 줄 일부가 잘림 | 목록 여백과 다른 높이의 글자가 고정 3줄 경계에 걸렸다. 실제 글자 줄의 경계를 읽어 3줄 이내 마지막 온전한 줄에서 접는다. 자세히는 원문 전체를 유지한다. §8 검사의 실패를 재현한 뒤 같은 검사로 수정 확인 |
| 준비 화면의 옛 연속 진행 안내 | 원본은 보존하고 현재 표시만 앞 루트에서 넘겨받은 실제 가호·게이지 확인으로 고친다. 네 1부 뒤 네 2부 진행이라는 최신 정본과 맞춘다 |
| 휴대폰 검색칸이 짧고 두 필터가 모두 전체로 보임 | 검색칸은 전체 폭, 필터 첫 항목은 모든 역할·모든 목적으로 구별 |
| 재료 표의 의미 없는 추가 안내 제목 | 다른 이름·사용 인물·지도 표기로 구별. 값은 변경하지 않음 |
| 좁은 첫 화면의 두 줄 배지가 그림 위를 침범 | 폭 1200px 미만에서 그림 위 여백을 64px로 조정. 배지 하단과 실제 그림 시작점을 사각형으로 대조 |
| 태블릿의 디트리히 얼굴이 왼쪽에서 잘림 | 원본 얼굴 위치에 맞춰 768~1199px에서 그림의 가로 기준점을 25%로 조정. 원본 전체 파일은 변경하지 않음 |
| 휴대폰 팀 마법표 제목이 한 글자씩 세로로 내려감 | 표·제목·머리글을 정상 표 배치로 유지. 등급·흑마술·백마술을 함께 비교할 수 있음 |
| 팀 비교 목차 버튼이 붙어서 보임 | 기존 8px 간격을 적용하고 원본 nav 의미도 보존 |
| Git의 자동 줄바꿈 변환이 원본 해시를 바꿈 | content와 assets의 자동 변환을 끄고 원본 바이트로 저장. 기존 자료 324파일의 줄바꿈만 바뀌었음을 따로 확인. 947개 원본 자료·미디어의 Git 저장 내용을 직접 대조 |

추가 시각 기준은 `docs/design-spec.md` §9에 기록했다. 사양이 요구하는 현재 행동 강조 띠는 디자인 검사기의 일반 경고에 따라 삭제하지 않았다. 강조 사라짐 시간도 기존 2초 유지·0.15초 전환을 유지한다.

## 검증 범위

실행 환경은 Codex / Windows / Node.js 24 / 설치된 Chrome다. Playwright는 별도의 브라우저 저장소를 사용했다. 사용자의 실제 체크·원본 체크 서버·archive는 변경하지 않았다.

- lint·타입 검사·원본 이전 검사·정적 빌드를 실제 실행했다. 자료 원문·체크 ID·그림 보존과 코드 형식을 검증하며 실제 게임 사실의 정확성을 증명하지는 않는다.
- `docs/browser-results.json`: 정적 빌드 240장면·45동작. 다섯 테마, 네 화면 크기와 밝게·어둡게, 저장 실패·가져오기·그림·겹침을 검사한다.
- `docs/corrections-browser-results.json`: 148장면. 1·2·3부 전 루트의 표·그림 시대·48px 얼굴 줄·가로 넘침을 검사한다.
- `docs/design-lead-browser-results.json`: 8장면·20동작. 인물 설명의 반쯤 잘린 줄, 현재 장 이동, 완료 구역, 강조·키보드 초점을 확인한다.
- `docs/feature-browser-results.json`: 복원 기능과 추가 화면 32검사. 마법표의 제목 폭·열 이름 검사도 추가했다.
- `docs/home-visual-results.json`: 첫 화면 10조합. 휴대폰·태블릿·노트북·데스크톱·4K의 두 테마에서 배지·그림 분리와 스크롤 없음을 확인한다.
- `docs/git-content-verification.json`: 원본 947파일과 Git에 저장된 바이트 일치를 확인한다. 원격 푸시는 별도로 확인한다.

위의 코드·원본·화면 검사는 모두 통과했다. macOS·Linux·Safari·Firefox와 실제 휴대폰에서는 실행하지 않았다. 휴대폰·태블릿 검사는 Windows Chrome의 화면 크기 재현이다. 최초의 잘린 줄 검사, Git 줄바꿈 대조, 태블릿 배지 검사는 실패했으며, 원인을 수정한 뒤 같은 조건으로 다시 통과했다. 실패를 통과 건수에 넣지 않았다.
