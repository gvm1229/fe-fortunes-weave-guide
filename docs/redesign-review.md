# B 기반 재설계 검토 · 2026-11-14

## 결과

B(Checklist Design)의 따뜻한 중립색 바탕, 흰 목록, 큰 글자와 항목 간 여백으로 내부 화면을 다시 구성했다. A에서 군주 배경 머리와 행동 묶음 접기를 가져왔고, C에서는 진행률별 색 변화만 사용했다. 학습 통계·메달·요금제는 추가하지 않았다.

첫 화면 네 군주의 원본 일러스트·공식 문장·색면·순서를 유지했다. 데스크톱 3부 링크는 144px 높이이고 그림·진행 막대·배경을 포함한 전체 영역으로 진입한다. 휴대폰은 최소 136px다. 휴대폰 첫 화면은 글자와 그림을 지키기 위해 세로 스크롤을 허용한다.

지원·유대의 분홍 하트, 명성의 파란 반짝임, 금색 동전, 물고기·광석·고기·선물 기호를 추가했다. 이 기호는 Lucide이며 게임 원본 그림을 새로 추출한 것은 아니다. 원본 무기 기능·병종·인물·지도·이벤트 자산은 유지하고 표시한다. 꼬치고기를 물고기로 구분하는 검사를 추가했다.

## 직접 본 화면

호스트: Codex, Windows, Chrome. 개발 화면과 별도 정적 빌드 모두 열어 보았다. 휴대폰은 Chrome의 390×844 화면 모의 검사이며 실제 휴대폰 하드웨어는 아니다.

- 데스크톱 1440×900 및 1440×1000: 네 오벨리스크 첫 화면, 3부 진입, 세오도라 할 일·군주 머리·목록·오른쪽 정보, 레다 군주 머리, 재료와 구매.
- 휴대폰 390×844: 첫 화면, 3부 할 일, 세오도라 할 일·묶음 제목·체크박스, 인물 검색·지원/명성 표시, 시험 안내, 물고기 지도와 원본 크기 보기.
- 밝게·어둡게: 세오도라 머리·할 일·인물 화면을 직접 비교했다. 다른 모든 루트의 모든 테마·장까지 전수 검토했다는 뜻은 아니다.
- 태블릿 768×1024: 카이·디트리히·레다·3부의 가로 넘침을 DOM으로 측정해 0을 확인했다. 이 측정은 각 화면의 미적 품질 전수 검토를 대신하지 않는다.
- 시각 검토 뒤 좁은 묶음 제목·초상화·완료 수 배치를 두 줄로 정리했다. 원본 그림 확대 창의 제목 높이와 닫기 버튼 겹침 방지도 보강했다.

이미지: `docs/screens/redesign/desktop.jpg`, `desktop-checklist.jpg`, `mobile-checklist.jpg`, `home-desktop.jpg`, `home-mobile.jpg`. 화면 파일은 저장소의 기존 무시 규칙에 따라 로컬에 보관한다.

## 원본 대조 기록 갱신

초기 전체 보존 검사는 앞 대화에서 사용자 선호 정본 `notes/knowledge/interface.md`에 추가한 결정 때문에 실패했다. 해당 파일만 `content/` 사본에 동기화하고 그 파일의 해시만 갱신했다. 다른 원본 해시를 일괄 승인하거나 검사를 건너뛰지 않았다. 파생 문서 재생성 후 전체 보존 검사가 통과했다. 실제 게임 체크·진행값은 변경하지 않았다.

## Modern Web Guidance 적용

공개 GoogleChrome/modern-web-guidance의 SKILL.md를 읽고 `accordion`, `responsive-design`, `css-layout`을 검색·조회했다. 저장소 전체 설치나 불필요한 의존성 추가는 하지 않았다.

- `accordion`: 기본 `details/summary`, 여러 묶음 동시 열기, 제목 가까이 펼침 표시. “Do not put headings inside summary”에 따라 새 접기 제목은 일반 텍스트이며 별도의 페이지 제목을 유지한다.
- `responsive-design`: 화면 폭별 재배치, `dvh`, 상하한이 있는 글자 크기. “DON'T use vw alone for font-size without clamp()”를 따른다.
- `css-layout`: 줄바꿈 가능한 탐색, `minmax(0,1fr)`, 목록 폭에 따른 `@container`. “Do NOT use overflow: hidden to mask layout issues”에 따라 가로 넘침을 숨기지 않고 측정했다. 군주 머리의 `overflow:clip`은 의도한 일러스트 영역에만 적용한다.

검토용 빌드: `.tmp/redesign-build/out`. 사용자 개발 서버를 종료하거나 체크 저장소를 시험 데이터로 덮어쓰지 않았다.
