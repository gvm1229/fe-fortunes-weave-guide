# 디자인 참고안 시각 검토 · 2026-11-13

범위: 현재 프로젝트. 사용자가 참고안을 선택하기 위한 조사이며 구현 결정은 아니다.

이전 추천은 소개 문구에 의존했다. 4번 Checklist Dashboard의 체크리스트 적합성 추천을 철회한다.

## 사용자 피드백

- 1번 Listables: 진행 막대만 참고.
- 2번 Learning Dashboard: 전체 진행은 잘 보이나 한 화면이 과밀함.
- 3번 E-Learning Student Dashboard: 단정하고 세련된 디자인과 진행 막대가 좋음. 학습 관련 요소 제외 시 후보.
- 4번 Checklist Dashboard: 디자인 불만족, 샘플에 실제 체크리스트 없음. 제외.
- 5번 Travel Itinerary: 날짜 목록과 날짜별 행동은 좋으나 나머지는 여행 중심.
- 6번 Achievr: 체크박스는 좋으나 메달·유료 요금제 등 불필요한 요소가 많음.
- 7번 Dark Souls Cheat Sheet: 단순함은 좋지만 그림이 없고 글자가 너무 작음.
- 소개·검색어만으로 추천하지 않고 실제 이미지를 직접 검토할 것.

## 직접 본 화면과 판단

실행: Codex / Windows / Chrome. Dribbble의 실제 렌더링 이미지와 Checklist Design 실제 페이지를 화면 캡처로 관찰했다. CSS 글자 크기 수치, 휴대폰 실기기 동작, 저장 기능, 접근성은 검사하지 않았다. 시안의 축소 이미지로 실제 글자 크기가 충분하다고 단정하지 않는다.

### 기존 3번

https://dribbble.com/shots/25129825-E-Learning-Student-Dashboard-Design

첫 화면 및 Course Progress Detail Page 확대 이미지 관찰. 상세 화면은 왼쪽 메뉴, 중앙 장별 접기 목록, 행별 진행 막대, 오른쪽 알림·개선사항·순위표로 구성된다. 단정한 정렬과 접힌 장 목록은 후보로 유지. 위 통계 여섯 개, 점수·출석·순위표는 우리 용도에 불필요하다. 목록 행에 수동 체크박스는 없다.

### 기존 5번과 6번

https://dribbble.com/shots/8499905-Travel-Itinerary

세 휴대폰 화면 관찰. 가운데 날짜별 행과 오른쪽 시간별 일정 블록을 확인했다. 날짜 목록만 부분 참고. 체크리스트 전체 화면 후보로는 부적합하다.

https://dribbble.com/shots/25135648-Achievr-Gamification-To-do-List-App

첫 이미지에 빈 사각 체크박스, 보라색 완료 체크, 완료 글자 취소선을 확인했다. 상단 메달·레벨·Pro Plan이 크게 차지한다. 체크 상태 표현만 참고한다.

### 새 후보 A: PackItEasy

https://dribbble.com/shots/21871960-Travel-Checklist-App

앞선 전체 시안 https://dribbble.com/shots/21845286-Travel-Checklist-App 도 확인한 뒤, 정면 목록을 보여 주는 위 상세 시안을 검토했다.

그림 바로 아래 전체 진행 막대, 묶음별 완료 수, 접힌 묶음·열린 묶음, 빈 사각 체크박스와 보라색 완료 행이 함께 보인다. 제목 아래 사진을 제외하면 중앙 구조는 범용 체크리스트에 가깝다. 그림·진행·체크를 함께 비교할 후보로 추천한다. 휴대폰 시안이며 짧은 준비물 이름 위주이므로 긴 공략 설명과 데스크톱 배치를 증명하지 않는다. 완료 행 전체의 강한 색과 옅은 미완료 경계도 그대로 채택하지 않는다.

### 새 후보 B: Checklist Design

https://dribbble.com/shots/14109651-Checklist-Design-Redesign

소개 그림 외 네 번째 상세 이미지에서 체크박스·제목·설명과 오른쪽 참고 자료를 확인했다. 연결된 현재 실제 사이트는 이전 시안과 다르다.

https://www.checklist.design/mobile/login

실제 페이지는 왼쪽의 넓은 체크 목록, 제목 아래 설명, 별도 색의 주의 문장, 상단 완료 개수, 오른쪽 관련 자료로 구성된다. 행동·조건·주의사항을 한 항목에서 나누는 방식만 추천한다. 본문 그림이 없으며 회색 보조 설명이 있어 전체 시각 기준으로는 부족하다.

## 상태

이 조사 당시에는 참고안 선택을 기다렸다. 이후 2026-11-13 사용자가 B를 기반으로 확정했다. A에서는 접히는 묶음·맨 위 중앙 체크리스트와 배경 이미지, C에서는 진행률별 색 변화만 채택했다. 현재 첫 화면의 네 오벨리스크 구성은 보존하며 3부 영역은 확대하고 전체를 누를 수 있게 한다. 최신 결정은 [디자인 정본](design-spec.md)의 첫 절에 반영했다. 앱·배포 변경은 아직 없다.
