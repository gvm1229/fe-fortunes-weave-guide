# 전체 설명·화면 검토 완료 · 2026-11-14

## 완료 범위

- 루트별 인물 61개 항목의 1·2·3부 설명 183개와 팀 후보 34명의 역할 설명을 정리했다. 같은 이름이라도 다른 루트에서 영입하는 이유는 별도로 썼다.
- 영입 이유, 합류 계획, 실제 출격 조건, 목표, 육성을 멈출 때를 구분한다. 계획을 실제 합류 사실로 쓰지 않는다. 오래된 레벨은 ‘기록 당시’라고 표시하고, 원문 수치를 바꾸지 않는다.
- 수집·전투 제외 인물과 이오·알렉산드라의 탈것 보존 예외를 유지했다. 원본 전체 기록은 접힌 상세에서 읽을 수 있다.
- 인물명 옆 초상화, 병종 그림과 분류 표식, 기능 아이콘, 표의 가로·세로 경계, 버튼 간격을 적용했다. 3부의 같은 이름 동료는 준비한 루트를 표시한다.
- 팀 인물 설명과 백마법을 옆 패널로 연다. 개별 마법의 수치와 효과는 접지 않고 보여 준다. 특효 아이콘을 사거리 옆에 배치하고 병종 패널의 중복 제목을 제거했다.

## 시각 검토

실행 환경은 **Codex / Windows / Chrome**이다. 데스크톱은 1440×1000, 휴대폰은 390×844 화면 모의 검사다. 실제 휴대폰 기기로 테스트했다는 뜻은 아니다.

첫 화면·팀 화면, 9개 루트/부의 할 일·인물·준비·재료와 구매·참고 문서, **47개 주 화면을 두 크기에서 직접 확인했다(94개 조합)**. 데스크톱 루트 화면은 어둡게, 휴대폰 루트 화면은 밝게 확인했다. 모든 테마×모든 화면×모든 크기 조합을 전수 검사한 것은 아니다. 인물·병종·마법 상세 패널과 체크리스트 본문도 별도로 확인했다. 참고 문서 328개의 모든 문단을 수동으로 훑었다는 뜻은 아니며 원문 보존·공통 표시 구조 검사는 별도로 수행했다.

발견해 수정한 문제:

1. 여러 문장으로 저장된 목표가 `[object Object]`로 표시됨 → 표시용 문장 묶음을 정상 해석하도록 수정하고 실제 표시 자료 183개로 검사.
2. 휴대폰 표 머리가 글자 중간에서 끊김 → 단어 단위 줄바꿈과 머리 칸 폭 수정.
3. 금액 `48,000G`가 여러 줄로 끊김 → 금액 칸 폭 확보 및 숫자 줄바꿈 방지.
4. 인물 문서 패널의 머리 칸이 지나치게 좁음 → 고정 표 배치와 칸 폭 적용.
5. 마법 패널에서 위력·명중이 ‘자세히’ 뒤로 숨음 → 개별 마법 효과는 전체 표시.
6. 원본 병종 버튼 안 그림과 자동 보충 그림이 중복됨 → 기존 그림을 보존하며 중복 보충을 제거.

화면 기록은 `docs/screens/final-review/`에 있다. 화면별 측정과 마지막 인물 표시 수는 `docs/final-browser-review.json`, 설명별 검토 자료는 `docs/character-copy-review.json`이다. 스크린샷은 기존 저장소 규칙에 따라 로컬에 보관한다.

## 미리보기

기존 **http://localhost:18763/** 주소를 새 `.tmp/complete-preview/out` 빌드로 교체했다. 개발 화면은 http://localhost:3000/ 이다. 사용자 원본 체크와 운영 도메인의 체크는 시험 데이터로 덮어쓰지 않았다.

## 적용한 지침

`modern-web-guidance`의 `responsive-table`을 검색·조회했다. “maintaining the relationship between data cells and their headers”를 기준으로 표 머리와 내용 칸의 연결을 유지하고, 작은 화면에서도 표 머리가 낱글자로 흩어지거나 금액이 잘리지 않게 수정했다.
