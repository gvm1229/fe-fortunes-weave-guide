# 디자인 사양 v2 (정본)

이 문서가 디자인의 정본이다. 구현자는 여기 적힌 값과 배치를 그대로 따른다. 적혀 있지 않은 시각 결정(색, 간격, 배치, 문구)은 새로 만들지 말고 보고서의 질문으로 남긴다.

## 0. 금지
- 장식용 문구 금지: "오늘의 여정을 이어가세요", "지나온 일은 기록하고…", "세오도라 1부의 공략", 루트 설명 문구("현재 전력을 지키며 다음 준비" 등). 화면 문구는 이름, 수치, 게임 조건, 행동만 쓴다.
- 테두리만 있는(outline) 버튼 금지. 모든 버튼은 채운 버튼이다. 아이콘 단독 버튼만 투명 배경을 허용하며, 이때도 hover/active에서 채움을 쓴다.
- 얇은 테두리 카드를 겹쳐 쌓는 구성 금지(상자 속 상자). 구역은 배경 면 색 차이로 나눈다. 1px 선은 표 행과 목록 구분에만 쓴다.
- 이미지 없는 공략 화면 금지. 인물·신·기능·병종·장소·지도·이벤트 그림을 원래 공략처럼 보여 준다(4절).
- 둥근 모서리는 8px(작은 것)·12px(면)만 쓴다. 알약(pill) 모양은 진행 칩에만 쓴다.

## 1. 색 (루트가 화면 전체를 칠한다)
primary는 배경과 큰 면을 차지한다. secondary는 두 번째 면, 보조 버튼, 표 머리에 쓴다. accent(금색)는 진행률, 체크 표시, 현재 장 표시, 중요한 수치에만 쓴다.

토큰: `--bg`(페이지), `--rail`(옆 메뉴·상단 띠: primary 단색), `--rail-fg`, `--surface`(내용 면), `--surface-2`(안쪽 면), `--primary`, `--primary-fg`, `--secondary`, `--secondary-fg`, `--secondary-soft`, `--accent`, `--accent-fg`, `--text`, `--muted`, `--line`.

## 2. 글자·간격
- Pretendard. 크기: 18(최소, 보조), 20(본문), 24(소제목), 30(장 제목), 40(첫 화면 이름). 굵기 400/600/700.
- 간격 단계: 4, 8, 12, 16, 24, 32, 48. 면 안쪽 여백 24(휴대폰 16), 목록 행 간격 12, 구역 간격 32.
- 한국어 띄어쓰기: "세오도라 1부", "레다 2부"처럼 쓴다. 숫자와 단위는 붙인다("185개", "Lv18").

## 4. 루트 화면 `/[루트]/[부]`
### 배치(데스크톱 ≥1200)
- 왼쪽 옆 메뉴(폭 264, 배경 rail 단색, 글자 rail-fg):
  - 위에 군주 얼굴 원형 72px과 이름
  - 그 아래 1부/2부 전환(채운 분할 버튼)
  - 메뉴: 할 일·인물·준비·재료와 구매·참고 문서. 선택된 메뉴는 accent 채움 + accent-fg
  - 맨 아래: 첫 화면·테마
- 가운데(최대 폭 820, 배경 bg): 할 일 목록
- 오른쪽 보조 칸(폭 360, surface-2), 위에서부터:
  - 현재 장 카드: 장, 게임 날짜, 이 장 완료 n/m
  - 이 장의 인물: 얼굴 48px 줄, 누르면 인물 시트
  - 이 장 골드 목표
  - 이 장의 재료: 지도 썸네일 120×80, 누르면 큰 지도 시트
- 768~1199: 오른쪽 보조 칸을 할 일 위 가로 띠로 접는다.
- 휴대폰: 위 띠 56(rail 색, 얼굴 32px·"세오도라 1부"·테마), 아래 탭 5개(rail 색, 선택은 accent).

### 할 일 머리(한 줄, 겹침 금지)
- 장 선택(채운 secondary 드롭다운), 진행 막대, 내보내기·가져오기(채운 secondary 작은 버튼)를 한 줄에 둔다. 휴대폰은 두 줄까지.
- "다음 할 일" 카드(surface, 왼쪽 accent 띠): 행동 문장, 그 안의 그림 포함, "이동" 버튼(채움 primary).
- sticky로 붙이지 않는다. 장 제목과 절대 겹치지 않는다.
- 저장 상태 문구는 실패일 때만 눈에 띄게(빨강 면) 보이고, 성공 시는 작은 체크 아이콘만 둔다.

### 장 구역
- 장 제목 줄(30, 굵게): "6장", 날짜 범위, n/m 칩, 접기 아이콘. 현재 장은 펼치고 나머지는 접는다.
- 장 머리 그림: 그 장에 events 그림이 있으면 16:9로 폭 꽉 차게, 최대 높이 220.
- 묶음(행동 그룹):
  - 제목(24)과 묶음의 인물 얼굴(28px, 한 번씩)을 둔다.
  - 행동 목록: 체크박스, 분류 칩(secondary-soft 바탕), 문장 순서다.
  - 문장 안의 인물 이름 앞 얼굴 22×26, 신·기능·병종·무기 아이콘 20px, 지도 버튼(채운 secondary 작은 버튼 + 지도 아이콘)을 둔다.
- 완료 행은 글자를 muted로, 배경을 surface-2로 바꾼다. 체크는 체크박스만 눌러서 바꾼다.

### 그림 복원 (필수)
- 원래 공략(`C:\Users\hojin\Documents\fe-fortunes-weave-guide-main\personalized-app\src\content.json`)의 행동·메모 HTML에는 그림이 들어 있다. 예를 들어 6장 하나에 초상화 51, 기능 63, 신 26, 병종 8, 안내/이벤트 그림 9개가 있다. 위치·재료 버튼도 있다. 새 화면은 이 그림과 버튼을 모두 보여 준다.
- 방법: 원래 HTML 조각을 안전하게 정리해(스크립트 제거) 렌더하거나, 같은 정보를 구조화해 컴포넌트로 그린다. 어떤 방법이든 묶음별 그림 수가 원래와 같아야 한다. 같은 묶음 안 같은 얼굴은 한 번만 쓴다.
- 확인 스크립트: 루트·부·장별로 원래 대비 그림 수와 위치 버튼 수를 비교해 `npm run verify`에 넣는다.

- 재료·구매: 재료마다 지도 썸네일과 "지도 보기"(채운 버튼)를 둔다.
