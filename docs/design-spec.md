# 디자인 사양 (정본)

이 문서가 디자인의 정본이다. 구현자는 여기 적힌 값과 배치를 그대로 따른다. 적혀 있지 않은 시각 결정(색, 간격, 배치, 문구)은 새로 만들지 말고 보고서의 질문으로 남긴다.

## 현재 승인된 디자인 방향 · 2026-11-13 사용자 선택

**이번 절이 아래의 이전 사양보다 우선한다.** 사용자는 현재 첫 화면의 네 군주 구성을 보존하고, 나머지 화면은 B를 기반으로 새로 구성하기로 했다. 아래 §0~§9는 이전 구현의 기록이며, 새 디자인과 충돌하는 시각값을 새 화면에 강제하지 않는다. 이 절은 참고안 선택의 확정이지 새로운 화면의 구현 완료 기록은 아니다.

### 현재 첫 화면에서 보존할 것과 바꿀 것

- 사용자 첨부 화면의 **네 군주 오벨리스크 일러스트와 공식 문장, 루트 주제색, 네 칸을 나란히 배치한 구성**을 보존한다. 게임 속 네 오벨리스크를 떠올리게 하는 것이 보존 목적이다.
- 순서는 기존 **카이 → 디트리히 → 세오도라 → 레다**를 유지한다. 실제 게임 진행 순서와 혼동하지 않는다.
- **3부 영역은 현재보다 크고 분명하게 보이게 한다.** 작은 ‘3부’ 버튼만 누르는 대신 그림·진행 막대·배경을 포함한 영역 전체를 눌러 3부로 이동하게 한다. 키보드로도 같은 영역을 선택해 이동할 수 있어야 한다.
- 첫 화면 외 기존 화면의 미감·배치는 승인된 보존 대상이 아니다. 현재 화면의 색과 상자 구성을 조금 다듬는 것으로 재설계를 대신하지 않는다.

### 이전 규칙과의 관계

- §1의 ‘루트 색으로 화면 전체를 칠한다’는 새 내부 화면의 강제 규칙에서 제외한다. 내부 화면은 B를 기반으로 하며, 루트 주제색과 그림은 사용자가 지정한 상단 구역에 활용할 수 있다. 첫 화면의 네 루트 색면은 보존한다.
- §1의 ‘진행 막대는 금색 고정’과 ‘진행 막대 초록색 금지’는 진행률별 색 변화 요구로 대체한다. 다만 실제 색과 색이 바뀌는 진행률은 아직 확정되지 않았다.
- §0·§2의 이전 버튼·모서리·간격 수치와 §4·§7의 기존 고정 열 배치를 B보다 우선하지 않는다. 새로운 반응형 배치의 상세값은 별도 설계 대상이다.
- §3의 ‘3부 띠 높이 96·얼굴 40px·작은 3부 버튼’은 확대 및 전체 영역 클릭 요구로 대체한다. 정확한 높이는 아직 확정하지 않았다.
- **최소 글자 18px, 읽을 수 있는 대비, 공략 그림·원문·기능·실제 체크 보존, 루트·부 분리, 이야기 반전 비노출, 두 테마 지원**은 계속 지킨다. 그림을 없애거나 글자를 줄여서 공간을 맞추지 않는다.
- 진행률은 색만으로 구별하지 않고 완료 수와 막대 길이도 함께 보여 준다. 접기는 내용 숨김이며 데이터 삭제나 체크 변경이 아니다.

### 구현 상세값 · 2026-11-14

사용자가 구현·시각 검토를 요청한 뒤 위 참고안에 맞춰 정한 구현값이다. 사용자가 개별 색상값까지 지정했다는 뜻은 아니다. 스타일은 `app/redesign.css`, 상태는 공유 `Progress`와 `GameText`에서 관리한다.

- 내부 화면: 밝은 바탕 `#F1EEDC`, 목록 `#FFFFFF`, 본문 `#292820`, 보조 `#676357`. 어두운 바탕 `#1C1C1A`, 목록 `#292926`, 본문 `#F3F1E8`, 보조 `#C2BEB2`. 첫 화면 네 색면은 기존 그대로다.
- 본문 20px, 보조 18px 이상, 목록 면 반경 24px. 목록 행 여백은 넓은 화면 24×28px, 좁은 목록 20px. 그림을 없애거나 글자를 줄여 공간을 맞추지 않는다.
- 내부 화면 상단에 첫 화면·현재 루트·1/2부 전환·테마를 놓고 그 아래 다섯 탐색 탭을 둔다. 휴대폰에서는 탭을 다섯 칸으로 맞춘다.
- 전체 폭 최대 1184px. 넓은 화면의 체크 목록은 최대 780px, 보조 정보는 최대 300px이며 간격은 40px. 1000px 이하에서는 한 열로 배치하고 보조 정보를 본문 뒤에서 볼 수 있다. 가로로 꽉 찬 왼쪽 고정 메뉴는 사용하지 않는다.
- 군주 배경 머리 높이 208px, 휴대폰 176px. 그 아래 흰 면에 완료 수·막대·백분율을 함께 놓는다. 체크 도구 줄만 스크롤 중 위에 유지한다. 기록 내보내기·가져오기는 ‘기록 관리’를 펼쳐 사용한다.
- 장과 행동 묶음은 각각 `details`로 접는다. 여러 묶음을 동시에 열 수 있고, ‘이동’·문서 내부 링크는 목표를 감싼 접기 영역을 모두 연다. 접기 제목에 가짜 체크박스를 넣지 않는다.
- 진행률: 0~49% `#B16A2F`, 50~99% `#4B78A2`, 100% `#27805D`. 어둡게는 각각 `#E6AC70`, `#8FB9E0`, `#7BC7A3`. 수치·길이를 함께 보여 주므로 색만 알아볼 필요가 없다.
- 지원·유대는 분홍 하트, 명성은 파란 반짝임, 골드는 금색 동전, 물고기는 물고기, 광석·옥강·뇌석은 보석 모양으로 표시한다. 기존 Lucide의 의미 있는 기호를 사용하며 게임에서 추출한 원본 아이템 그림이라고 부르지 않는다. 무기 기능·병종·초상화는 저장된 원본 자산을 사용한다. ‘라돈 꼬치고기’는 물고기로 분류한다.
- 첫 화면 3부 영역은 데스크톱 144px, 휴대폰 최소 136px로 키우고 전체를 단일 링크로 만든다. 넓은 화면의 네 오벨리스크는 같은 순서로 한 줄을 유지한다. 휴대폰은 두 열이며 그림·큰 글자를 위해 필요한 세로 스크롤을 허용한다. 이전의 휴대폰 스크롤 0 강제값보다 우선한다.
- 원본 이미지 확대 창의 제목은 줄어들지 않으며 닫기 버튼은 항상 앞에 놓는다. 동작 줄이기 설정에서는 이동·전환 효과를 줄인다.

## 이전 구현 사양 v2 · 아래 §0~§9

## 0. 금지
- 장식용 문구 금지: "오늘의 여정을 이어가세요", "지나온 일은 기록하고…", "세오도라 1부의 공략", 루트 설명 문구("현재 전력을 지키며 다음 준비" 등). 화면 문구는 이름, 수치, 게임 조건, 행동만 쓴다.
- 테두리만 있는(outline) 버튼 금지. 모든 버튼은 채운 버튼이다. 아이콘 단독 버튼만 투명 배경을 허용하며, 이때도 hover/active에서 채움을 쓴다.
- 얇은 테두리 카드를 겹쳐 쌓는 구성 금지(상자 속 상자). 구역은 배경 면 색 차이로 나눈다. 1px 선은 표 행과 목록 구분에만 쓴다.
- 이미지 없는 공략 화면 금지. 인물·신·기능·병종·장소·지도·이벤트 그림을 원래 공략처럼 보여 준다(4절).
- 둥근 모서리는 8px(작은 것)·12px(면)만 쓴다. 알약(pill) 모양은 진행 칩에만 쓴다.

## 3. 첫 화면 (대시보드) · 스크롤 없음
- 높이 100dvh 안에 모두 들어간다(1280×720 이상과 375×812에서 스크롤 0).
- 위 띠(높이 56): 왼쪽 "만자천홍 개인화 공략", 오른쪽 "최종 25명"(채운 버튼)·테마 전환(아이콘 버튼).
- 가운데: 네 루트 칸을 한 줄 4열(휴대폰은 2×2)로 둔다. 순서는 게임 오벨리스크 순서 **카이 → 디트리히 → 세오도라 → 레다**다.
- 각 초상화 위(왼쪽 위 모서리)에 진행 순서 배지를 단다. 채운 accent 배지, 글자 18 굵게. 문구는 "루트 진행 순서: 1st"처럼 쓴다. 이 공략의 진행 순서는 세오도라 1st, 레다 2nd, 디트리히 3rd, 카이 4th다.
- 초상화 규칙: 1·2부 화면과 대시보드의 루트 칸에는 **타임스킵 전** 초상화를 쓴다. 타임스킵 후(`assets/portraits/post-timeskip/`) 초상화는 3부 화면과 3부 띠에서만 쓴다. 1·2부의 인물 얼굴도 모두 타임스킵 전 초상화를 쓴다.

- 칸마다:

### 7.4 같은 구역 안 그림 크기 통일
크기 토큰은 다음 넷뿐이다. 한 구역(할 일 목록, 오른쪽 칸, 준비 탭, 인물 탭) 안의 얼굴과 신 초상화는 모두 같은 토큰을 쓴다. 신과 인물 사이에도 크기를 다르게 하지 않는다.

| 토큰 | 크기 | 쓰는 곳 |
|---|---|---|
| `--face-inline` | 28×28 | 할 일 목록 안: 묶음 머리, 문장 안, 신 아이콘 |
| `--face-list` | 48×48 | 오른쪽 보조 칸, 준비 탭의 신·인물 목록 |
| `--face-card` | 96×96 | 인물 탭 카드 머리 |
| hero | 정해진 칸 크기 | 대시보드 군주 그림만 |

- 준비 탭의 "1부 · 실전과 보충 육성" 인물 그림(지금 수백 px)은 `--face-list` 48 크기의 줄 목록으로 바꾼다. 이름은 얼굴 오른쪽에 같은 줄로 둔다.
- 얼굴은 원형이 아니라 8px 둥근 사각형이다. 원본 비율이 정사각이 아니면 정사각 틀 안에 얼굴 부위(위쪽 기준)를 맞춘다. 이 경우만 object-position: top을 허용한다.

### 7.5 그림은 절대 잘리지 않게

- 병종 이름 버튼과 분류 표식의 높이·안쪽 여백을 통일한다. 마법 버튼 사이에 8px 간격을 둔다.
- 백마법 버튼은 해당 마법의 옆 패널을 연다. 본문 아래로 이동하지 않는다. 사거리·특효 아이콘은 함께 묶고 마법별 경계를 둔다.

구현: 공통 GameText에 인물·병종 자산 연결, 인물 요약과 접힌 전체 기록, 병종 문서 그림, 백마법 패널, 공통 표·간격 적용. Windows Chrome에서 인물·병종·엔젤 패널을 직접 확인했다. 타입·lint·아이콘 검사를 통과했다. 이번 수정의 전체 문구 윤문·모든 화면 전수 검토·정적 미리보기 재빌드·운영 배포는 아직 완료하지 않았다.
