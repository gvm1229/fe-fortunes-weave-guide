- 1부 지원 대화 묶음: 제목 `1부 완료 전 · 12장 다시 끝내고 지원 대화 보기(필수)`, 칩 `마지막 회차`, 네 루트 모두 12장 끝쪽(완료·보상 묶음 앞).
- 2부: 칩 `지원 확인`, 글 `2부에는 만찬이 없다…`. 2부 네 범위에 만찬을 하라는 단계 0건(`만찬`은 그 한 줄뿐).
- 3부 2구간 순서: 기준판 선택 → 알렉산드라·이오 선택 → **재영입·만찬 반복** → 첫 문 편성 → 융합 직전 확인 → **융합**. 6행동 글이 계획과 같다.
- 절차는 사용자 말과 맞다: 12장 저장 → 12장 영입 → 주 1회 선물 → 마법 1회 → 고기 만찬 → 장 다시 하기, 마지막 뒤 12장을 다시 끝내고 여관, 2부는 여관만, 3부는 재영입 → 만찬 반복 → 여관 → 융합. 어긋나는 곳은 M3(5구간) 하나다.

**영입 가능성**
- 네 루트 명단(27·21·27·19)의 모든 인물에게 그 루트의 영입 단계나 자동 합류가 있다. 명단 = `final-roster.recruitByRoute`.
- 1·2부 한정 109쌍 모두 두 인물이 같은 루트 명단에 있다(무우–그자람은 미카엘라 포함). 볼 수 없는 것은 울턴드–센트리온, 토비아스–아나톨리아뿐이다.
- 새 묶음의 조건은 `recruitment-gates.json`과 같다: 레다 울턴드 명성8·지원3, 디트리히 밴디츠 명성7·지원2, 디트리히 카타냐 명성8·지원1, 카이 누조 명성6·지원2.
- 대표 루트: 밴디츠 → 디트리히(명성7·지원2), 자스민 → 세오도라(명성8·지원3·5,000G). 63명 유지.

**화면**
