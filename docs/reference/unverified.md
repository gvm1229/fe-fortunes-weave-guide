# 확인되지 않은 내용(원문 꼬리말)

할 일 글의 확인 꼬리말("원래 공략 한 곳에서만 확인됐다", "(단일 출처)", "Anna's Notebook 초안, 미검증", "확인되지 않았다")은 화면에서 한 낱말 "미확인"으로 줄였다(2026-11-27, lib/display.ts `verificationTail`). 자료의 원문은 그대로이며 아래가 그 문장 전부다.

| 파일 | 원문 |
|---|---|
| content/derived/checklist.json | 선더 소드 지참은 원래 공략 한 곳에서만 확인됐다. |
| content/derived/checklist.json | 12장 무렵 영입하면 선더 소드를 들고 온다고 한다(원래 공략 한 곳에서만 확인). |
| content/derived/checklist.json | 티아라·보나파르트 C는 세오도라·보나파르트 B 뒤(이 둘과 두 세오도라 B 조건은 Anna's Notebook 초안, 미검증). |
| content/derived/checklist.json | 기한(4~10장) 안에 명성 10으로 제스터–레다 C를 본 기록은 아직 확인되지 않았다. |
| content/derived/checklist.json | 누조는 12장 무렵 영입하면 선더 소드를 들고 온다고 한다(원래 공략 한 곳에서만 확인). |
| content/derived/checklist.json | 상점의 고정 해금 날짜는 확인되지 않았다. |
| content/derived/checklist.json | 놓친 1·2부 대화는 오벨리스크로 해당 장을 다시 해서 볼 수 있다는 자료가 있다(단일 출처). |
| content/display-overrides.json | 이 C가 실제로 열렸다는 확인은 아직 없다(출처 한 곳). |
