# 루트별 지원 대화 근거

"루트별 지원 대화" 문서의 순서 잠금 표 근거 열과 "## 근거" 절을 옮겼다(2026-11-27). 화면은 이 열·절을 그리지 않고, 파일 content/notes/support-pairs-by-route.md는 그대로다(검사 U36·U39가 읽음).

## 순서 잠금

이야기가 이어지는 대화는 앞 대화를 보기 전에 다른 대화를 보면 막힐 수 있다. 아래 쌍은 대부분 1·2부에만 열리는 단계라, 순서를 어기면 그 부 안에 못 보고 놓칠 수 있다. 이미 막혔다면 지금 부를 끝낸 뒤 앞 장을 다시 해서 순서대로 본다(Game8). 2026-11-15 출처를 다시 확인했다. 'Game8 확인'은 큰 비공식 공략 사이트에서 확인한 것, '공동체 자료'는 출처 표시 없는 플레이어 정리·경험담이라 미검증이다.

| 순서 | 루트 | 근거 |
|---|---|---|
| 라이선더·릴리안 C·B → 세오도라·릴리안 B | 세오도라 | 확인: Game8 지원 대화 공략의 권장 순서, Game8 지원 레벨 공략(다른 대화를 먼저 보면 라이선더·릴리안 B가 막힐 수 있음), Anna's Notebook(세오도라·릴리안 B를 보면 라이선더·릴리안 C·B를 볼 수 없음) |
| 라이선더·릴리안 C·B → 세오도라·라이선더 B | 세오도라 | 공동체 자료(초안, 미검증): Anna's Notebook(초안)은 세오도라·라이선더 B를 먼저 보면 라이선더·릴리안 C·B를 볼 수 없다고 함. 일본 플레이어 블로그는 라이선더·릴리안 B가 실제로 막혔고, 원인이 두 세오도라 B 중 하나라고 검색으로 알게 됐다고 함. 세오도라·라이선더 B 자체는 막히지 않는다(막히는 쪽은 라이선더·릴리안) |
| 티아라·피터르 B → 피터르·울턴드 B → 티아라·피터르 A → 티아라·울턴드 B | 카이 | 확인: Game8 지원 대화 공략의 순서 ②. 티아라·울턴드 B는 티아라·피터르 B와 A 사이(둘이 다투는 동안) 막힌다(Anna's Notebook 초안) |
| 또는 티아라·울턴드 B → 티아라·피터르 B → 피터르·울턴드 B | 카이 | 확인: Game8 지원 대화 공략의 순서 ①(티아라·울턴드 B를 맨 먼저 본 경우) |
| 세오도라·릴리안 B와 세오도라·라이선더 B를 모두 본 뒤 → 라이선더·릴리안 A | 세오도라 | 공동체 자료(초안, 미검증): Anna's Notebook(초안) |
| 세오도라·보나파르트 B → 티아라·보나파르트 C | 세오도라 | 초안 1곳, 상충 있음: Anna's Notebook(초안)이 C만 이 조건이라고 함(B·A는 조건 없음). Serenes Forest 글에 티아라·보나파르트 C가 막혔다는 보고가 있다는 검색 결과 요약만 확인(본문은 열리지 않음, 이유도 없음). Fextralife는 조건 없이 A만 적음. Game8·GameWith·AppMedia·KeenGamer·RPG Site에는 없음 |
| 보나파르트·릴리안 C → 세오도라·릴리안 B → 보나파르트·릴리안 A | 세오도라 | 공동체 자료(초안, 미검증): Anna's Notebook(초안). C·B·A 모두 1부 한정. 아래 세오도라 표에 있다. 세오도라 1부 순서 잠금 체크에 넣었다 |
| 미카엘라와 무우의 마을 대화 → 미카엘라·무우 C | 디트리히 | 공동체 자료(초안, 미검증): Anna's Notebook(초안). 아래 표의 '마을 대화 뒤'와 같다 |
