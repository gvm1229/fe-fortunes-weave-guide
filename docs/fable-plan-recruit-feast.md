# 전원 영입 필수 · 1부 식사 반복 필수 — 실행 계획 (Fable, 2026-11-14)

대상: 조정자(Claude Opus). 이 문서는 계획만 담는다. 코드·자료는 아직 바꾸지 않았다. 커밋하지 않았다.

사용자 지시(사실로 취급):

1. 모든 인물 영입은 선택이 아니라 필수다. 체크리스트가 그것을 가능하게 해야 한다.
2. 1부를 끝내기 전에 식사 반복(마법 1회 소모 → 식당에서 마법을 회복하지 않는 고기로 식사 → 영입한 동료 전원 지원 상승 → 고기가 떨어지면 장 다시 하기 → 반복)을 반드시 한다. 2부에는 식사가 없으므로 1·2부 한정 대화의 지원 단계도 1부에서 올린다.

표기: **[확인]** = 저장소에서 직접 확인. **[미확인]** = 확인하지 못함. **Q n** = 사용자 질문(맨 아래).

### 0.2 M4 절차(새 ID)

새 ID는 **행동 22개 + 묶음 4개 = 26개**다(§B.2, §A.2).

1. `content/data/playbook.json` `groups`에 묶음/행동 추가. 행동 꼴: `{"id","category","text","inheritLegacy":false}`. 새 묶음 꼴은 `support-talks-cai-part1-20261112`를 복사(`people:[]`, `figures:[]`, `notes`, `curated:true`, `referenceLinks`, `route`).
2. `content/source/react-content.json`
   - 새 묶음: 해당 `stages[].blocks`에 `{id, html, title}` 삽입. HTML은 `support-talks-theodora-part1-20261112` 블록을 본뜬다: `<section class="action-group" data-group-id="ID" data-guide-phase="1" data-guide-route="ROUTE" id="ID"><div class="group-heading"><h3>제목</h3><div class="group-tools"><span class="group-count" data-group-count="ID">—</span></div></div><ol class="action-list">…</ol>(참고 버튼 2개 그대로)</section>`
   - 행동 한 줄: `<li class="action-item" data-done="false"><input aria-label="글" data-inherit-legacy="false" data-parent-task="묶음ID" data-task-id="행동ID" disabled="" id="행동ID" type="checkbox"/><div class="action-label"><span class="action-category">분류</span><span class="action-text">글</span></div></li>`
   - 기존 묶음에 행동 추가(카타냐·누조): 그 블록의 `</ol>` 앞에 위 `<li>`를 넣는다.
   - `allTaskIds`에 새 ID 26개 추가.
3. `content/check-ids.json`에 같은 26개 추가.
4. `content/action-links.json`에 `"ID": "/루트/1/#ID"` 26개 추가(기존 꼴과 같음).
5. `content/data/action-migration.json`은 건드리지 않는다(최근 묶음도 없음 [확인]).
6. 수치: `scripts/verify.mjs` 1858→**1880**, 2817→**2843**(21·22·54행). `content/transfer-manifest.json` `activeActions` 1880, `checkIds` 2843, `oldBlockCounts` 세오도라 181→182·레다 177→178·디트리히 198→199·카이 170→171.
7. `npm run derive:checklist` → `node scripts/refresh-manifest.mjs` → `npm run verify`.
8. 장 배치 검사(직접): 파생 전후로 "장 제목 → 묶음 ID 목록"을 비교한다. 새 묶음 4개가 `12장`에 들어가고, 카이 `support-talks-cai-part1-20261112`만 11장→12장으로 옮겨지고(§B.3), 다른 묶음은 움직이지 않아야 한다.

## B. 1부 식사 반복(필수)

### B.1 설계

- 지원은 **그 시점에 영입돼 있는 동료끼리만** 오른다. 장 다시 하기는 지원만 남기고 그 장의 골드·아이템·명성·영입·진행을 장 시작으로 되돌린다(`support-follow-along.md` [확인]).
- 그래서 두 단계로 나눈다.
  - **1차(대량)**: 12장 자유행동이 열린 직후. 아무것도 하기 전에 저장 → 반복. 11장까지 영입한 전원이 대상.
  - **2차(보충)**: 12장 영입·외전을 끝낸 뒤. 12장에 합류한 인물의 쌍만 모자라면 한 번 더. 장 다시 하기를 하면 12장 영입부터 다시 한다.
- 대화는 **마지막 장 다시 하기 뒤**에 본다(본 기록이 장 다시 하기 뒤에도 남는지 [미확인] → Q5).
- 목표 단계: `content/notes/support-pairs-by-route.md`의 루트 표에서, 그 쌍의 줄에 `1부`·`1·2부`·`2부`로 적힌 **가장 높은 단계**. 2부에는 식사가 없으니 `1·2부`·`2부` 단계도 1부에서 올린다. C·B·A에 필요한 지원 수치는 자료에 없다 [미확인] → 게임 화면의 지원 목록으로 확인.
