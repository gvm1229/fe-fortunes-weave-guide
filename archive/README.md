# 파이어 엠블렘 만자천홍 — 하드/클래식 육성 공략

진행 순서 **세오도라 1부 → 레다 1부 → 디트리히 1부 → 레다 2부 → 디트리히 2부 → 세오도라 2부 스킵 → 3부** 기준의 하드/클래식 캐릭터 육성 공략집.
앞 루트의 해금 병종·구세의 축복·가호 레벨을 이어받는 것을 전제로 루트별 로스터·성장률·합류 시점·병종 경로를 정리했다.
국내·해외 커뮤니티 자료를 3중 검증(독립 조사 → 팩트체크 → 교차 검증)하고 모든 추천에 신뢰도 배지를 붙였다.
