# 개인화 팀 구성 통합 · 2026-11-04

## 결과와 범위

- `personalized-team.html`은 최종 편성·육성 완료 목표를 보는 페이지다. 개인화 진행표는 실제로 따라 할 과정이다.
- 바탕은 기존3부 후보 비교다. 세 기본안과 아스완/트로이아 선택 교체를 유지한다. 기존 팀 비교에서는 루트별1·2부 편성, 변경 이유, 선호 점수, 확보37명 계산, 예비·추가 영입, 병종·춤·보존 주의와 근거를 붙였다.
- 현재안·부담 적은 추천은 미카엘라, 네 진영장 포함안은 베르트랑이 **배틀 마스터→도끼술 S→디 이터널**을 목표로 한다. 두 명을 동시에 같은 신장직에 두지 않는다. 3부4구간·심판의 천칭·시험100% 조건을 함께 표시한다.
- 핵심 백마술은 무기·마법 종류 아래에 금색 별·마법명·습득 목표 등급을 붙였다. 기능 등급은 학습 조건이며 현재 병종에서 사용할 수 없으면 ‘병종 변경 시·현재 사용 불가’를 함께 표시한다. 아직 배웠다고 추정하지 않는다.
- 최신 지양 대상은10명: 양계·키로이카·밴디츠·마지데·골라이어스·자코네·대도·자스민·센트리온·타호니아. 일반 본대·전투 예비에서 제외한다. 자스민의 기존 확보 정보는 수집 선택이며 센트리온·타호니아의 조건도 전투 육성 지시와 구별한다.
- 현재안 외의 후기 편성을 실제 진행표에 적용한 것은 아니다. 실제 게임·체크 완료는 변경하지 않았다.

## 화면과 연결

- Pretendard, 기존 공략의 메뉴·색·실제 초상화·병과/무기/기능 아이콘을 사용한다.
- 머리글을 고정하고 본문·메뉴만 독립 스크롤한다. 각 영역의 위/아래 이동, 메뉴의 눈 버튼과 오른쪽 위 표시 버튼, 현재 메뉴 강조를 제공한다.
- 병과 이름은 화면 중앙의 상세 모달을 열며 닫으면 본문·메뉴 위치와 버튼 초점을 유지한다. 원문 Markdown을 직접 연결하지 않는다.
- 공략19개 메뉴의 개인화 바로 아래에 새 페이지를 연결했다. `tools/workspace_ui.py`에도 메뉴 생성을 추가해 진행표 재생성 시 유지한다.
- 생성은 `tools/build_personalized_team.py`, 루트별 보조 내용은 `data/team-reference-sections.json`, 백마술 표시는 `data/team-white-highlights.json`이다. 옛 두HTML을 입력으로 요구하지 않는다.

## 최종 추가 배치와 백마법 효과

- 이전1:1 요청을 최신6:4 요청이 대체한다. 본문은 왼쪽60%·오른쪽40% 두 열이고, 넓은 화면의 최종25인은3열이다. 왼쪽은 선택한 최종25인 카드만, 오른쪽은 모든 비교·준비·근거·백마법 효과다. 메뉴·왼쪽·오른쪽은 독립 스크롤한다.
- 금색 별은 무기 종류 아래에 있다. 이름을 누르면 오른쪽의 해당 효과로 이동하며 왼쪽 위치는 유지한다. 현재 병종에서 못 쓰는 마법도 그 조건을 명시한다.
- 백마법21종의 기본 사거리·효과·특성·출처를 `data/team-white-spells.json`에 정리했다. 공개Game8 각 개별 페이지의 본문 표를 읽었다. 회복 위력은 현재 회복량과 다르고 병과·개인 스킬의 사거리/횟수 보정을 별도로 안내한다.
- Game8 워프의 레스큐 문구 혼재·라이브 표의 기병특효 오류는 그대로 쓰지 않는다. 워프의 대상1·주위5칸 이동은 로컬 `units.html`을 따른다. 레스큐는2~10칸 아군을 옆으로 회수한다. Resquia는[별도 팬 도감 원문](https://yuphastemple.com/?item=resquia)에서도2~3칸 아군을 옆으로 회수하는 것으로 확인했다.
- 이머지스는 필살 회피+30이며 물 위 이동 마법이 아니다. M실드는 다음 자기 페이즈까지 마방+10, Barrier는 다음 한 전투 피해 반감으로 구별한다.
- 엔젤·스타라이트는 명마(Undead) 특효 아이콘과 라벨을 함께 표시한다. 명마 표시는 공개 사이트에서 내려받은 게임 원본PNG다. 원본이 확인되지 않은 일반 효과 분류는 글자 태그로 표시한다. 출처·구분은 `assets/traits/SOURCES.md`에 있다.
- 시로코의 사용자 제공 흑/백마술 학습표를 오른쪽에5등급 표로 표시했다. 실제 달성한 기능으로 기록하지 않았다.
- 새 화면에서도1440·760·390 너비에서 좌우 실측576/576·362/362·183/183px, 바깥 스크롤0·두 열 가로 넘침0을 확인했다. 모달 전후 메뉴·왼쪽·오른쪽 위치가 같고 화면 중앙에 배치된다.


## 최신6:4·여성판·게임 원본 특성 아이콘

- 앞의1:1 실측은 이전 요청의 검증 이력이다. 최종 화면은6:4이며 넓은 화면 명단은3열이다. 좁은 화면은 글자 크기를 유지하며 명단 열 수를 줄인다.
- 이스마르는 Fire Emblem Wiki가 Fortune’s Weave 기본 Type B로 분류한 여성판 게임 초상화를 내려받아 팀 화면에 적용했다. 팀 화면의 여성 인원도 이 표시 선택을 반영한다. 실제 게임 변경·선택 완료를 추정하지 않았다.
- YuphasTemple 공개 표시 코드의 `effectiveCell`에서 `images/effective/undead.png`가 Effective vs. undead에 쓰이는 경로임을 확인했다. 해당 원본을 내려받아 엔젤·스타라이트에 적용했다. 직접 그렸던 명마SVG를 삭제했다.
- 출처: `assets/traits/manifest.json`·`assets/traits/SOURCES.md`·`assets/portraits/SOURCES.md`. 다른 작품 아이콘을 만자천홍 원본이라고 쓰지 않았다.


## 1920×1080 최종 카드 검토

- 표시 영역1920×1080에서 메뉴를 보인 상태의 좌우 폭은979.2/652.8px(6:4), 명단은3열303.5px, 얼굴은96×114px다.
- 역할 최소 높이를0으로 바꾸고 모든 카드의 역할·최종 병과·경유 목표·무기 경계를 선으로 구분했다. 카드 자체 높이는 내용에 맞게 표시한다.
- 여성판 이스마르와 실제 게임 명마 아이콘을 확인했다. 마법 이름 이동과 중앙 모달의 메뉴/양쪽 읽던 위치 보존을 유지했다.
-1920·1440·760·390폭에서 바깥 스크롤과 내용 가로 넘침을 점검했다. 작은 화면에서는 읽기 쉬운 크기를 지키며 명단을2열/1열로 줄인다.

최종 브라우저 표시와1920×1080 스크린샷을 저장하고 인앱 브라우저의 완성 페이지를 열었다. 검증 결과는 최신 `notes/team-page-merge-validation.json`·`notes/team-page-browser-validation.json`에 기록했다. 실제 체크 정본은 유지하며 별도 진행표 본문/내용 갱신은 되돌리지 않았다.
