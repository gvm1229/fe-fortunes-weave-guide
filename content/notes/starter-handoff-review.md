# 시작 동료·지원 대기열·투자 한도 검토

## 결정

- 실제 합류한 인물만 센다. 시작·자동 동료는 대체자가 역할을 맡기 전까지 사용한다.
- 실제 출격 정원을 본대가 채우면 교체된 인물의 추가 막타·유료 훈련·시험·전용 강화는 중단한다. 루트 고유 동료도 예외가 아니다.
- 현재 자격·능력·영입·대화 기록은 보관한다. 다음 부에서 실제 출격시킬 때만 보유·지급 증서부터 써서 육성을 재개한다.
- 1부 기본9명·세오도라/레다12장10명,2부13명·세오도라14명은 로컬 계획값이다. 실제 출격 준비창의 정원·강제 출격·게스트가 우선이며 모든 전투를 실측한 정원표는 아니다.

## 세오도라

1장 첫 턴은 세오도라 단독,2턴째 토비아스·보나파르트가 합류한다.3장 끝의 릴리안·라이선더는4장부터 사용한다. 라이선더는 초반 기동 전열이며 리네·알렉산드라가 역할을 맡고 본대9명이 실제로 모인 뒤 교체한다. 그 전까지 미래 동료의 자리를 빈칸으로 남기지 않는다.

라이선더를 벤치로 보낸 뒤 바딩거·창B를 의무로 준비하지 않는다. 초반 경기병도 실제 필요할 때만 선택한다. 토비아스·보나파르트는 현재 기본9명에 포함되지만 실제로 빠졌다면 고유 동료라는 이유로 계속 투자하지 않는다.2부 스킵·보존만 한다면14명 전원 전직을 하지 않는다.

## 레다

시작4명에 버커니어를 포함한다. 레다·무우·시로코의 공격 경험치와 함께 버커니어의 물리 벽·안전한 약한 적 정리를 명시했다. 회복은3장 전투 뒤 합류한 올림피아부터다. 에스메랄다가 전열을 맡고 본대가 정원을 채우면 버커니어 육성을 멈춘다. 늦게 영입하면 그 전까지 현재 전력을 계속 사용한다.

버커니어의 헤비 아머·상급 증서를 기본 목표에서 뺐다.8장 마지막 날7/9까지 장비를 옮기는 별도 행동은 본문에 유지하고, 이야기 이유는 빨간 스포일러 버튼 안에만 새로 적었다. 피아나·하르빈은1부에 빈칸이 없으면 멈췄다가2부에서 실제 출격할 때 재개한다.

## 디트리히

1장 디트리히·파비오,2장 에스메랄다,4장 미카엘라로 합류 시점을 바로잡았다.4장 영입 이오는5장 레버·초반 기동에 사용한다. 기동 본대가 합류하고 정원이 차면 경기병·전용 말을 보존하며 육성을 멈춘다. 소피아는 명성9 이후이므로 초반 회복 담당으로 세지 않는다.

울턴드는 명성5·지원3의 선택 보완판을 추가했다. 카이의 흑마법 성장과 달리 HP·힘·수비를 노리되, 본대 지원·영입금·시험비와 공격 칸이 남았을 때만 선택한다. 실제 가입 자격을 유지하고 검B·Lv35·명성8·시험100%가 자연스럽게 준비됐을 때만 워리어로 전환한다. 하급 시험·마스터·유료 반복 훈련은 요구하지 않는다. 본대9명이 차면 중단하며2부의 기본11명+이야기2칸을 넘겨 자동으로 육성을 계속하지 않는다. 워리어는 마법을 못 쓴다.

## 카이

카이·티아라·피터르는 시작부터 사용한다. 그자람·미카엘라·울턴드를 실제 합류 전에 경험치 대상으로 쓰지 않는다. 녹투라·누조는 부족한 공격 칸을 채우는 동안만 사용하고 본대9명이 모이면 추가 투자 중단.2부13칸에서 실제 출격할 때만 확대한다.

## 명단과 영입 행동

인물 명단 밖의 선택 영입7묶음을 활성 체크에서 제외하고 기존ID는 이력에 보관했다. 레다 울턴드, 세 루트 피터르, 세오도라 울턴드, 디트리히/카이 시로코다. 디트리히 울턴드는 인물 명단·기능·부별 목표와 함께 선택 행동을 유지한다. 수집·외전·적 인물·훈련 담당자 이름은 영입 추천으로 오인해 삭제하지 않는다.

스카우트 지원2 이상 계획 영입34건은 루트별 지원 대기열에 표시한다. **세오도라는5장 군비증강 안내 뒤 선물·스카우트가 열린 다음부터** 준비한다. 다른 루트의 첫 다그시온 기준을 세오도라4장에 적용하지 않는다. 등장 전에는 대기하고 현재 로드와의 지원을 본대→보완→선택→수집 순으로 준비한다. 이미 지원을 채웠으면 넘기며 선택 영입은 선택했을 때만 진행한다. 모든 사람에게 매주 선물을 주거나 동시에 식사하라는 일정이 아니다. [개방 시점 근거](theodora-ch5-review.md).

## 최종25명의 추가 성장판 검토

전원×네 루트100조합을 `data/optional-growth-review.json`에 기록했다. 기존 계획판·영입 불가·추가 보류를 구분했다. 새 선택은 디트리히 울턴드1판이다. 세오도라 울턴드는 리네·단테와 명성6·지원3 준비가 겹치고 기본9명이 차므로 기본에서 추가하지 않는다. 레다 울턴드는 명성8로 더 늦다. 카이 하르빈은 명성5이지만 피터르·그자람·미카엘라의 활 성장칸과 겹치며 레다에서 이미 최종판을 키우므로 반복 육성을 추가하지 않는다. 새로운 판은 무조건 더 강해지는 보장이 아니라 실제 부족한 기본치가 있을 때 비교할 선택 자료다.

## 출처와 한계

- [세오도라 로컬 원문](../theodora.html):1~4장 합류·5명 활용·출격9/10명.
- [레다 로컬 원문](../leda.html):초반 역할·올림피아 합류·8장 마지막 날 장비 이전·9장 상태 변화.
- [디트리히 로컬 원문](../dietrich.html):1/2/4장 합류·5장 기동·명성별 영입.
- [카이 로컬 원문](../kai.html):시작3명·그자람3장·미카엘라5장·울턴드3~6장 표기. 현재 개인화는6장 확인을 따르며 실제 합류가 빠르면 그때부터 사용 가능하다.
- [2부 로컬 원문](../part2.html):로드 측 출격 정원·레벨 올리기·증서.
- 상세 영입 요구는 현재 `data/recruitment-build-audit.json`, `data/recruitment-gates.json`과 [로컬 인물 도감](../characters.html)을 따른다. 원문의 오래된 추천 인물 전체를 사용자 본대로 복사하지 않는다.

이번 변경은 공략·자료 표시의 검증이다. 게임v1.1.0을 직접 실행해 합류 레벨·모든 전투 정원·보완판의 성장 결과·자원 소비를 실측한 것은 아니다. 실제 체크·게임 상태·최종25명 명단은 바꾸지 않는다.

작업 중 외부에서 실제 체크와 경험치 참고 기록이 갱신됐다. 이 작업은 체크 JSON을 쓰지 않았고 외부 갱신을 되돌리지 않았다. 따라서 현재 체크가 작업 시작 시점과 동일하다는 주장은 하지 않는다. 관찰한 범위는 starter-handoff-external-observation.json에 분리했다. 임시 저장소 검사는 실제 진행 파일과 분리해 새54개ID의 저장·해제·다시 읽기만 확인했다.
