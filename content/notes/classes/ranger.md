## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv35 |
| 명성 | 명성 8 |
| 필수 기능 · 모두 | 별도 필수 기능 없음 |
| 선택 기능 · 하나 | 궁술 B 또는 검술 B |
| 시험 증표 | 상급 시험 증표 |

**추가 해금:** 명성 Lv.10에서 도전장 「도전자 모집! 필멸의 오우코」 클리어 · 흥행 「신상품을 만들어 선보이고 싶다 4」 클리어

해금이 이미 공유돼 있으면 같은 해금 의뢰를 반복하지 않습니다.

권장 레벨은 응시 하한이 아닙니다. 실제 시험창의 조건과 합격률 100%를 확인하고, 이미 합격한 자격은 다시 시험 보지 않습니다.
