**상급직**

## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv35 |
| 명성 | 별도 명성 조건 표기 없음. 아래 해금 조건 확인. |
| 필수 기능 · 모두 | 기마술 D |
| 선택 기능 · 하나 | 백마술 B 또는 흑마술 B |
| 시험 증표 | 상급 시험 증표 |

**추가 해금:** 명성 Lv.10에서 백발귀의 의뢰 클리어 · 흥행 「신상품을 만들어 선보이고 싶다 4」 클리어

해금이 이미 공유돼 있으면 같은 해금 의뢰를 반복하지 않습니다.

권장 레벨은 응시 하한이 아닙니다. 실제 시험창의 조건과 합격률 100%를 확인하고, 이미 합격한 자격은 다시 시험 보지 않습니다.
