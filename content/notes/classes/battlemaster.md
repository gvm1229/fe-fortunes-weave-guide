# 배틀 마스터

**최상급직**

## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv45 |
| 명성 | 별도 명성 조건 표기 없음. 아래 해금 조건 확인. |
| 필수 기능 · 모두 | 별도 필수 기능 없음 |
| 선택 기능 · 하나 | 격투술 A 또는 도끼술 A 또는 검술 A |
| 시험 증표 | 최상급 시험 증표 |

**추가 해금:** 구세편 1구간 클리어

해금이 이미 공유돼 있으면 같은 해금 의뢰를 반복하지 않습니다.

권장 레벨은 응시 하한이 아닙니다. 실제 시험창의 조건과 합격률 100%를 확인하고, 이미 합격한 자격은 다시 시험 보지 않습니다.

## 병과 스킬

| 스킬 | 효과 |
|---|---|
| 전투 기술 장비 +2 | 장비 가능한 전투 기술 수 +2. |
| 도끼 명중 +7 | 도끼 장비 시 명중 +7. |
| 격투 명중 +7 | 건틀릿 장비 시 명중 +7. |

**자료 차이:** 전투 기술 장비 수: 로컬은 +2, Game8은 +3. 이 문서는 로컬 수치를 쓰며 실제 병과 화면의 수치를 확인해야 합니다.
