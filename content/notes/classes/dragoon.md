| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv35 |
| 명성 | 별도 명성 조건 표기 없음. 아래 해금 조건 확인. |
| 필수 기능 · 모두 | 비행술 C |
| 선택 기능 · 하나 | 도끼술 B 또는 창술 B |

**추가 해금:** 명성 Lv.8에서 아우로라의 의뢰 클리어 이 조건은 카이편 경로다. 세오도라편은 11장까지 군비증강 전부 달성 으로 열리고, 해금은 뒤 루트로 이월된다

해금이 이미 공유돼 있으면 같은 해금 의뢰를 반복하지 않습니다.

권장 레벨은 응시 하한이 아닙니다. 실제 시험창의 조건과 합격률 100%를 확인하고, 이미 합격한 자격은 다시 시험 보지 않습니다.
