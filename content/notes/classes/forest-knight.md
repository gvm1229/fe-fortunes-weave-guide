| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv35 |
| 명성 | 명성 8 |
| 필수 기능 · 모두 | 기마술 D, 궁술 B |
| 선택 기능 · 하나 | 선택 조건 없음 |
| 시험 증표 | 상급 시험 증표 |
