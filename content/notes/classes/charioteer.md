# 전차병

**중급직**

## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv20 |
| 명성 | 명성 4 |
| 필수 기능 · 모두 | 기마술 D, 궁술 C |
| 선택 기능 · 하나 | 선택 조건 없음 |
| 시험 증표 | 중급 시험 증표 |

권장 레벨은 응시 하한이 아닙니다. 실제 시험창의 조건과 합격률 100%를 확인하고, 이미 합격한 자격은 다시 시험 보지 않습니다.

## 병과 스킬

| 스킬 | 효과 |
|---|---|
| 전차의 장갑 | 방어력 +5. 공격을 회피할 수 없습니다. |
| 전차병의 전술 | 타기·내리기를 사용합니다. 기병 탑승 중에는 돌진도 사용합니다. |
| 전차병의 길 | 자신의 레벨이 높아질수록 성장률도 높아집니다. |
