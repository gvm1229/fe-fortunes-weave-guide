# 더 갓 핸드

**신장직**

## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 명성 | 별도 명성 조건 표기 없음. 아래 해금 조건 확인. |
| 필수 기능 · 모두 | 백마술 C, 격투술 S |
| 선택 기능 · 하나 | 선택 조건 없음 |
| 전용 아이템 | 대제의 복대 |

**추가 해금:** 구세편 4구간 시작 시 해금 (천관의 신전에서 「대제의 복대」 입수 시 전직 가능)

해금이 이미 공유돼 있으면 같은 해금 의뢰를 반복하지 않습니다.

신장직은 전용 아이템으로 전직하며, 같은 병종은 동시에 한 명만 사용할 수 있습니다.

## 병과 스킬

| 스킬 | 효과 |
|---|---|
| 전투 기술 장비 +3 | 장비 가능한 전투 기술 수 +3. |
| 격투 회피 +10 | 건틀릿 장비 시 회피 +10. |
| White-Magic Zenith | 백마술 사용 횟수가 3배가 됩니다. |
