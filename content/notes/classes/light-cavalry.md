# 경기병

**중급직**

## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv20 |
| 명성 | 명성 4 |
| 필수 기능 · 모두 | 기마술 D |
| 선택 기능 · 하나 | 검술 C 또는 창술 C |
| 시험 증표 | 중급 시험 증표 |

권장 레벨은 응시 하한이 아닙니다. 실제 시험창의 조건과 합격률 100%를 확인하고, 이미 합격한 자격은 다시 시험 보지 않습니다.

## 병과 스킬

| 스킬 | 효과 |
|---|---|
| 타기 내리기 | 타기·내리기 명령을 사용할 수 있습니다. |

## 마스터 보상

해당 병과의 숙련도를 채워 마스터하면 아래 보상을 배웁니다.

| 보상 | 효과 |
|---|---|
| 체력의 강화 | 최대 HP +3. |

## 근거

시험 조건·해금·한글 이름은 로컬 병종 도감을, 효과는 [Game8 병과 원문](https://game8.co/games/Fire-Emblem-Fortunes-Weave/archives/624045)을 대조했습니다. 로컬에 한글 이름이 없는 보상은 원문 이름을 유지합니다.
