# 중갑 보병

**중급직**

## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv20 |
| 명성 | 명성 4 |
| 필수 기능 · 모두 | 중장술 E+ |
| 선택 기능 · 하나 | 창술 C 또는 도끼술 C |
| 시험 증표 | 중급 시험 증표 |

권장 레벨은 응시 하한이 아닙니다. 실제 시험창의 조건과 합격률 100%를 확인하고, 이미 합격한 자격은 다시 시험 보지 않습니다.

## 병과 스킬

| 스킬 | 효과 |
|---|---|
| 후공 수비 +3 | 적이 먼저 공격하면 해당 전투 동안 물리 방어 +3. |
| 전투 기술 장비 +1 | 장비 가능한 전투 기술 수 +1. |

## 마스터 보상
