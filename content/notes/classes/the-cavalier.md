# 더 캐벌리어

**신장직**

## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 명성 | 별도 명성 조건 표기 없음. 아래 해금 조건 확인. |
| 필수 기능 · 모두 | 기마술 A |
| 선택 기능 · 하나 | 도끼술 S 또는 창술 S 또는 검술 S |
| 전용 아이템 | 신철의 안장 |

**추가 해금:** 구세편 4구간 시작 시 해금 (천관의 신전에서 「신철의 안장」 입수 시 전직 가능)

해금이 이미 공유돼 있으면 같은 해금 의뢰를 반복하지 않습니다.

신장직은 전용 아이템으로 전직하며, 같은 병종은 동시에 한 명만 사용할 수 있습니다.

## 병과 스킬

| 스킬 | 효과 |
|---|---|
| 타기 내리기 | 타기·내리기 명령을 사용할 수 있습니다. |
| 전투 기술 장비 +3 | 장비 가능한 전투 기술 수 +3. |
| Golden Ride | 자신에게 적용되는 기병 특효를 무효화합니다. |

## 마스터 보상

해당 병과의 숙련도를 채워 마스터하면 아래 보상을 배웁니다.

| 보상 | 효과 |
|---|---|
| Divine Dexterity | 기술 +10. |
