# 사냥병

**초급직**

## 시험·전직 조건

| 항목 | 필요 조건 |
|---|---|
| 권장 레벨 | Lv5 |
| 명성 | 명성 1 |
| 필수 기능 · 모두 | 별도 필수 기능 없음 |
| 선택 기능 · 하나 | 검술 D 또는 궁술 D |
| 시험 증표 | 초급 시험 증표 |

권장 레벨은 응시 하한이 아닙니다. 실제 시험창의 조건과 합격률 100%를 확인하고, 이미 합격한 자격은 다시 시험 보지 않습니다.

## 병과 스킬

전용 병과 스킬은 없습니다. 아래의 마스터 보상은 따로 배웁니다.

해당 병과의 숙련도를 채워 마스터하면 아래 보상을 배웁니다.

|---|---|
