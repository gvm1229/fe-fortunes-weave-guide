## 최신 공략 보완 · 영입 수주·성장 기준·공격형 봉사 · 2026-11-04

전원62명·물품18종의 선확보/수주 전용을 대조해 전용 의뢰의 수주→수집→보고를 분리했다. 네 루트48장에 시험 권장 레벨과19/34 점검선을 넣었다. 크레르1→칼라3→크레르3→주라3→마스3→스미르노스3으로 주간 봉사·루트별 누적 목표를 작성하고 시작 축복은10개3,200·잔액4,205 계획으로 조정했다. [영입 근거](notes/recruitment-gates-review.md), [성장 기준](notes/level-renown-review.md), [가호 일정](notes/god-service-review.md).

현재 실제 보고는 디트리히1부12장 완료·2부 첫 전투 전, 다른 루트 미플레이·아우로라3·주라2·그 외0·파편7,405·구매0 그대로다. 미래 목표를 달성했다고 기록하지 않았다. 새 체크는 기존 완료를 자동 상속하지 않는다.

## 공략 교정 · 시로코 비문 수주 · 2026-11-04

사본은 전용 의뢰 진행 중에만 입수한다. 명성·지원→본인 스카우트→수주·진행 확인→원정→납품 보고 순서로 고쳤다. 공통 완료 보상으로 사본을 대신한다는 가정은 폐기했다. [근거](notes/poet-copy-review.md). 현재 실제 디트리히1부12장 완료·2부 첫 전투 전과 나머지 미플레이, 게임 자원·영입·체크 정본은 유지한다.

## 공략 표시 · 공통 준비·인물 탭 · 2026-11-04

오른쪽 상자 하나에서 공통 준비/인물 탭을 전환한다. 선택 강조·탭별 읽던 위치·검색 유지·초상화 이동·눈 버튼 연결을 보완했다. [표시 기준](notes/context-tabs-review.md). 실제 디트리히1부12장 완료·2부 첫 전투 전과 나머지 미플레이 상태, 게임 자원·정본 체크는 유지한다.

## 공략 표시 · 상자별 눈 버튼 · 2026-11-04

메뉴·할 일·공통 준비·인물 머리글과 오른쪽 위에서 표시를 바꾼다. 기존 버튼과 상태를 함께 갱신하고 숨겼다가 다시 열면 읽던 위치를 복원한다. [표시 검토](notes/panel-visibility-review.md). 실제 게임 진행·구매·영입·정본 체크 기록은 변경하지 않았다.

## 공략 표시 · 모달 루트·부 분리 · 2026-11-04

무기37종·영입 물품·지원·구매·육성 참고는 현재 루트·부만 기본 표시한다. 인물 문서는 선택한 인물을 유지하며 전체 비교는 별도 버튼으로 연다. 후속 문서·지도·닫기 후 읽던 위치도 같은 기준을 따른다. [표시 기준](notes/modal-route-scope-review.md). 기존 디트리히1부12장 완료·2부 첫 전투 전, 나머지 미플레이 상태는 그대로다. 실제 구매·영입·전투·체크 완료를 추가하지 않았다.

검증: Windows Chrome의 네 루트·2/3부 대표 모달과1440/390폭을 확인했다. 구조상 무기37종의222구역·재료4종의16구역·입수처86버튼, 기존747ID·활성580행동·정본 체크 해시가 유지됐다. 전체111문서 구조 검사와 대표 화면 검증이며 실제 게임 실행 검증은 아니다. 상세 `notes/modal-route-scope-validation.json`.

사용자는 디트리히1부12장 완료·2부 첫 전투 전 그대로라고 재확인했다. 2부 완료·스킵은 하지 않았다. 마지막 확인 파편7,405·구매0·아우로라3·주라2는 새 값 보고 전 유지한다. [이월 기준](notes/carry-hard-review.md)과 시작 전 구매 체크를 추가했다. 구매·새 루트 시작·최종 부대 변화는 아직 실행 보고가 없다.

## 목표와 선호

- 게임을 숙제나 공부처럼 느끼지 않고 즐긴다. 2026-11-04에 **전 루트·전 부·디트리히 재진입 모두 하드·캐주얼로 고정**했다. 노멀 재육성·하드 복귀 계획은 실행 목록에서 제외했다. 실제 게임 설정을 대신 변경하지 않았다.
- 네 주인공 이야기를 전부 본다. 처음 보는 1부·컷신은 건너뛰지 않는다. 반복 2부는 줄이고 싶지만 육성 이득이 충분하면 네 번 직접 해도 괜찮다.
- 필요하다면 훈련·장 재진행·능력치 작업도 허용한다. 허용을 이유로 전부 의무 과제로 만들지 않는다.
- 전투 희망 인물: 리네·우술라·알렉산드라·단테. 여성 캐릭터 중심을 선호하지만 전투상 더 유리한 대안도 허용한다.
- 새 기준: 옛 디트리히 자료가 사라져도 괜찮으며 새 장비와 전용 탈것 보존을 우선한다. 포럼의 보존 절차를 반드시 따르기를 요청했다. 이는 실제 자료 삭제·난이도 변경 실행 보고가 아니다.
- 대화·영입도 가능한 한 챙긴다. 성능이 낮다는 이유만으로 수집 누락을 중요하지 않다고 하지 않는다.

- 최신 요청에 따른 [개인화 HTML 진행표](personalized.html)를 작성했다. 날짜별 번호 목록, 네 희망 동료의 영입·선물·병종, 베르트랑·키릭·레다 전용 의뢰·선더 소드 준비를 담았다. 이는 앞으로 할 계획이며 현재 저장의 완료 사실이 아니다.
- 최신 권고: 세오도라 시작 전 축복 구매 → 세오도라 1부 → 레다 1부 → 디트리히 1부 하드·캐주얼 재육성 → 레다 2부 직접 완료 → 새 디트리히·세오도라 2부의 물품·탑승 자료 준비 → 카이 1·2부 → 3부. **옛 디트리히 2부 선스킵은 제외**했다.
- 일반 물품의 첫 반입 고정과 무료 능력 보완, 전용 탈것·군단의 장착 자료 갱신을 구분했다. 알렉산드라 기준판은 상급 시험 합격 자체를 보류한다. [최신 보존 검토](notes/inventory-mount-review.md)가 이전 개인화 기본안을 대체한다.
- 개인화 화면을 초상화·단계별 구역·펼친 행동 목록·체크 목록으로 바꿨다. `공략 열기.cmd`와 로컬 저장 도구가 `data/checklist.json`을 사용한다. 실제 Chrome과 인앱 브라우저 사이의 체크·해제·새로고침 공유를 확인했다. 시험 체크는 해제했고 실제 게임 진행을 완료로 바꾸지 않았다.
