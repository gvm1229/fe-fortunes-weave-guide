# 레다 루트 진행 상황

## 현재 계획 · 2026-11-04

모든 진행은 하드·캐주얼. 세오도라 시작 전에 아우로라20%할인300을 포함한 축복8개(합계2,600)를 구매하는 계획이다. 마지막7,405 기준4,805 잔여이며 주라20%할인300은 선택이다. 아우로라3·주라2·기존 지도·공통 완료·같은 인물 쌍의 지원을 활용한다. [현재 이월 기준](../../notes/carry-hard-review.md). 이 루트의 실제 새 시작·구매·영입·전투 완료 보고는 없다.

마지막 갱신: 2026-11-04 (한국 시간)

- 현재 위치: 1·2부 모두 미플레이. 사용자가 디트리히 외에는 하지 않았다고 직접 밝혔다.
- 완료·누락·영입·육성: 아직 기록할 실제 진행 없음.
- 축복·공유 자원: [전체 현황](../../progress.md) 참조. 이 루트에서 새로 쓴 자원 없음.
- 다음 할 일(계획·미실행): 세오도라 1부 뒤 [레다 1부](../../personalized.html#leda-plan)를 하드로 한다. 신상품 1→2→3→4·무용수·천녀의 노래·칼라의 활·키릭 의뢰를 챙기고 이오·알렉산드라도 영입한다. 두 전용 탈것을 보관한 1부를 마친 뒤 디트리히 하드·캐주얼 재육성 후 레다 2부를 직접 진행해 키릭·네이선을 챙긴다. 이후 재시작·재장착·스킵으로 탑승 자료를 등록한다. 옛 디트리히 선스킵은 제외했다. 실제 시작·구매·완료는 아직 없다.
- 현재 저장의 난이도·모드: 하드·캐주얼. 미확인: 실제 시작 시점, 사용할 부대.

새 진행을 알려 주면 이 파일과 전체 현황을 함께 갱신한다.

## 공략 표시 갱신 · 2026-11-03

개인화의 아이콘·명성 태그·병종 등급·지도 그림과 루트별 편성을 보완했다. [편성 검토](../../notes/roster-build-review.md)는 제안이며, 실제 게임 진행·영입·전투·파편 사용은 추가 보고되지 않았다. 기존 실제 현황을 유지한다.

## 행동별 안내 갱신 · 2026-11-03

개인화의 현재 루트 인물과 공통 준비를 행동 체크 옆에 표시했다. 가입 병종에서 바로 목표 자격을 준비하며 불필요한 하급직 시험·마스터를 제외했다. [전원 검토](../../notes/late-recruit-review.md)는 자료와 추천이다. 실제 게임 진행·영입·레벨·자원 사용은 새로 보고되지 않아 기존 상태를 유지한다.

## 부별·주간 안내 갱신 · 2026-11-03

독립 스크롤·인물 표·부별 목표와 주간 식사 조를 보완했다. [부별 목표](../../notes/phase-goals-review.md), [지원 안내](../../notes/weekly-support-review.md)는 제안이다. 실제 진행·레벨·지원·소지품 변경은 보고되지 않아 기존 현황을 유지한다.

1부 목표 표시는 [가입 병종별 경로](../../notes/part1-paths-review.md)로 보완했다(2026-11-03). 실제 진행·병종을 변경한 기록은 아니다.
