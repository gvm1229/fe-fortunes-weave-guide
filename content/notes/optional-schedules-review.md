# 선택 일정도 실행 체크로 확인

2026-11-05 · 개인화의 표시·순서 보완이다. 실제 관전·시합·현재 장을 새로 완료한 기록이 아니다.

## 고친 문제

6장에4/6 특별 시합을 ‘별도 일정’이라는 메모로 안내하고, 실제 시합 체크는4/15 봉사 뒤에 두었다. 순서대로 읽으면 늦게 발견할 수 있는 배치였다. ‘작은 보너스는 기존 동선에서 가능한 것만’이라는 이전 설명도 사용자의 놓침 방지 목표와 맞지 않아 대체했다.

**게임에서 선택할 수 있는 콘텐츠도 놓치지 않도록 실행 체크에는 모두 표시한다.** 날짜·장소·선행 조건이 확인된 일정은 귀환과 실제 참가로 나누고 날짜순으로 둔다. 메모나 참고 문서만 읽어야 찾을 수 있게 두지 않는다.

4/6 특별 시합의 기존 체크ID3개는 그대로 두고 귀환 체크만 추가했다. 정오 관전8건은 각각 귀환·관전 체크를 만들었다.6~12장 시작에는 실제 달력의 관전·행사·생일·아직 안 본 선택 장면을 살피는 체크를 둔다.

주간 봉사는 기존 행동ID를 유지한 채 일정 사이에서 나눈다.6장은4/1 봉사 →4/6 시합 →4/8 봉사 →4/10 관전 →4/15 봉사 순이다. 다른 장도 관전보다 뒤인 봉사가 앞에 나오지 않게 했다. 일반 참고 문서보다 본문 체크를 먼저 볼 수 있다.

## 다른 선택 장면 검토

레다·디트리히·카이에 추가한 관전17건·행사/공휴일30일과 선택 장면의 실제 날짜순 배치는 [다른 세 루트 대조](other-routes-schedules-review.md)를 따른다. 세오도라 날짜를 그대로 복사하지 않는다.

기존 `data/missable-events.json`의42개 장면은 본문 체크와 연결되는지 전부 다시 확인한다. 자동 후속도 선행 행동과 관찰 체크를 구별한다. 새 정오 관전8건은 `data/optional-schedules.json`에 별도 날짜·출처·체크 연결을 둔다. 자료에 없는 모든 생일의 날짜를 임의로 채우지는 않는다.

## 출처와 확인 범위

- [일본어 세오도라 플레이 기록](https://note.com/yaoya_neko/n/n8a4e9ed94bb2):6~11장의 정오 관전8건과 기능 종류를 본문에서 읽었다.4/6을 놓치지 않도록 미리 제도로 돌아오라는 경험도 적혀 있다. 날짜별 경험 한 건이며 독립 검증 여러 건으로 세지 않는다.
- [기존4/6 장면 근거](events/miss-theo06-crystal.md), [기존 장면42개 근거](missables-shopping-review.md):4/6 접수 장소·시각과 기존 장면 체크의 출처를 유지했다.
- Windows·Codex에서 자료·생성 문서·체크 연결을 확인한다. 실제 게임의 모든 달력·생일·관전 효과를 재현한 것은 아니다. 당일 표시가 자료와 다르면 실제 게임 표시를 확인하며 시청 완료로 체크하지 않는다.
- 기존 체크·진행 정본은 변경하지 않는다. 새 행동은 미완료로 시작한다. 구조·순서·보존 검증은 `notes/optional-schedules-validation.json`에 남긴다.
