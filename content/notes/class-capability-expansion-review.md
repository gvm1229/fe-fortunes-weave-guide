# 병과 무기·특성 표시 범위 확대

2026-11-04 · current-project. 기존 병과 사실·편성·육성·실제 체크는 변경하지 않았다.

## 적용

- 기능 우선순위의 시점·이유·보충 문장에 있는 병과515곳에 가입 후 목표와 같은 무기·특성 아이콘 줄을 표시했다. 병과 이름으로 여는 기존 중앙 모달 연결은 유지한다.
- 작은 병과 표시도 기존 병과 그림23×23px와 글자 크기·너비를 유지한다. 아래 아이콘 줄만 추가한다. 비교한 비숍·홀리 랜서는 글자15/17px, 기존 너비와 같고 높이만17px 늘었다.
- 병과 모달58개 위쪽에 사용 무기와 병과 특성을 나눠 표시한다. 각 그림은18px, 옆 이름은14px이며, 이름이 이미 있는 그림은 화면 읽기에서 장식으로 취급해 중복 낭독을 줄인다.
- 아이콘 순서·종류는 assets/classes/manifest.json의 기존 자료와 capabilityIconOrder를 재사용한다. 코끼리병의 사용 무기 미표기 상태도 임의로 채우지 않는다.
- 아이콘·이름을 묶은 구역을 문장 표시기가 다시 꾸미지 않도록 하여 흑마술·백마술 이름 앞에 그림이 두 번 붙는 일을 막았다.

## 확인

Windows Chrome에서 세오도라판 리네의 기능 우선순위, 해당 병과 버튼으로 연 비숍 모달을 확인했다. 무기4개와 보병 특성의 이름·그림이 맞고 중복 그림은 없었다. 기존 제목 그림·이름과 중앙 위치를 유지한다.

모달 안의 마스터 보상 목차를 사용하고 Escape로 닫아도 내려 둔 할 일·인물 스크롤 위치가 같았다. 콘솔 오류0개. 참고 문서191개·문구/표9,280개 보존, 그림·출처 누락0, 현재 체크ID1,163개 일치. semantic.css의 layout 검사 경고0개.

체크·편성·부별 목표·행동·기능 우선순위·병과 사실 정본8개의 SHA256은 작업 전과 같다. 실제 게임과 좁은 화면은 이번 실검증 범위 밖이다.
