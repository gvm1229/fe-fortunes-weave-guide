# 병과 경로 · 선택 이유와 필수 조건

2026-11-05. 개인화65루트판의1·2·3부 경로를 기준으로 한다. 실제 시험 합격·마스터 완료를 자동으로 판정하지 않는다.

## 표시를 읽는 법

| 표시 | 할 일 |
|---|---|
| 선택 경유 | 같은 역할의 동급 병과로 바꿔도 된다. 이미 상위 자격이 있으면 낮은 시험을 생략한다. |
| 합류 기준 | 도감·고정 합류의 출발점을 표시한다. 실제 합류 화면과 보유 자격을 먼저 확인한다. |
| 성장 병과 유지 | 이 루트판의 능력 보완을 위해 그 병과에서 레벨업한다. 상급 자격만 땄다고 성장 병과를 바로 버리지 않는다. |
| 선택 · 자격만 | 실전에 쓸 자격이 필요할 때만 시험을 본다. 그 병과에서 레벨업하거나 마스터할 의무는 없다. |
| 전투별 교체 | 회복·기동 등 이번 전투의 역할에 맞춰 바꾼다. 두 병과를 순서대로 마스터하는 경로가 아니다. |
| 육성 선택 | 수집·대화·물품 보존만 하면 현재 병종을 사용한다. 표시한 전투 육성 경로는 생략해도 된다. |

해당 병과를 사용하려면 그 병과의 자격을 얻는다. 다음 병과 시험은 그 시험의 기능·명성·해금·물품 조건을 직접 준비한다. 확인한 시험표에서는 이전 병과의 자격·마스터를 선행으로 요구하지 않는다.

낮은 병과를 생략한다는 안내는 이미 상위 자격이 있거나 다른 동급 병과를 고르는 상황에 적용한다. 초급 시험이 열린 뒤에도 기본 병과로 상급 레벨까지 버티는 과제를 만들지 않는다. 시험은 실제 합격률100%에서만 보고 이미 가진 자격은 다시 사지 않는다.

## 성장·이동·마스터를 구분한다

- 성장 보정은 그 병과로 레벨업할 때 개인 성장률에 더한다. +5%p는 예를 들어30%→35%가 되는 뜻이다. 능력치가 즉시5 오른다는 뜻이 아니다.
- 이동력은 기본 전투맵 수치다. 지형·현재 탑승·장비·스킬의 변화는 실제 화면을 따른다.
- 마스터 보상은 병과 숙련도를 채운 뒤 배운다. 전직 직후의 병과 스킬·고정 능력치 보정과 구별한다.
- 현재 경로에는 하급 병과 마스터를 필수 선행으로 만든 단계가 없다. 보상을 실제로 쓰고 싶을 때만 선택하며, 다음 시험 조건이 됐다면 하급 마스터를 기다리느라 전직을 미루지 않는다.
- 초급·중급·상급 표시와 함께 증서 예산도 전체 경로를 선택할 때의 최대 준비로 읽는다. 생략한 경유·보유 자격·지급 증서만큼 제외한다.

## 세오도라의 경기병

경기병은 창을 유지하며 이동6과 속도 성장+5%p를 택하는 중간 선택이다. 수비 성장을 집중하는 중갑 보병은 이동4·수비+25%p·속도−5%p다. 가디언의 권장35·명성8·창술B는 별도 시험 조건이며 경기병 자격·마스터가 선행 조건은 아니다. [Game8 경기병](https://game8.jp/fe-banshisenko/816659), [중갑 보병](https://game8.jp/fe-banshisenko/816660), [가디언](https://game8.jp/fe-banshisenko/816860).

## 보존·성장 때문에 구분할 경로

- 알렉산드라1·2부는 천익병 합류를 활용한다. 첫 전용 페가수스 반입 전에 상급 시험 합격도 보류한다. 비탑승 중급 자격은 보관용으로 필요할 때만 준비한다.3부 보관 확인 뒤 성천익병을 고른다.
- 이오의 바딩거는 추가 실전 육성을 원할 때만 고른다. 말 보존·등록이 목적이면 경기병 유지가 가능하며, 상급을 택하면 같은 등급의 비탑승 보관 자격 비용도 확인한다.
- 카이의 피터르·그자람·미카엘라는 한혈마 친밀도5·전차병을 성장에 쓴다. 포레스트 나이트는 실전 기동용 자격을 선택하며 레벨업 병과와 구별한다. 전차병은 활을 사용한다. 미카엘라 도끼·그자람 검은 다른 판에서 준비한다.
- 자격만 취득한 뒤 성장 병과로 돌아가는 것은 ‘다음 운용’으로 표시한다. 이미 가진 자격이면 재시험 없이 바꾸며, 상급에서 중급으로 다시 시험을 보라는 뜻이 아니다.
- 카이의 에스메랄다는 속도 성장용 기갑 타조병과 실전 자격용 바딩거를 구별한다. 카이 리네의2부 바딩거·가디언은 회복 필요에 따라 바꾸는 선택이다.
- 티아라의1~2칸 춤은 참모의 재능을 활용한다. 무희 마스터가 사거리 증가의 선행 조건은 아니다. 전직 후 마법 불가와 무희의 목걸이 이전을 확인한다.
- 미카엘라의 배틀 마스터는 힘 성장·도끼 기능을 준비할 실전 선택이다. 디 이터널의 선행 자격·마스터로 강제하지 않으며 배틀 마스터로 마무리해도 된다. 신장직의 전용 아이템·동시1명 조건은 별도다.

## 인물·루트별 내용

같은 병과라도 다른 루트판에 합칠 능력이 다르다. 세오도라 시로코·우술라는 물리 성장 보완, 디트리히 카타냐는 마법검용 마력·마방, 세오도라 리네는 회복 육성으로 이유를 나눈다. 실제 출격 칸이 차서 교대된 예비에게 모든 경유 시험·마스터를 강요하지 않는다.

## 자료와 확인 한계

- 병과·시험·이동·무기 호환: 로컬 병종 도감과 `assets/classes/manifest.json`.
- 병과 스킬·마스터 이름과 효과: 기존 `data/class-details.json`의 로컬·Game8 대조 자료. 보상 효과를 전직 직후 효과로 옮겨 쓰지 않았다.
- 개별 성장 보정: [hyperWiki 병과 성장 표](https://hyperwiki.jp/fefw/class-growth/). 현재 경로47종과 추가 선택 디 이터널을 자료상 확인했다. 성장·탈것은 [기존 성장 설명](level-renown-review.md)도 따른다.
- 경기병 기술 성장은Game8 +5·합계40, hyperWiki 0·합계35로 다르다. 이번 이유 표시에는 기술·합계 수치를 쓰지 않고 일치하는 속도·수비 등을 썼다.
- 더 캘러미티·디 이터널·디 아바타르의 일부S조건은 선택/동시 조건이 미해결이므로 실제 시험창·합격률100%를 우선한다. 칼라드리오스의 기마 요구 차이도 기존 주의를 유지한다.

Windows에서 자료·표시·범위와 기존 체크 보존을 검사한다. 모든 합류 시점의 실제 병종, 모든 스킬의 게임v1.1.0 동작, 성장·전투 효율을 게임에서 재현한 결과는 아니다. 상세 검증은 `class-path-reasons-validation.json`에 기록한다.
