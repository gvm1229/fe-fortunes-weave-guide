# 팀 비교안 교체 대상·표시 결과 · 2026-11-06

## 적용

- 현재25명 정본 유지 · 베르트랑·타리문·아나톨리아·오르헬 미포함
- 네 진영장 포함: 미카엘라→베르트랑 / 파비오→타리문 / 올림피아→아나톨리아 / 피아나→오르헬
- 울턴드 유지 · 사용자 요청대로 울턴드보다 피아나 우선 교체 · 원래 동료의 영입·육성 자료를 삭제한 변경과 구별
- 피아나→오르헬: 리브로·리저브 보강, 기동·레스큐 상실 · 필요 전투에서 피아나 예비 출격
- 올림피아→아나톨리아: 네 진영장 정원을 확보하면서 고유 흑마법 추가 · 올림피아의 사일런스·버서크·원격 회복은 예비로 분리 · 회복은 소피아·오르헬·리네·세오도라에게 분담
- 역할 균형 추천의 명단·교체 대상 유지 · 이 탭의 오르헬은 로레타 대신이며 네 진영장 포함안의 피아나 대신과 구별

## 표시

- 두 비교안 모두 현재25명과 이름으로 비교 · 정렬 위치 이동을 신규 편입으로 처리하지 않음
- 변경 카드에4px 윤곽선과 오른쪽 위 채움 배지 · 상세·한눈 보기 공통
- 선택 교체도 동일 기준 · 아스완 선택 시 ‘이니오니 대신’·4px·25명 유지 확인
- 1920 한눈 보기의 짧은 이유는 이름 옆 배지로 배치 · 같은 이유의 아래 문단 중복 표시 제거 · 이름·무기·설명 글자 크기를 줄이지 않고25명 수용
- 4K5열은 특기 그림만 표시해 긴 이름의 줄바꿈을 줄임 · 기본 상세·작은 화면의 기능 이름은 유지
- 실제 편성·체크·성장·게임 설정 변경 없음
