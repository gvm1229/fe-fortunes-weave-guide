# 팀 화면 3840×2160 검토·수정 · 2026-11-06

1. 지정된 실제 화면을3840×2160에서 읽고 카드 높이·내용 높이·아이콘 크기·빈 공간을 측정한다.
2. 화면 높이를5등분해 늘리던 카드 대신 내용과 읽기 크기에 맞춰 배치한다. 넓은 공간은 큰 얼굴·읽기 쉬운 글자·아이콘과 명확한 행에 사용한다. ‘사용 가능 무기’와 ‘주요 무기’를 두 행으로 분리한다.
3. 디트리히 주요 무기를 재계의 검에서 사검 벨로키네로 바꾸며 실제 아이콘·사용 조건·출처를 연결한다. 획득 완료·구매 의무·나머지 인물의 무기 변경으로 확대하지 않는다.
4. 4K의 기본/한눈 보기·두 색상,1920×1080과 좁은 화면에서 카드 내용·줄바꿈·아이콘·모달·25명 보존을 확인한다. 남는 높이를 카드의 빈 내부 공간으로 강제하지 않는다.
5. 생성 정본과 React 묶음을 갱신하고 사용자 선호·검증 범위·한계를 프로젝트 안에 기록한다. 실제 진행·체크는 건드리지 않는다.
