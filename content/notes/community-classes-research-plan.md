# 최종 병과의 외부 선택 사례 조사 · 2026-11-06

1. 현재 팀 화면의32명·최종 병과를 읽기 전용 비교 기준으로 고정. 실제 공략·편성·화면·체크는 수정하지 않음
2. 한국어·영어·일본어의 실제 플레이 기록·종료 편성·인물별 병과 토론을 검색. 같은 플레이어의 원본/번역/재게시를 하나로 집계
3. Game8·GameWith 등 편집 공략의 추천은 실제 플레이어 사용 사례와 별도 표시. 1·2부 성장 병과와3부 최종 병과 구별
4. 인물마다 확인한 선택·현재 병과·일치/차이·판단 한계를 표로 정리. 대표 표본·집계가 없으면 ‘가장 많이 선택’으로 단정하지 않음
5. 출처·열람 범위와 비교 결과를 별도 조사 기록에 저장. 기존 공략 정본의 변경 여부 확인

자료 범위:현재 프로젝트만. 전역 Hive·외부 업로드·공략 자동 반영 없음

## 추가 범위 · 캐릭터 사용·교체 제안

6. 실제 플레이 기록의 사용 인물도 함께 집계. 같은 작성자·영상 번역·재게시 중복 제거. 공략 평가·추천과 실제 사용 빈도 구별
7. 지양10명은 제안에서 제외. 여성 선호·희망4인·현재 버전/합류 시점·한정 경험치·3부25인 역할 배분을 고려
8. 같은 역할에서 더 강한 근거가 있는 후보와 교체 대상·얻는 것·잃는 것·추가 육성 비용을 별도 제안. 현재25인·과정 공략에는 적용하지 않음
