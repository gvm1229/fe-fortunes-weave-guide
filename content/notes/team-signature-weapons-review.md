# 최종25인 대표 무기·한국어 이름

완료:2026-11-06 · Windows · 현재 프로젝트만

## 화면

- 현재·추천·네 진영장·체험 후보32명에게 대표 무기/마법2개씩 지정. 실제 선택25명에는 배지50개 표시
- 아이콘과 이름을 같은 채움 배지로 묶고 외곽선 제거. 기능 특기·무기 종류와 대표 품목을 구별
- 기본6:4·4열에서 무기 종류 아래 대표 무기 행.5열에서는 대표 품목을 무기 행에 표시하고 두 이름 모두 유지
- 5열은 얼굴80×96 옆에 이름·역할·병과·짧은 설명, 아래에 대표 무기→특기→핵심 백마술 배치. 상세 이유는 이름 클릭 모달에 유지
- 기존25인·병과·8개 신장직·정렬·선호 인물·교체 강조 유지. 우술라는 활 주력·물리검 보조로 정정
- 인물 모달에도 대표2개의 쓰임·원문 연결 추가. 구입·습득 완료나 소지품2칸 제한으로 표시하지 않음

## 선정·그림 근거

- `data/team-signature-weapons.json`:42품목·32명 선정과 조건. 전용 전투 기술·최종 병과·현재 역할을 기준으로 선정한 대표 예시이며 최강 순위나 강제 구매 목록이 아님
- `data/team-signature-learning.json`:마법을 배정한12명의20개 학습 등급을 인물 원문과 대조
- `assets/weapons/manifest.json`·`SOURCES.md`:Game8의 실제 무기·주보·흑마법·백마법 그림8개. 원문이 같은 아이콘을 쓰는 품목은 같은 파일을 공유. 개별 장비 일러스트로 임의 제작하지 않음
- 그림/요구 기능:[Game8 일본어 무기 목록](https://game8.jp/fe-banshisenko/817514), [마법 목록](https://game8.jp/fe-banshisenko/817283)
- 학습:각 인물의 Yu Phas’ Temple 원문. 레스큐의 일본어 목록 누락은 다른 항목을 만든 것으로 처리하지 않고 확인된 원문과 백마법 종류 그림을 사용
- 희귀품을 동시에 두 사람에게 배정하지 않도록12개 편성 대조. 미카엘라와 베르트랑의 잘목시스는 서로 교대하는 경우의 같은 무기 배정. 일반 구입 무기·실제 보유량은 별도

## 한국어 이름

대응 정본:`data/team-korean-name-sources.json`. 한국어 도감의 각 항목 제목을 직접 대조한10개

| 이전 표시 | 현재 표시 |
|---|---|
| Barrier | 배리어 |
| Resquia | 레스키아 |
| M실드 | 매직 실드 |
| Horsekiller Bow | 말 킬러의 활 |
| Shining Spear | 소렐의 휘창 |
| Star Spear | 아우로라의 성창 |
| Mahadu's Spear | 마하마두의 창 |
| Zalmoxis | 잘목시스 |
| Idah's Bow | 이데아의 활 |
| Zerberus | 체르베루스 |

한국어 명칭은 [만자천홍 도감의 전체 문서](https://fire-emblem-fortunes-weave.turam.dev/ko/directory/)에서 개별 항목으로 이동해 제목 확인. 에드릭슨의 말잡이 활과 같은 다른 표기와 섞지 않고 이 도감 명칭으로 통일. 이미 사용자가 확인한 한국어 품목명은 이번 대조로 일괄 변경하지 않음

`tools/team_item_names.py`는 화면 문구·제목·접근 가능한 이름과 동적 표시 자료에 같은 대응 적용. 원문 주소·식별자·원어 메타데이터 보존. 기존 영문 임시 표시 규칙을 실제 한국어 이름 확인으로 대체

## 검증·한계

- 실행:Windows Python·Chrome. `team-signature-weapons-validation.json`과 `team-signature-weapons-browser-validation.json`에 범위 기록
- 32명×2개·42품목의 현재 병과 사용 가능·마법20개 학습·트로이아 화기 제한·희귀품 중복·아이콘 파일 확인
- 12개 편성 모두1920×1080에서 기본4열/한눈5열·25명·배지50개·한국어 이름·채움 배지·잘림 없음 확인
- 모달 중심960×540, 닫기 전후 양쪽 스크롤 위치 일치. 대표 무기 이름과 설명 표시 확인
- 1440×900은3열,390×844는1열로 전환. 이름 유지·카드 가로 넘침·바깥 스크롤 없음. 좁은 화면은25명 전체를 동시에 표시하는 범위가 아님
- 배지의 글자 대비:밝은 화면8.04:1·어두운 화면8.11:1. 일반 글자 기준4.5:1 이상
- 글꼴275HTML·9파일 오류0. 기존 문체 검사12,479문구·체크1,712ID 보존. 현재 진행/과정 정본8개 작업 시작과 동일
- 게임 저장 파일의 실제 보유·강화·학습·피해를 확인한 검증은 아님. 한국어 명칭은 공개 도감 제목 대조이며 모든 품목을 게임 화면에서 재촬영한 결과는 아님
