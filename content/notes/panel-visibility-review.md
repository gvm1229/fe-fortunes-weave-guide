# 상자별 표시 버튼 · 2026-11-04

메뉴·할 일·공통 준비·인물의 머리글에 눈 아이콘을 붙였다. 오른쪽 위에도 이름과 눈 아이콘이 있는 버튼4개를 둔다. 기존 왼쪽 버튼3개는 유지하며 모든 위치가 같은 표시 상태를 사용한다.

- 펼친 눈은 표시 중, 선이 그어진 눈은 숨김이다. 버튼의 설명·보조기기 이름도 숨기기/보이기로 함께 바뀐다.
- 숨길 때 상자 안을 읽던 위치를 기억하고, 다시 표시하면 복원한다. 상자 안 버튼으로 숨겼다면 키보드 초점은 오른쪽 위의 같은 버튼으로 옮긴다.
- 할 일을 숨겨도 오른쪽 위 버튼은 남는다. ‘다음 할 일’과 루트 선택·본문 행동 연결은 할 일을 다시 표시한다.
- 작은 화면에서는 공통 준비·인물 중 한 개만 표시하는 기존 방식을 유지한다. 모달에는 기존 닫기 버튼을 사용한다.
- 체크 정본·게임 진행·가호·파편·구매 여부는 이 작업으로 바꾸지 않는다.

Windows Chrome의1440×1000에서 네 상자의 숨김·복원과 스크롤 위치를 확인했다.390×844에서 오른쪽 위 버튼4개가 모두44px 이상의 높이로 보이고, 공통 준비/인물 전환과 가로 넘침 없음을 확인했다. 실제 게임 조작을 검증하는 작업은 아니다.
