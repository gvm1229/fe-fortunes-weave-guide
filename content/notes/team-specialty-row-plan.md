# 특기 행·기본4열 보완 · 2026-11-05

1. 현재 특기 자료와 아이콘을 재사용해 전원 특기 행 추가. 무기는 사용할 무기, 특기는 기능의 습득 특기로 구분
2. 두 행에 실제 텍스트 라벨 ‘무기’·‘특기’ 표시. 특기는 설명 바로 아래·핵심 백마술 바로 위에 가로 정렬. 미표기는 추정하지 않음
3. 참고 영역 표시 상태의 넓은 화면은4열. 무기·특기 아이콘 옆 이름 유지, 작은 화면에서는 읽을 수 있는 열 수로 조정
4. 한눈 보기5열만 아이콘 중심 표시.25명·신장직8종·정렬·채움 배지·교체 카드 강조를 유지하며 새 특기 행을 넣을 공간 확보
5. 생성 자료 검사·글꼴 검사와 실제1920×1080의4열/5열, 비교/체험, 좁은 화면·숨김 복원을 확인. 실제 진행·체크·육성 계획에는 쓰지 않음
