# 세오도라5장 명성2 · 조건별 행동

기준일: 2026-11-05. 현재 프로젝트만의 개인 진행 안내다.

## 지금 할 일

현재는 **세오도라1부5장·명성2**다. 군비증강2건과 소피아 영입은 완료했다. 리네·단테·우술라·로레타·루루디아·이오의 부족한 지원을 올리는 일은 계속할 수 있다. 요구 지원을 채운 사람은 다음 사람에게 자리를 넘긴다.

| 실제 명성 | 실행할 일 | 기다릴 일 |
|---|---|---|
| 현재2 | 소피아·군비증강 완료 확인, 여섯 명의 부족한 지원 준비, 기존 동료 육성·봉사 | 녹투라 영입, 중급 시험, 시로코 수주·사본 원정, 로레타·리네·단테 영입 |
| 3 | 녹투라 지원1과 등장 상태를 확인해 영입 | 중급 시험은4, 시로코·로레타는5, 리네·단테는6까지 대기 |
| 4 | 목표 중급 병종의 기능·해금·합격률100%를 확인해 필요한 사람만 시험 | 명성5/6 영입·의뢰 |
| 5 | 시로코 지원1 → 본인에게 스카우트 수주 → 전력·기한 확인 → 사본 회수·귀환 보고. 로레타 지원3·철의 검3개를 갖추면 영입 | 리네·단테는6까지 지원만 준비 |
| 6 | 리네·단테 각각 지원3, 반짝반짝어1, 단테8,000G를 갖춰 실제 영입 | 아직 부족한 조건이 있으면 해당 조건부터 준비 |

**6장 명성3은 사용자 예상이며 실제 진행 완료가 아니다.** 새 장을 시작했다고 명성을 자동으로 바꾸지 않는다. 명성5/6 도달 장은 아직 정하지 않는다. 화면의 ‘나중에’ 묶음도 특정 장에서 모두 끝내야 한다는 뜻이 아니다.

5장부터 등장·스카우트 기능 개방은 명성 조건 충족과 다르다. 지원이 남아 있어도 명성이 부족하면 영입·전용 의뢰는 기다린다. 놓치기 전에 마칠 기한은 그대로 지킨다.

## 전직·돈을 준비할 때

- 지금은 초급 병과를 사용한다. Lv19 전후에 닿았는데 중급 조건을 기다릴 때만 추가 경험치10%를OFF로 두고 전직 뒤ON으로 복구한다.5·6장에Lv20을 달성하려고 반복 육성하지 않는다.
- 4~6장 기본 예산에서 명성4 중급 증서·명성5 로레타 물품·명성6 단테 영입금을 뺐다. 필요한 명성과 다른 조건을 갖추고 실제 행동할 직전에 추가한다.
- 5장의 기본 추천액은2,300G(미보유 초급 증서1장300G+여유2,000G),6장은3,000G(필요한 선더 소드 강화1,000G+여유2,000G)다. 이미 가진 자격·강화한 무기의 비용은 제외한다. 실제 잔액 보고나 강제 장 진입 조건은 아니다.

## 바꾼 순서와 체크 보존

5장에는 완료 확인과 지원 준비를 남겼다. 녹투라 영입은6장의 ‘실제 명성3이 되면’ 묶음으로 나눴다. 시로코 의뢰·원정과 로레타 영입, 리네·단테 요구품·영입은 별도의 명성5/6 조건 묶음으로 옮겼다.7장 안내에서도 영입 완료를 전제하지 않는다.

기존 행동19개와 로레타 묶음을 옮기되 체크ID·옛 묶음 상속·현재 완료값을 보존했다. 새 녹투라 영입 행동은 미완료로 시작하며 현재 명성2만 보고 자동 완료하지 않는다. 기존의 준비 체크를 실제 명성5 달성·시로코 수주 완료로 해석하지 않는다.
