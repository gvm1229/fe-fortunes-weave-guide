# 루트별 재료·입수처 참고 목록 · 2026-11-05

## 바뀐 화면

개인화의 ‘공통 준비·인물’ 옆에 ‘재료·입수처’ 탭을 추가했다. 네1부 루트의 선더 소드 교환 재료·수량·위치 그림, 현재 본문에서 준비하는 영입 물품의 수량·입수처·수주 조건·기존 지도 연결을 표시한다. 세오도라 군비증강14건은 장별 물품 목록으로 모았다. 레다 힝가샤와 그 밖의 등록된 의뢰 재료도 본문 자료에서 가져온다.

참고 목록에는 체크박스·진행ID를 추가하지 않는다. 완료 숨기기를 켜도 참고 목록은 남는다. 탭을 오가거나 입수처 창을 닫을 때 할 일의 읽던 위치를 보존한다. ‘재료·입수처’의 위/아래 이동·숨기기와 주소의 `#route-materials` 바로가기도 연결했다.2부·3부에는 반입품과 해당 부의 개방 조건을 먼저 확인하는 안내를 둔다. 새 수집처를 추측해 채우지 않았다.

## 내용의 정본

- 선더 소드: `data/weapon-buy-sources.json`의 `tradeRecipe`와 `data/purchase-plan.json`. 교환창 개방과 실제 선더 소드 재고를 구별한다.
- 영입 물품: `data/recruit-materials.json`, `data/roster-plan.json`, 현재 루트의 `data/playbook.json` 행동. 물품 없는 영입자를 위한 새 재료를 만들지 않는다.
- 군비증강: `data/theodora-timing.json`의5~11장 물품14건.
- 그 밖의 재료: `data/playbook.json`의 기존 재료·부품·힝가샤·라돈 꼬치고기 안내.
- 지도: `assets/recruitment/map-links.json`의 기존 핀 주소와 기존 입수처 문서. 새 좌표·핀ID를 조합하지 않았다.
- 생성: `tools/material_reference.py`를 `tools/workspace_ui.py`에서 사용한다. `tools/build_playbook.py`로 다시 만들어도 남는다.

## 실제 진행과 선호

사용자의 세오도라1부7장·선더 소드 교환 미해금 보고를 전체/루트 진행에 반영했다. 재료 안내 체크는 준비를 이해한 표시이며 실제 보유 수량·수집·교환 완료로 바꾸지 않았다. 체크 없는 참고 목록을 별도로 두는 선호는 `notes/knowledge/interface.md`와 출처에 현재 프로젝트 범위로만 기록했다. Hive·전역 저장·공유 색인·외부 업로드는 사용하지 않았다.

## 검증한 범위

실행 호스트는 Codex, 운영체제는 Windows다.

- 생성·파일 검사: 참고 목록의 체크박스0개, 여섯 단계별 표시 구역, 네 루트 선더 소드 재료·입수처, 참고 HTML·그림의 존재, 선호 출처 연결을 확인했다. 기존1,712개 체크의ID·속성·순서와 체크JSON·행동 정본·이전 완료 연결 파일의 내용 해시가 작업 전과 같다. 이는 파일·연결 보존 확인이며 새 게임 완료를 뜻하지 않는다.
- 글꼴·문법: `python tools/check_fonts.py`로239HTML·로컬 글꼴9개 오류0, `node --check personalized.js`로 문법 오류 없음을 확인했다. 실제 모든 문서의 그림·색을 확인한 검사는 아니다.
- 브라우저: Windows의 인앱 브라우저에서 실제 CSS 크기1920×1080·600×900·480×844를 확인했다. 전 루트/부 전환, 선택 탭 하나만 표시, 체크 없는 목록, 완료 숨기기와 무관한 표시, 탭별 스크롤 복원, 기존 선더 소드/영입 물품 모달의 지도·그림, 바로가기, 키보드 Home/End, 밝은/어두운 화면과 가로 넘침 없음을 확인했다.600px에서는 두 열을 유지한다. 좁은 화면의 머리글 버튼이 잘리지 않게 기존 작은 버튼 배치를900px까지 사용한다.
- 자동 시각 검사: `impeccable detect`를 실제 실행했으나 기존 병과 태그 간격·기존 꾸밈 등의 경고로 종료값1을 반환했다. 연결된 스타일 내부의 글꼴 경로를 프로젝트 밖으로 잘못 해석한 경고도 있어 완전 통과로 기록하지 않는다. 실제 파일 연결은 별도 글꼴 검사에서 확인했다. 기존 화면 전체의 재설계는 이번 범위에서 하지 않았다.
- 미검증: 이 브라우저에서 요청한390px는 실제480px로 제한돼390px 실물 크기를 증명하지 못했다. 실제 휴대폰 기기·Whale의 모든 조합·게임 안 재료 확보·교환 해금 시점은 이번에 재현하지 않았다. 이번 작업은 기존 자료의 참고 표시와 화면 동작을 검증한 것이다.
