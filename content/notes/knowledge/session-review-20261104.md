# 다른 네 대화의 선호 재검토 · 2026-11-04

범위는 현재 프로젝트(`current-project`)뿐이다. 이 문서는 원문 대화가 아니라 출처 위치와 짧은 검토 판단을 남긴다. 기존 지식에 있는 선호는 다시 항목으로 만들지 않았다.

로컬 Codex·Windows에서 대화 읽기 도구로 아래 네 대화의 마지막 페이지까지 확인했다.

사용자 메시지 147개에는 공통 과거 이력이 포함된다. 메시지 식별자로 중복을 제거한 것은 91개다. 이 중 51개는 이전 [출처 목록](sources.md)에 이미 있던 발화라 다시 기록하지 않았다. 나머지 40개는 기존 로컬 문서 8개와 프로젝트 규칙을 의미로 대조해 아래처럼 처리했다. 출처 식별자가 전에 없던 발화도 내용이 이미 기록돼 있으면 새 지식으로 추가하지 않았다.

| 처리 | 발화 수 |
| --- | ---: |
| 기록됨 | 26 |
| 새 규칙 | 3 |
| 후속 요청으로 대체 | 3 |
| 게임 사실·진행 값 | 4 |
| 질문·해당 응답 범위 | 4 |

새 규칙은 P17·W17·W18 세 개다. 기존 명단의 7명 표현과 결과 화면의 동일 너비 설명은 이미 저장된 최신 규칙을 가리키도록 정리했다. 지양 10명·최종25명·Pretendard 등 기존 선호를 새로 추가한 것으로 세지 않는다. 이번 요청으로 허용된 자동 기록 방식은 [공통 기록 절차](auto-capture.md)에 따로 남겼다.

## 확인 한계

- 통과: 로컬 Windows·Codex에서 네 대화의 끝까지 읽고 중복을 제거했다. 확인한 시점 뒤에 추가된 발화까지 포함했다는 뜻은 아니다.
- 통과: 명시 선호만 추가하고 기존 항목의 문구·출처·문서 연결을 확인했다. 사용자 질문 속 가설을 게임의 확정 사실로 올리지 않았다.
- 미실행: 첨부 이미지 픽셀 재판독, 게임 실행, 실제 진행·구매 재확인은 이번 선호 정리 범위에 포함하지 않았다. 이미지와 함께 적힌 사용자 설명만 검토했다.
- 미실행: 전역 Hive·공유 색인·외부 업로드를 사용하지 않았다. 별도 상시 감시나 다른 대화에 보내는 메시지도 만들지 않았다.
- 지식은 일반 로컬 Markdown이다. Hive 정본 등록·색인 등록의 성공으로 표현하지 않는다.

로컬 문서·출처 연결 검사와 체크 JSON 보존 확인 결과는 [검증 기록](../knowledge-rescan-validation.json)에 있다. 자동 기록은 각 대화의 에이전트가 수행하는 지침이며 상시 감시 프로그램의 동작을 시험한 것은 아니다.
