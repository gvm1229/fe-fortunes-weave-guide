# 유료 융합·문 전투의 손실 방지

범위: 현재 프로젝트만 · 출처:2026-11-06~07 현재 대화의 Reddit 피해 사례 확인·스포일러 없는 문 전투 준비/체크 요청과 일반 동료300파편 비용 정정

- 일반 동료의 추가 자료1개를 합칠 때마다300파편 · 여러 판이면 횟수만큼 지출 · 카이/디트리히/세오도라/레다의 무료 자동 융합과3부 전용 인물의 비대상을 구분
- 레다 1부 첫 보상 뒤 기존 주력 기능 7종 +3, 크레르 할인 50%, 인물 경험치 +20%의 미구매 단계만 산다. 3부 진입 전에 융합용 5,100파편을 남긴다. [2026-11-10 승인](sources.md#leda-boons-fusion-reserve-20261110)
- 구간 재시작으로 해당 구간의 융합 결과가 사라져도 소비 파편은 미환급이라는 반복 보고 · 수동 세이브/클라우드가 이 지출을 되돌릴 것이라고 약속하지 않음
- 지원 루프·재시작·기준판 재선택 작업부터 종료하고,전투 예고·실제 참전할 부대의 구성/위치를 확인한 뒤 필요한 유료 보완만 실행
- 명계의 문에는 문 위나 인접 지점 부대가 참전 후보 · 최종25명 보유와 모든 전투 동시 출격은 별개 ·9인/17인 등 실제 상한을 배치창에서 확인
- 방지 행동은 해당 시점의 본문 체크에 표시 · 참고 표/근거 모달만 읽어야 알 수 있는 숨은 필수 행동으로 두지 않음 · 새 안전 체크는 기존 완료를 상속하지 않음
- 사용자에게는 보스 정체·사건·결말을 밝히지 않고 전투의 인원·적 병종·타일·회복·장비·부대 이동만 설명
