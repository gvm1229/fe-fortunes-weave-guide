# 프로젝트 전용 사용자 지식

이 폴더는 이 공략에서만 쓸 사용자 선호와 작업 방식의 정본이다. 범위는 `current-project`다. 전역 공유·승격·다른 프로젝트에서의 재사용은 허용하지 않는다. 이 경계는 [현재 설정 요청 S52](sources.md#s52)를 따른다.

## 먼저 읽을 문서

- [모든 대화의 선호 자동 기록](auto-capture.md): 명시 선호를 같은 응답에서 중복 없이 로컬에 저장하는 절차.
- [게임과 편성 선호](preferences.md): 즐기는 목표, 난이도, 이야기, 수집, 동료 선택과 육성.
- [공략 작성 방식](guide-workflow.md): 조사·질문·승인·진행 기록·장별 실행 안내.
- [반복 금지 육성 추천](training-advice-guardrails.md): 여관 우선·강제 교대·출격/경험치 혼동·근거 없는 반복 성장 추천 방지.
- [화면 사용 방식](interface.md): 체크·배치·모달·그림·조건 표시.
- [명시 발화 출처와 전체 검토](sources.md): 세 대화의 중복 제거와 항목별 근거.
- [최종25명과 루트별 육성](final25-targets.md): 현재 승인된 목표·자원 제한·최신 지양 명단.
- [유료 융합·문 전투의 손실 방지](merge-gate-safety.md):300파편·구간 재시작 비환급·원정부대 위치와 참전 확인.
- [개인화 팀 구성 결과 화면](team-results-page.md): 과정과 결과 화면 구분·6:4 배치·주요 백마술·실제 아이콘.
- [지원의 뜻과 하트 표시](support-word-meaning.md): 관계 수치와 전투 역할의 지원을 구별하는 기준.
- [다른 네 대화의 추가 검토](session-review-20261104.md): 이미 있는 항목·새 규칙·대체된 요청의 구별과 후속 출처.

각 문서의 `S01` 같은 표시는 출처 문서의 사용자 메시지 번호다. 대화 원문이나 조언을 그대로 지식으로 복사한 것이 아니다. 세 대화의 공통 과거 이력은 한 번만 근거로 센다.

## 읽기와 갱신

1. 관련 문서를 읽는다. 필요한 단어는 `rg -n -- <검색어> notes/knowledge`로 찾는다.
2. 사용자가 명시한 재사용 가능한 선호·작업 방식은 별도 저장 요청을 기다리지 않고 같은 응답 안에서 짧게 정리한다. 기록 전 기존 뜻과 비교하고 같으면 새 항목을 만들지 않는다. 자세한 순서는 [자동 기록 절차](auto-capture.md)를 따른다. 게임 규칙의 사실 확인은 별도의 근거 문서에서 한다.
3. 최신 발화가 이전 결정을 바꾸면 최신 규칙을 본문에 남기고 이전 규칙이 대체됐음을 적는다.
4. 현재 장·소지금·레벨·소지품은 여기에 저장하지 않고 기존 `progress.md`와 루트별 진행 기록을 갱신한다.
5. 원문 대화, 숨은 추론, 도구 출력, 임시 파일 경로, 비밀정보는 지식에 저장하지 않는다.

## Hive 연결 범위

- 프로젝트 설정은 한국어·로컬 위키 활성화 상태다.
- Hive 0.14의 공유 검색 색인은 전역 저장소에 있다. 전역 읽기 전용 요구를 지키기 위해 이 프로젝트의 빈 컬렉션 연결을 해제했다.
- 이 폴더는 일반 Markdown 지식이다. Hive 정본 등록·검색 색인 등록을 성공했다고 주장하지 않는다. `.hive/knowledge/`의 생성 파일을 수작업으로 등록한 것처럼 꾸미지 않는다.
- 전역 지식은 필요할 때 관련 정본을 읽기만 한다. 이 프로젝트 내용을 전역 정본이나 검색 색인에 넣지 않는다.
- 이번 검증에서는 분리 후 추가 Hive 명령과 동시 작업이 이어지는 동안 빈 컬렉션의 재연결을 관찰했다. 원인은 확정하지 못했다. 일반 작업에서 Hive 명령을 자동 실행하지 않고 파일 도구로만 읽고 갱신한다. 설정을 다시 수행할 때는 이 제한을 먼저 확인한다.
- 설치·분리의 실제 결과와 제한은 [설정 검토](../hive-local-setup-review.md)를 따른다. 운영체제 권한으로 전역 쓰기를 봉쇄한 상태는 아니다.

## 이미 대체된 요청

- 최초의 Hive 사용 금지는 이번 프로젝트 설정 허용으로 대체됐다. 전역 쓰기 금지는 계속 적용한다.
- 디트리히 노멀 재진행 뒤 하드 복귀 계획은 전 루트·전 부 하드·캐주얼 고정으로 대체됐다.
- 화면 오른쪽 아래의 전체 ‘맨 위’ 버튼은 영역별 ‘맨 위로·맨 아래로’로 대체됐다.
- 공통 준비·인물을 위아래에 나누는 배치는 한 공간의 가로 탭으로 대체됐다.
- 전체 남성 제외로 해석하지 않는다. 지양 명단은 [최종25명 목표](final25-targets.md)의 최신 정본을 따른다. 이전 7명 설명은 이미 저장된 10명 명단으로 대체됐다.
- 결과 화면의 이전 동일 너비 두 열 설명은 [결과 화면 정본](team-results-page.md)의 6:4 배치로 대체됐다.
