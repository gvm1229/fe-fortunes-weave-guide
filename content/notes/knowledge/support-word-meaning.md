# 지원의 뜻과 하트 표시

- 범위: 현재 프로젝트만. 출처: 사용자 2026-11-04 명시 요청.
- 하트와 분홍 지원 태그는 인물 사이 관계를 뜻하는 지원 레벨·조건·집중·대화·상승에만 쓴다.
- 전투 지원·상태 지원·회복 지원·지원 사격·지원군은 관계 수치가 아니다. 같은 단어가 들어가도 하트나 지원 레벨 배경을 붙이지 않는다.
- 단독 단어 ‘지원’을 보고 관계 의미로 자동 추정하지 않는다. 수치나 관계 문맥을 확인한다.
- 사례: 최종25명 올림피아의 ‘원거리 회복·상태 지원’은 일반 전투 역할이다. 하트 없이 표시한다.
- 자동 꾸밈 정본: tools/format_guide.py의 is_support_context와 tools/ui_semantics.py. 본문·버튼·이전 자동 태그의 재처리에도 같은 판정을 사용한다.
- 팀 비교 화면의 무기 아이콘은 사용 무기 종류·마법이다. 마법검은 검에 포함하고, 현재 병종에서 못 쓰는 마법은 넣지 않는다. 배운 마법·소지품·실제 사용 가능 무기를 구별한다.
