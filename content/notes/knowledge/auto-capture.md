# 모든 대화의 선호 자동 기록

범위: 현재 프로젝트만. 근거: 2026-11-04 「프로젝트 전용 Hive 설정」 대화에서 사용자가 다른 네 대화의 중복 없는 선호 정리와, 이후 모든 대화의 명시 선호 자동 기록을 요청했다.

사용자가 재사용할 선호·작업 방식·결정·정정을 직접 밝히면 그 대화를 맡은 에이전트가 같은 응답을 끝내기 전에 기록한다. 매번 별도 저장 요청이나 승인을 받지 않는다. 사용자의 명시적인 저장 제외 요청은 우선한다.

## 매 응답의 순서

1. 현재 사용자 발화에서 재사용 가능한 명시 선호가 있는지 확인한다. 단순 질문·가설·조사 결과·에이전트 제안은 새 선호로 만들지 않는다. 실제 수치·구매·장 진행은 진행 기록과 해당 정본의 영역이다.
2. `README.md`와 관련 주제 문서·출처를 읽고 같은 뜻이 있는지 찾는다. 문장이 달라도 같은 요구면 기존 지식이다.
3. 뜻이 같으면 기존 항목을 그대로 두고 새 항목을 만들지 않는다. 새 예외·조건은 기존 항목에 합친다. 최신 정정은 기존 항목을 고치고 무엇을 대체했는지 짧게 남긴다.
4. 새 주제만 기존 문서의 안정된 항목으로 추가한다. 새 문서가 꼭 필요하면 `README.md`에 연결한다. 한 선호를 여러 문서에 같은 명단·수치로 복사하기보다 정본 한 곳으로 연결한다.
5. 날짜와 실제 대화 제목·메시지 식별자 등 다시 찾을 수 있는 출처를 남긴다. 식별자를 알 수 없으면 날짜·대화 제목·정리한 요지만 적고 식별자를 만들지 않는다. 원문 전체나 임시 첨부 경로는 남기지 않는다.
6. 쓰기 직전에 최신 파일을 다시 읽고 필요한 부분만 수정한다. 같은 파일을 다른 대화가 바꿨으면 그 변경을 보존한다. 과거에 읽어 둔 파일 전체로 덮어쓰지 않는다.
7. 파일과 출처 연결·중복 여부를 확인한 뒤, 새 기록이나 갱신이 있으면 최종 답변에서 결과와 로컬 경로를 짧게 알린다. 실패했으면 원인과 저장되지 않은 범위를 밝힌다. 새로운 내용이 없으면 기록 수를 부풀리지 않는다.

## 기록하지 않는 것

- 원문 대화·전체 대화·숨은 추론·도구 출력·임시 파일 경로·비밀·민감 정보.
- 확인되지 않은 추측이나 에이전트가 제안했을 뿐인 선택.
- 현재 장·금액·보유품 같은 일시적 상태를 영구 선호로 바꾼 내용.
- 답변만 원한다는 요청을 실제 공략 수정 승인으로 넓힌 해석.

## 적용과 한계

이 절차는 루트 `AGENTS.md`를 읽는 모든 프로젝트 대화의 작업 규칙이다. 각 에이전트가 그 대화에서 사용자 발화를 처리할 때 실행한다. 읽거나 응답하는 에이전트 없이 다른 대화를 상시 감시하는 기능은 아니다. 별도 예약 작업·감시 프로그램·다른 대화로 보내는 메시지를 만들지 않는다.

전역 Hive 명령·전역 지식 기록·공유 색인·승격·동기화·외부 업로드는 사용하지 않는다. `notes/knowledge/`의 일반 Markdown을 파일 도구로 읽고 수정한다. 한 대화의 선호를 기록했다고 게임 진행이나 체크 완료를 자동 변경하지 않는다.
