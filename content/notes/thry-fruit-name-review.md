# 발레리 협곡의 열매 이름 정정 · 2026-11-05

## 현재 이름

**태양 열매**를 쓴다. 영문 `Thry Fruit`, 일문 `サンノミ`와 같은 물품이다. ‘스리열매/스리 열매’는 영어 이름을 임시로 옮긴 잘못된 한국어 안내였다. 영어 지도 그림에서 이름이 다르게 보인다는 이유로 실제 한국어 이름을 배제한 판단을 폐기한다. 발레리 협곡에서 별도의 다섯 번째 열매를 찾을 필요가 없다.

| 사용자 게임 화면 보고 | 영문 채집 목록 |
|---|---|
| 리나리아 | Linaria |
| 태양 열매 | Thry Fruit |
| 멜라라 | Melara |
| 리가네트 | Liganet |

## 수량과 장소

- 태양 열매: 발레리 협곡에서 채집한다. 선더 소드1자루의 교환용은10개,2자루를 모두 새로 교환하면20개다.
- 유나메이: 별도 재료다. 다마센 곶에서1자루당1개,2자루면2개를 준비한다.
- 세오도라7장 군비증강용 태양 열매30개는 검 교환용과 나눈다. 군비증강과 검2자루를 모두 새로 준비하면 총50개다. 이미 보유·납품한 몫은 뺀다.
- 한국어 이름 정정으로 교환이 열렸거나 실제 재료를 보유한 것으로 기록하지 않는다.

## 근거

1. 사용자 직접 관찰: 2026-11-05 현재 대화에서 발레리 협곡의 한국어 채집 목록4종을 보고하고 이름 조사·정정을 요청했다. 이는 채집 가능 목록이며 실제 수집·보유 수량 보고가 아니다.
2. [Yu Phas’ Temple 발레리 협곡](https://yuphastemple.com/map/valeri-gorge/): 원문 채집 목록은 Linaria·Thry Fruit·Melara·Liganet이다. 사용자 목록의 네 품목과 대응한다.
3. [한국어 팬 도감의 태양 열매](https://fire-emblem-fortunes-weave.turam.dev/ko/entry/thry-fruit/): 같은 항목 주소 `thry-fruit`를 한국어 태양 열매로 표시하고 발레리 협곡을 입수처로 적는다. 공식 한국어 용어집은 아니며, 사용자 게임 화면 보고를 함께 근거로 삼는다. 영문 팬 도감의 자료를 다시 사용했을 수 있어 여러 독립 플레이 근거로 세지 않는다.
4. [GameWith サンノミ](https://gamewith.jp/fefw/578035): 선더 소드는サンノミ10·ユナメイ1을 요구하고, 같은 열매30개가7장 군비증강 납품품이라고 명시한다. 해당 표는 교환을1부8장으로 표시한다.
5. [Game8 ユナメイ](https://game8.jp/fe-banshisenko/817018): 다마센 곶 입수와 선더 소드의サンノミ10·ユナメイ1 교환을 대조했다. 외국어 이름으로 한국어 표기를 추측하지 않는다.

## 적용과 확인 범위

현재 데이터·루트 안내·참고 목록·교환 문서·생성 도구는 태양 열매로 맞춘다. `AGENTS.md`의 한국어 이름 사용 금지 문장은 폐기하고 실제 한국어 이름을 우선하는 규칙으로 고친다. 과거 보관본·대조용 기준 파일의 원문은 이력으로 보존하며 이 문서가 이름 판단을 대체한다.

Codex/Windows에서 인터넷 원문과 사용자 보고를 대조했다. 게임을 직접 실행하거나 한국어 게임 화면을 새로 촬영한 것은 아니다. 새 수집·납품·검 교환 완료를 추정하지 않으며 체크ID·이전 완료 연결·저장값을 보존한다. 실제 파일·화면 검사 결과는 작업 계획의 완료 기록에 덧붙인다.
