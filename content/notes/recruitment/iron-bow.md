# 철의 활 · 영입 물품

## 세오도라 1부

**누조 영입용 — 디트리히 2개 · 세오도라/레다/카이 3개**

| 출발 전 확인 | 내용 |
|---|---|
| 교섭 조건 | 지원1 · 명성6 |
| 선확보 | 가능. 일반 물품이며 지도·판매·재배 해금은 별도. |
| 획득 | 구입 · 무기점 |
| 장소 | 제도 다그시온 (Dagsion) 무기점 |

### 따라하기

1. 제도 다그시온 무기점에서 철의 활 재고를 확인한다. 모자라면 해당 장의 다른 상점·행상인 재고도 확인한다.
2. 철의 활 디트리히 2개 · 세오도라/레다/카이 3개를 누조 교섭용으로 남긴다. 강화품 대신 화면에서 요구하는 기본 무기를 준비한다.
3. 누조의 해당 루트 명성·지원 조건도 함께 준비한다. 무기 수량만으로 바로 영입되는 것은 아니다.
4. 선더 소드 소지품을 노리면 준비와 영입 시점을 구별한다. 12장 무렵 영입 직전에 식사 화면 등에서 실제 소지품을 확인한다.

### 위치와 지도

[세오도라 지도 열기](https://game8.co/games/Fire-Emblem-Fortunes-Weave/archives/624208 "recruit-map:iron-bow:theodora")

![철의 활 위치 참고](../../assets/recruitment/dagsion-location.jpg)

Game8 지도에서 확인한 제도 다그시온. 핀의 무기점 목록에 Iron Bow가 표시된다. 지도 그림은 레다 루트의 위치 예시이며, 지도 열기 버튼은 선택한 인물의 루트로 연결한다.

### 주의

행상인은 시점에 따라 위치가 바뀌므로 고정 핀 한 곳에서 반드시 살 수 있다고 계산하지 않는다. 10/24 출발 전에 보고하고, 화면 기한이 더 이르면 그 기한을 우선한다.
