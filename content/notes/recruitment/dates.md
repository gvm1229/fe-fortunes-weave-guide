# 대추야자 · 영입 물품

## 세오도라 1부

**하르빈 영입용 — 10개**

| 출발 전 확인 | 내용 |
|---|---|
| 교섭 조건 | 지원3 · 명성7 |
| 선확보 | 가능. 일반 물품이며 지도·판매·재배 해금은 별도. |
| 획득 | 일반 물품 · 선확보 가능(지도·상점 해금 필요) |
| 장소 | 바이나 오아시스·탈보스 지역 |

### 따라하기

1. 일반 상점·채집·재배로 대추야자10개를 남긴다. 카이는8장 ‘털북숭이 거대한 짐승’ 보상으로 씨앗을 얻은 뒤 재배하는 현재 기본안을 따른다.
2. 재료가 준비되면 해당 주인공과의 지원·명성·기타 선행 조건을 맞추고 스카우트한다.
3. 요구 수량을 전달하고 실제 합류를 확인한다.
