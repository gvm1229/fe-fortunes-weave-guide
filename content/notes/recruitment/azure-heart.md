# 푸른 심장 · 영입 물품

## 세오도라 1부

**올림피아 영입용 — 1개**

| 출발 전 확인 | 내용 |
|---|---|
| 교섭 조건 | 지원3 · 명성9 |
| 선확보 | 수주 전 입수 불가. 해당 의뢰의 진행 중 표시부터 확인. |
| 획득 | 전용 의뢰 진행 중에만 · 탐색 |
| 장소 | 벽정 동굴(Azure Crystal Cave) |

### 따라하기

1. 세오도라와 올림피아의 지원3·명성9을 맞춘다. 첫 선물로 스카우트 메뉴를 연다.
2. 앞 의뢰2를 보고하고 올림피아에게 말을 걸어 스카우트에서 ‘올림피아의 의뢰3’를 수락하고 의뢰 목록의 진행 중 표시·기한을 확인한다.
3. 의뢰3 진행 중 벽정 동굴(Azure Crystal Cave)의 목적지 표시를 따라 탐색해 푸른 심장1개를 얻는다.
4. 제도로 돌아와 올림피아에게 납품·보고한다. 실제 합류를 확인한다.

### 위치와 지도

[지도 열기 · 세오도라 선택 후 Azure Crystal Cave 검색](https://game8.co/games/Fire-Emblem-Fortunes-Weave/archives/624208 "recruit-map:azure-heart:theodora")

![푸른 심장 위치 참고](../../assets/recruitment/azure-crystal-map.jpg)

해당 목적지의 실제 게임 지도. 그림의 날짜·레벨은 사용자 상태가 아닌 위치 참고다.

### 주의

조건을 맞추기만 하거나 단순 대화로는 수주되지 않는다. 스카우트에서 의뢰를 받고 진행 중 표시부터 확인한다. 10/24 출발 전에 보고하고, 화면 기한이 더 이르면 그 기한을 우선한다.
