## 세오도라 1부

**리네 영입용 — 1마리**

| 출발 전 확인 | 내용 |
|---|---|
| 교섭 조건 | 지원3 · 명성6 |
| 선확보 | 가능. 일반 물품이며 지도·판매·재배 해금은 별도. |
| 획득 | 채집 · 물고기 탐색 |
| 장소 | 사베일론의 브론테스호 (Lake Brontes) |

### 따라하기

1. 브론테스 호수에서 일반 탐색으로 반짝반짝어1마리를 미리 확보한다. 확정1회 획득으로 계산하지 않는다.
2. 현재 루트의 명성·지원과 첫 선물을 준비하고 리네에게 스카우트를 선택한다.
3. 반짝반짝어1마리를 영입에 사용하고 실제 합류를 확인한다.

## 카이 1부

**리네 영입용 — 1마리**

| 출발 전 확인 | 내용 |
|---|---|
| 교섭 조건 | 지원3 · 명성6 |
| 선확보 | 가능. 일반 물품이며 지도·판매·재배 해금은 별도. |
| 획득 | 채집 · 물고기 탐색 |
| 장소 | 사베일론의 브론테스호 (Lake Brontes) |

### 따라하기

1. 이미 열린 이동 기능과 역을 이용해 사베일론으로 들어간다. 살라키아역을 사용할 수 있다면 브론테스호를 목표로 잡는다.
2. 물고기 탐색 핀에서 탐색한다. 한 번에 반드시 나오는 물고기가 아니므로 보유량을 확인하며 반복한다.
3. 반짝반짝어 1마리가 생기면 리네 교섭용으로 따로 남긴다. 식사나 카이의 포획 먹이로 쓰지 않는다.
4. 리네의 요구 명성·지원도 함께 채운 뒤 교섭한다. 물고기만 있다고 영입 조건이 모두 끝난 것은 아니다.
