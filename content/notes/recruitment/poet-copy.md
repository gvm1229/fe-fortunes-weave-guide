# 시인의 비문 사본 · 영입 물품

## 세오도라 1부

**시로코 영입용 — 1개**

| 출발 전 확인 | 내용 |
|---|---|
| 교섭 조건 | 지원1 · 명성5 |
| 선확보 | 수주 전 입수 불가. 해당 의뢰의 진행 중 표시부터 확인. |
| 획득 | 의뢰 수주 중에만 · 지정 지점 탐색 |
| 장소 | 솔리다스의 아트라 산맥 (지도 이름 Atla Peak) |

### 따라하기

1. 세오도라와 시로코의 지원1·명성5을 맞춘다. 첫 선물로 스카우트 메뉴를 연다.
2. 시로코에게 말을 걸어 스카우트에서 ‘시로코의 의뢰’를 수락하고 의뢰 목록의 진행 중 표시·기한을 확인한다.
3. 카르토도역→야시로 요새 탐색→이아페토스 대동굴의 다른 출구→아트라 산맥에서 사본1개를 탐색한다. 이미 열린 길은 다시 열지 않는다.
4. 제도로 돌아와 시로코에게 납품·보고한다. 실제 합류를 확인한다.

### 위치와 지도

[세오도라 지도 열기](https://game8.co/games/Fire-Emblem-Fortunes-Weave/archives/624208 "recruit-map:poet-copy:theodora")

![시인의 비문 사본 위치 참고](../../assets/guide/atla-route.webp)

Game8 일문 공략의 실제 이동 그림. 오른쪽 카르토도역에서 이아페토스 대동굴을 거쳐 왼쪽 아트라 산맥으로 간다.

### 주의

수주 전 선채집 불가. 명성·지원만 맞추고 출발해도 나오지 않는다. 권장Lv33 지역이므로 리네·단테와 전력이 준비된 뒤 간다. 다른 루트의 공통 의뢰 완료만 보고 이 영입 의뢰·사본을 건너뛰지 않는다. 비석/비문 사본은 같은 영입 물품의 표기 차이다. 10/24 출발 전에 보고하고, 화면 기한이 더 이르면 그 기한을 우선한다.

## 레다 1부

이 루트는 자동 합류라 이 영입 재료가 필요 없다.
