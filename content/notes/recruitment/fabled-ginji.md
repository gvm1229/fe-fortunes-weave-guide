# 환상의 긴지 · 영입 물품

## 세오도라 1부

**피터르 영입용 — 1개**

| 출발 전 확인 | 내용 |
|---|---|
| 교섭 조건 | 지원3 · 명성7 |
| 선확보 | 수주 전 입수 불가. 해당 의뢰의 진행 중 표시부터 확인. |
| 획득 | 전용 의뢰 진행 중에만 · 탐색 |
| 장소 | 아이기나 산(Mount Aegina) · 우르카역 |

### 따라하기

1. 세오도라와 피터르의 지원3·명성7을 맞춘다. 첫 선물로 스카우트 메뉴를 연다.
2. 피터르에게 말을 걸어 스카우트에서 ‘피터르의 의뢰’를 수락하고 의뢰 목록의 진행 중 표시·기한을 확인한다.
3. 동아말테아역→우르카역→아이기나 산(Mount Aegina)에서 의뢰 진행 중에만 환상의 긴지1개를 탐색한다. 우르카역 자체에서 탐색하지 않는다.
4. 제도로 돌아와 피터르에게 납품·보고한다. 실제 합류를 확인한다.

### 위치와 지도

![환상의 긴지 위치 참고](../../assets/recruitment/aegina-map.png)

해당 목적지의 실제 게임 지도. 그림의 날짜·레벨은 사용자 상태가 아닌 위치 참고다.

### 주의

조건을 맞추기만 하거나 단순 대화로는 수주되지 않는다. 스카우트에서 의뢰를 받고 진행 중 표시부터 확인한다. 10/24 출발 전에 보고하고, 화면 기한이 더 이르면 그 기한을 우선한다.
