# 3부 합류자 비교 · 별도 제안

1. 로컬 원문과 공개 출처로 타리문·아나톨리아·오르헬·베르트랑의 합류 시점·조건·사용 가능 여부를 확인한다.
2. Aswan·Hong Hua·Troy와 다른 후기 합류자를 함께 검토한다.2부 게스트 출전과3부 정식 사용을 구분하고, 합류 시 능력을 모르면 임의로 채우지 않는다.
3. 현재 승인25명과 네 진영장 포함25명,3부 후보 전체 재선정25명을 비교하는 별도 HTML을 만든다. 희망4명·여성 우선·비선호7명·병종/무기 호환·춤2명·회복 분담·신장직1명 제한을 지킨다.
4. 각 교체의 이득·잃는 역할·준비·근거를 표시하고 화면과 인원·자원 조건을 확인한다.
5. 기존 개인화·편성·체크·현재 비교안은 변경하지 않는다. 새 비교안은 승인 전 제안이다.
