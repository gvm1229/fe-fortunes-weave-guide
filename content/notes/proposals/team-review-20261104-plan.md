# 팀 비교 제안 · 작업 범위

1. 로컬 루트 추천·현재 개인화 편성과 Game8 지정 원문을 대조한다.
2. 영입 시기·루트 고유·역할 겹침·출격 정원·희망4명을 기준으로 변경안을 고른다.
3. 초상화와 유지/추가/제외 이유가 있는 별도 HTML을 만들고 화면으로 확인해 사용자에게 연다.
4. 기존 공략·편성 정본·체크는 수정하지 않는다. 승인 후 적용할 사항과 남길 사항을 구분한다.

## 완료 확인

- 여성 선호와 지양5명, 레다만 올림피아, 일반 남성 활용을 제안 명단에 반영했다.
- 3부 확보37명·2부 육성 배분33명·최종25명 예시와 예비를 대조했다.
- Windows Chrome의 넓은 화면과 작은 화면에서 탭·교체 필터·이미지를 확인했다.
- 기존 공략·편성 정본·체크 등10개 파일의 SHA256이 작업 전과 같다.
- 실제 게임 상태·실전 성장 결과는 검증 대상이 아니다.
