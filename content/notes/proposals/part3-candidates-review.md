# 3부 후기 합류자 · 별도 25인 비교 제안

- 범위: current-project. 별도 HTML과 제안 자료만 작성. 개인화·현재 편성·진행 체크는 미적용.
- 날짜: 2026-11-04. 사용자의 실제 게임 진행은 새로 보고되지 않았다.
- 화면: `show-me-part3-candidates.html`. 자료: `part3-candidates.json`. 생성: `tools/build_part3_comparison.py`.

## 확인한 사실

1. 베르트랑·타리문·아나톨리아·오르헬은 각각 1부 외전 완료를 조건으로 3부 합류한다. 로컬 도감·Game8는 1구간으로 묶지만, 로컬 `part3.html`의 상세 일정은 게스트와 정식 합류를 구별한다. 이 비교는 베르트랑·타리문을 1구간 후반, 아나톨리아·오르헬을 2구간 정식 편성으로 보수적으로 안내한다. 1구간 처음부터 전원을 자유 배치할 수 있다고 쓰지 않았다.
2. 홍화·트로이아는 서막에서 먼저 등장한다. ‘작품 전체에서 3부 첫 등장’이 아니라 ‘네 주인공 1·2부의 일반 스카우트 대상이 아니며 3부에 다시 사용’으로 표현한다. 로컬 성별은 둘 다 여성이다.
3. 아스완·타호니아는 2부 3장 게스트 생존을 준비하고 3부 5구간 합류한다. Game8 아스완의 카이/레다 완료 요구는 추정 표현이므로 확정으로 승격하지 않는다. 사용자는 네 루트를 모두 할 계획이다.
4. 센트리온은 2구간 구출 의뢰 뒤 다그시온에서 직접 대화한다. 백마술 C 레스큐 후보지만 백마법 사용 병종이 별도로 필요하다. 피해 반감은 적 턴의 첫 전투에 한정된다.
5. Klapka도 후기 검토 대상이다. Game8는 세오도라 루트 완료·5구간 생존과 가디언 고정을 안내한다. 다른 모집 자료는 6구간 정식 편성으로 표기해 경계가 상충한다. 정식 명단을 확인하도록 쓰고 최종 25명에는 의존하지 않는다. 로컬 한국어 이름·초상화가 없어 다른 인물 사진을 붙이지 않았다.
6. 키릭·네이선은 이미 2부 영입 대상이므로 ‘3부 신등장’으로 묶지 않는다. 루트 고유 동료인 보나파르트·토비아스와 함께 실전 예비도 계속 보유한다.

## 제안의 선택

| 안             | 교체                                                                 | 판단                                                                         |
| -------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 현재           | 없음                                                                 | 후기 동료가 없어도 성립하는 기존 승인 구성                                   |
| 네 진영장 포함 | 미카엘라→베르트랑, 파비오→타리문, 울턴드→아나톨리아, 올림피아→오르헬 | 네 수장을 모두 쓰는 체험안. 기존 인물보다 모두 강하다는 판정이 아님          |
| 부담 적은 추천 | 울턴드→아나톨리아, 올림피아→오르헬, 피아나→홍화                      | 고유 마법·회복 방어·낮은 레스큐 기능 목표. 여성 선호와 기존 육성 보존을 우선 |
| 선택 체험      | 카타냐→트로이아, 이니오니→아스완                                     | 각 기본안 위에 독립 적용. 항상 25명을 유지                                   |

- 본대에서 빠져도 영입을 취소하거나 예비를 버리지 않는다. 특히 올림피아의 레다 자동 합류와 1·2부 활용은 유지한다.
- 추천안에서도 홍화의 백마술 B·실제 레스큐 사용 준비 전에는 피아나를 계속 쓴다. 오르헬의 리브로를 확인한 뒤 세 번째 원거리 회복 자리를 넘긴다.
- 트로이아는 Lv50 대공 전투 기술·격투 명중과 백마법이 차별점이다. 리브로는 A+가 필요하므로 즉시 힐러로 계산하지 않는다. 무우가 더 갓 핸드를 쓰므로 배틀 몽크 최종을 제안한다.
- 아스완은 활 명중+20이 장점이다. 이미 육성한 이니오니보다 실제 피해·공속·전투 기술이 낫거나 명중 문제를 해결할 때만 교체한다. 여성이라는 이유만으로 같은 여성 궁수를 자동으로 밀어내지는 않는다.
- 베르트랑은 배틀 마스터가 기본이며 S를 새로 만드는 과제를 요구하지 않는다. 디 이터널은 자격이 이미 준비됐을 때만 선택한다. 타리문은 파비오의 암흑마법·기존 마력을 잃는 교체이므로 실제 능력 비교가 필요하다.
- 신장직 중복 없음. 후기 인물에게 디 아바타르·더 갓 핸드·더 캘러미티를 추가 배정하지 않았다. 드루이드 백마법 불가, 발키리움 흑백 가능, 배틀 몽크 격투·백마법, 와이즈맨 도끼·격투·백마법을 로컬 manifest로 확인했다.
- 여성 여부는 영어 이름으로 추측하지 않고 로컬 도감에서 읽는다. 무우·울턴드·하르빈도 여성이다. 기본 현재/추천은 여성18명, 네 진영장 포함은17명. 희망4명과 비선호7명 배제는 모든 조합에서 유지한다.

## 미확인·비교 한계

- 사용자 3부 가입 수치·현재 기능·융합 후 능력은 아직 없다. 서막 기본 능력표를 3부 합류 실측값으로 복사하지 않았다.
- Game8의 일부 표는 기술/속도 열 및 추천 본문이 서로 달라 성장률 합계 순위를 만들지 않았다. 최종 판단은 고유 기능·현재 병종 호환·추가 훈련량 중심이다.
- 신장직 시험 선택 조건·가호·현재 재고·합류 후 실제 전투 예측창은 게임에서 확인해야 한다. 자료 대조는 하드 실전 검증과 다르다.
- 합류 구간·Klapka 경계의 출처 상충은 남겼다. 실제 도달 시 확인할 항목이지 현재 작업 전체의 장애는 아니다.
