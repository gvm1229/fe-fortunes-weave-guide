# 인물표 압축·전체 비교 출처 · 2026-11-06

1. 성장률·전투 이동·마스터 보상을 부별 짧은 비교표로 표시. 기존 병과 아이콘·무기/특성·상세 모달 유지
2. 각 병과의 인물별 이유·선택/유지·필수 조건·예외만 짧게 표시. 공통 선행/마스터/투자 규칙은 인물 상자에서 한 번만 표시. 자세한 기존 사실은 정본·근거 모달에 보존
3. 전체 비교에서만 진영장 작은 초상화+루트 이름을 역할 표시 바로 위에 배치. 일반 루트 모드에서는 공간까지 숨김
4. 목표 경로·편성·체크 보존과 전원 범위, 비교/일반/검색/부 전환, 모달·넓고 좁은 화면 확인. 새 게임 진행으로 기록하지 않음
