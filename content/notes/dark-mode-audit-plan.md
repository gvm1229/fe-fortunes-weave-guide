# 어두운 화면의 남은 색 검토 · 2026-11-06

1. 첨부의 경기병 표시를 재현하고, 기존 내용 CSS와 React 공통 색의 충돌을 찾는다.
2. 개인화 공략의 모든 루트·부별 인물·준비·재료, 팀 구성·비교·백마법, 연결 문서 모달의 색을 점검한다. 원본 게임 그림의 색과 화면의 배경·글자색을 구별한다.
3. 밝은 배경·낮은 대비·옛 색이 남은 공통 요소를 같은 색 변수로 고친다. 게임 내용·배치·필터·체크는 바꾸지 않는다. 원본 보관 HTML의 구조를 고치지 않는다.
4. 새 묶음을 만들고 Windows 브라우저에서 실제 색·대비와 밝은 화면을 함께 검증한다. 글꼴·내용·진행 정본 보존을 확인하고 결과·한계를 기록한다.

범위: 현재 프로젝트만. Hive·전역 지식·외부 게시·실제 체크 조작 없음.


## 완료

고정 색733개 선언을 공통 어두운 색에 연결했다. 인물61판의 전 부·18개 진행 보기·팀·주요 모달과 밝은 화면을 확인했다. [결과와 검증 한계](dark-mode-audit-review.md)를 따른다. 내용과 배치는 유지하며 남은 에이전트 소유 작업은 없다.
