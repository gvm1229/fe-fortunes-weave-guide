# 현재 편성과 난사 투자 비교 · 2026-11-05

범위: current-project. Windows의 Codex에서 현재 정본을 읽고 공개 자료를 대조했다. 게임 실행·피해 실측·현재 궁술 수치 확인은 하지 않았다. 추천이며 편성·훈련·체크·실제 진행의 변경 승인이 아니다.

## 결론

기존 병종과 최종25명을 그대로 유지한다면 난사를 필수 훈련으로 추가하지 않는다. 난사를 시험하고 싶고 병종 변경도 받아들인다면 세오도라의 토비아스가 우선 후보다. 단, 궁술A와 활 병종·명중 보완을 추가해야 하므로 부담이 없는 선택은 아니다. 현재5장이라는 최신 진행을 기준으로 검토했으며 실제 기능 등급은 미확인이다.

## 비교

| 인물 | 현재 계획 | 추가 준비·잃는 역할 | 판단 |
|---|---|---|---|
| 토비아스 | 도끼B→A, 워리어→배틀 마스터, 3부 실전 예비 | 궁술A·활 병종 자격·명중 보완. 배틀 마스터에서 활 사용 불가. 궁수로 전환하면 근접 도끼 역할을 바꿈 | 난사를 직접 써볼 경우1순위. 힘 성장60%·전투기술 공격력+3과 어울림. 3부25명에 자동 편입하지 않고 실제 출격 자리가 있을 때만 준비 |
| 디트리히 | 검B→A→S, 사도→더 블레이드 | 궁술A·활 병종 추가. 더 블레이드는 검·창만 사용. 난사를 쓰는 전투에서는 검 신장직을 내려놓아야 함 | 기술 성장60%로 명중 잠재력은 좋지만 검 주력과 고유 역할을 유지하는 현재 계획에서는 후순위 |
| 로레타 | 세오도라 검A, 카이 창·비행, 최종 성천익병 | 이미 분담한 기능 외 궁술A·활 병종 추가. 성천익병은 검·창만 사용하므로 난사 사용 시 비행 역할을 바꿈 | 기존 경로 유지. 난사만 보고 세 번째 무기 훈련을 추가하지 않음 |
| 올림피아 | 백마술B→A, 비숍→와이즈맨, 원거리 회복 | 궁술A·활 병종·물리 화력 보완. 와이즈맨은 활 불가. 활 병종의 백마법 가능 여부를 따로 확인해야 하며 회복 역할을 그대로 보존한다고 가정하지 않음 | 기존 회복 담당 유지 |

기본 궁수 하르빈·피터르·이니오니·우술라는 난사 습득표에 없다. 활A 달성만으로 누구나 배우지 않는다. 지양 명단의 키로이카·밴디츠·자코네·대도를 이 기술 때문에 새로 육성하도록 권하지 않는다. 페페는 현재 승인된 최종25명·주요 육성 경로 밖이므로 신규 투자 대상으로 먼저 추가하지 않는다. 오르헬은 앞 조사에서 습득표가 충돌해 제외했다.

## 부담을 줄이는 방법

토비아스의 실제 궁술·보유 자격을 먼저 확인한다. 궁술이 낮으면 바로A를 요구하지 않고 현재 도끼 역할을 유지한다. 난사를 원할 때만 궁수 전환안을 고르며, 명중 보완은 해당 활 병종의 효과와 전투 예측을 보고 필요한 만큼만 준비한다. 초급부터 모든 궁수 병종 시험·마스터를 반복할 필요는 없다. 같은 기능을 여러 루트판에 반복 준비하지 않는다. 현재 궁술 수치·훈련 경험치·보유 증서가 없어 정확한 횟수·비용·완성 장은 계산하지 않았다.

## 근거

- 현재 편성: `data/final-roster.json`의 final25Example, `notes/knowledge/final25-targets.md`, `personalized-team.html`의 baseline 및 표시 인물.
- 부별 병종·훈련: `data/phase-goals.json`, `data/training-priorities.json`. 사용 무기: `assets/classes/manifest.json`의 weapons. 과거 characters.html 경로를 최신 편성보다 우선하지 않았다.
- [토비아스의 힘 성장·전투기술 공격력+3·궁술A 난사](https://yuphastemple.com/tobias/), [디트리히의 기술 성장·궁술A 난사](https://yuphastemple.com/dietrich/), [로레타 습득표](https://yuphastemple.com/loretta/).
- [토비아스 궁수 육성의 직접 플레이 기록](https://note.com/yaoya_neko/n/n41f1ba1d1bcf): 궁수로 처음부터 육성한 사례다. 현재 도끼 경로에서 궁술을 추가하는 비용·동일 결과를 증명하지 않는다. 토비아스 항목만 근거로 쓰며 후반 이야기 내용은 답변에 옮기지 않는다.
- [더 블레이드](https://annasnotebook.net/ja/classes/the-blade/), [성천익병](https://annasnotebook.net/ja/classes/celestial-trooper/)의 무기를 재대조했다. Game8 영어 병종4개 페이지는 이번 열기에서402로 실패해 새 원문 확인 근거로 세지 않는다. 배틀 마스터·와이즈맨의 무기는 기존 로컬 수집 정본을 사용했다.

## 도구 갱신 결과

사용자 요청에 따라 프로젝트 밖 사용자 전역 Agent Reach1.5.0을 공식 GitHub 배포본1.6.1·uv 방식으로 갱신했다. 일반 명령의 version 결과1.6.1·uv를 확인했고 setup은 기본5개 준비 성공·추가 사용자 조치 없음으로 반환했다. Codex용 skill도 공식 skill link 명령으로 최신 정본과 맞췄으며 두 파일 해시가 같다. 공개 예제 페이지의 실제 본문 읽기를 확인했다. 다른 플랫폼 검색·로그인·댓글·자막 전체는 실행하지 않았으므로 작동을 보장하지 않는다. 전역 Hive 지식·색인은 실행·수정하지 않았다.

이번 발화는 갱신 실행 요청과 조언 질문이며 새 지속 선호로 만들지 않았다. 이미 기록된 기존 병종·무기·훈련 부담을 함께 고려하는 방식을 적용했다.
