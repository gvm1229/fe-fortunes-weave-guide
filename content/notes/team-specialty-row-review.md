# 특기 행·4열 화면 보완

완료:2026-11-06 · Windows · 현재 프로젝트만

## 표시

- 카드 순서:무기→설명→특기→핵심 백마술. 실제 라벨 **무기**·**특기**로 같은 아이콘의 뜻 구분
- 확인된 모든 특기를 가로 아이콘 행으로 표시. 지휘·보병·기마·비행 등도 포함. 아스완은 자료상 특기 미표기로 유지
- 기본1920×1080:6:4 분할·왼쪽4열. 무기·특기 아이콘 옆 이름 유지. 얼굴80×96과 항목별 간격으로 밀도 조정
- 참고 영역 숨긴1920×1080:5열×5행. 아이콘만 표시하되 무기·특기 라벨과 접근 가능한 이름 유지
- 한눈 보기의 중복 큰 제목 행을 줄여 특기 행 공간 확보. 참고 표시 버튼은 고정 상단에서 계속 사용
- 오른쪽 안내·이동 버튼도 채움 색과 읽을 수 있는 글자색으로 통일

## 자료·생성

- `data/team-specialty-sources.json`의 확인된 특기 재사용. 새로운 게임 규칙 조사·명단/병과 재선정은 이번 범위에 없음
- `tools/team_specialties.py`에서 기능 순서대로 아이콘 자료 구성
- `tools/build_personalized_team.py`·`tools/team_page.py`에서 행·상단 버튼 생성
- `personalized-team.css`·`personalized-team.js`에서4열/5열 배치·표시 복원 처리
- 실제 과정 생성 도구와 진행 체크 저장 API는 실행하지 않음

## 검증

- 실행 환경:Windows Python·Chrome. `team-specialty-row-browser-validation.json`은 실제 화면 검사 기록
- 3개 비교안×체험 교체4가지=12개 조합. 기본4열은 이름 표시,5열은 아이콘 표시. 자료와 화면 특기 집합 일치·중복 인원 없음·행 순서·교체 카드만 굵은 강조 확인
- 1920×1080의12개5열 조합 모두25명 카드 가로/세로 넘침 없이 한 화면에 표시
- 숨기기 전후와 중앙 모달 닫기 뒤 명단·참고 양쪽 스크롤 위치 일치. 모달 중심960×540 확인
- 1440×900은3열,390×844는1열로 전환하며 이름 유지·카드 가로 넘침 없음. 휴대폰에서 두 참고 영역의 전체 내용을 한 화면에 표시한다는 뜻은 아님
- `tools/check_team_specialties.py`:36명 원자료·32명 이유·12개 편성의8신장직·정렬·아이콘 파일 확인
- `tools/check_fonts.py`:274HTML·글꼴9개 오류0
- `tools/check_guide_copy.py`:화면 문구12,479개·의미 예제10개·체크1,712ID 보존 확인
- 현재 작업 시작8개 진행/과정 정본의 비교는 `team-specialty-row-validation.json` 참조. 게임 저장 파일·실제 숙련·전투 성능을 확인한 검증은 아님
