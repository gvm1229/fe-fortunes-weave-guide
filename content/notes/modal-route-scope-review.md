# 모달 · 현재 루트와 부 기준

2026-11-04 · 입수처·재료·지원·육성·구매 참고의 표시 범위를 점검했다. 실제 획득·영입·시험·체크 완료를 바꾸는 작업이 아니다.

## 기본 표시

- 모달을 누른 버튼의 루트·부를 기준으로 표시한다. 인물 상자의 버튼은 선택한 인물의 루트판·부를 따른다.
- 내부 문서로 이동하거나 이전 문서로 돌아와도 같은 기준을 유지한다.
- 전체 비교는 사용자가 명시적으로 눌렀을 때만 펼친다. 모달을 닫고 다른 루트에서 새로 열면 현재 기준만 표시한다.
- 지도는 현재 보이는 구역의 루트를 따른다. 지도 버튼의 초기 예시 루트 이름이 본문 구역의 실제 루트를 덮지 않게 했다.

## 본문 행동은 유지

입수처 버튼은 추가 참고다. 날짜·장소·선행 대화·획득 행동·위치 그림과 실제 체크는 기존 본문에 남겨 둔다. 무기 이름의 본문 이동 연결도 유지한다. 비교표에서 본문 체크를 누르면 모달을 닫고 그 행동으로 간다.

## 적용 규칙

표의 ‘루트’·‘현재 로드’ 열, 인물의 루트판, 부 열과 구역 제목을 기준으로 주체를 표시한다. 다른 루트 이름이 문장에 나왔다고 무조건 지우지 않는다. 세오도라가 다음 로드 레다와 미리 식사하는 행은 세오도라의 행동이므로 그대로 둔다.

루트가 이미 지정된 구역의 주체는 안쪽 예시 지도 이름이나 비교 대상 이름보다 우선한다. 원문 자료는 삭제하지 않고 전체 비교에서 볼 수 있다. 실제 게임에서 확인되지 않은 판매 해금 장·새 영입 가능 조건을 추가하지 않는다.

정본은 `data/modal-scope-plan.json`, 작성과 구역 표시는 `tools/scoped_modal_docs.py`·`tools/modal_scope.py`, 표시 제어는 `personalized.js`다. 기존747체크ID·580행동과 체크JSON을 보존한다.

## 검증 범위

Windows Chrome에서 네 루트의 선더 소드, 디트리히/세오도라 철의 활 수량, 리네의 세오도라2부 목표,2부 지원·시험 후속 문서,3부 선더 소드를 확인했다. 전체 비교 후 다른 루트로 다시 열기·후속 문서·이전 문서·닫기 후 스크롤 보존도 확인했다.1440×1000과390×844 화면에서 중앙 정렬·가로 넘침을 확인했고 긴 지도 버튼은 줄바꿈한다.

전체 구조 검사와 대표 화면 확인이다.111문서의 모든 내용을 모든 화면 크기에서 눈으로 확인하거나 실제 게임에서 획득·전직·구매를 실행한 검사가 아니다. 수치·실행 범위와 화면은 `notes/modal-route-scope-validation.json`에 기록했다.
