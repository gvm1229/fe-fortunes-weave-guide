# 개인화 화면 최종 확인

2026-11-03 · 로컬 Windows · Chrome 및 Codex 인앱 브라우저. 현재 프로젝트만.

## 확인한 것

- 인물 표: 백마술 B·창 B 앞에 실제 기능 아이콘, 명성 8은 RGB(229,231,232) 회색 태그. 병종에는 실제 그림과 초급·중급·상급 구분. 지원·레벨·날짜·비용·파편과 준비 재료를 별도로 강조했다.
- 실제 Chrome 화면 폭 1440·390에서 가로 넘침 없음. 휴대폰 표는 병종·준비·선물·영입 머리칸과 내용을 세로로 나누고 병종 경로는 한 줄로 볼 수 있게 조정했다. 카이 표 15명이 좁은 화면에서 세로로 펼쳐짐을 확인했다.
- 고정 머리글 112px(넓은 화면)/136px(좁은 화면), 바로가기 목적지는 각각 약130/154px로 머리글 아래. 단계 선택은 해당 구역 하나만 표시하며 목록은 한 열. 지도 버튼 최소 높이44px.
- 93개 체크 ID 중복 없음. HTML ID·태그·상대 파일·그림 누락 없음. 아코디언0개, 그림75개, 표13개. 서식 도구를 다시 실행해도 파일 내용이 바뀌지 않는 것을 확인했다.
- 저장 도구 health와 checklist 응답 정상. JSON revision4·완료0개를 유지했다. 이전 실제 두 브라우저 체크/해제·새로고침·재시작 및 8개 저장 검사를 통과한 상태에서, 이번 표시 변경으로 체크 ID나 정본을 바꾸지 않았다. JavaScript 문법 검사도 통과했다.

- 병종·기능·지도 그림은 assets의 SOURCES와 manifest를 따른다. 공개 지도에서 검색·핀 표시만 확인했고 로그인·댓글·완료 표시를 하지 않았다.
- 인앱 브라우저의 화면 크기 강제 변경 뒤 캡처가 흐려져 최종 시각 증거는 실제 Chrome 캡처를 사용했다. Chrome의 영역 지정 캡처는 시간 초과가 나 전체 화면 캡처로 대체했다. 한 번의 본문 PageDown 자동 입력도 도구 오류로 실행되지 않아 그 입력의 성공을 주장하지 않는다. 일반 연결·단계 선택·위로 버튼·화면 계산은 별도로 확인했다.
- 위 검사는 공략 화면·파일 저장을 확인한다. 게임 버전1.1.0에서 전투·경험치 배율·능력 최적값·탈것 복사 개수를 재현한 것이 아니다. 무작위 채집을 포함한 모든 길의 최단 턴도 실측하지 않았다.

조사 도구 Agent Reach 확인 결과: 현재1.5.0, 업데이트1.6.1. 설치는 변경하지 않았다. 갱신 안내는 https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md 이다.
