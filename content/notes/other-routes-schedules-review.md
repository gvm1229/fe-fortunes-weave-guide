# 레다·디트리히·카이 · 선택 일정 날짜순 대조

확인일: 2026-11-05. 세 루트1부의 각 장을 플레이 기록·숨은 장면 자료·영문 달력과 대조했다. 실제 게임 진행이나 체크 완료를 새로 기록하지 않았다.

## 관전은 루트별 날짜를 따른다

| 루트 | 본문에 넣은 관전 | 귀환·참가 기준 |
|---|---|---|
| 레다 | 5장4/10,7장6/15,10장10/4,11장11/3 | 정오 전 귀환 → 당일 접수 위치·시각 확인 → 관전 |
| 디트리히 | 6장5/7,8장7/9·7/10,9장9/1·9/16,11장10/15 | 정오 전 귀환 → 관전.9/16 관전 뒤9/17 베르트랑 외전 기한을 함께 지킴 |
| 카이 | 5장3/21,6장5/7,7장6/15,10장9/16·9/27·10/4,12장11/4 | 각 날짜 귀환 → 접수 시각 확인 → 관전.10/4·11/4는 영문 달력에서 추가 확인했으며 정확한 시각은 현재 게임의 접수 표시를 확인 |

총17건이다. 같은 날짜라도 루트에 따라 직접 참가하는 메인 전투이거나 이야기로 지나가는 날일 수 있어 세오도라 날짜를 그대로 복사하지 않았다. 카이7/10은 자료에 관전 표시가 있지만 자유행동 표시가 없다.7장 마무리 전에 실제 가능 여부를 확인하는 조건부 체크를 따로 두었으며, 이야기로 넘어가는 날짜를 만들기 위해 재시작·숙박하지 않는다.

## 행사·공휴일은 종류를 구분한다

영문 달력에는 세 루트 모두4/24 스미르노스 행사일,5/11 칼라 행사일,6/14 포트나 행사일이 있다.9건을 각각 날짜별로 표시했다. ‘Golden Crow’s Rest Day’라는 공휴일도 각 루트의 자유행동 중 확인된7일씩21건을 표시했다.

총30일의 **달력 확인과 조건부 귀환·참가**다. 이 표시는 그날 별도 축제 퀘스트나 보상이 반드시 생긴다는 뜻이 아니다. 실제 참가할 행사·알현·대화가 표시돼 제도 방문이 필요하면 귀환하고, 참가 표시가 없으면 현재 위치에서 달력을 확인하는 것으로 마친다. 근거 없이 새 참가비·보상·퀘스트를 만들지 않는다. 한국어 정식 행사명·메뉴는 실제 게임 표시를 우선한다.

생일과 새로 보이는 선택 표시는 각 장 자유행동 시작의 달력 확인 체크에도 포함했다. 자료에 이름이 없거나 아직 만날 수 없는 사람을 임의로 채워 생일 선물을 강제하지 않는다.

## 선택 장면·선행 행동 수정

- 기존 장면 목록42건 중 세 루트에 해당하는20건을 본문 체크와 대조했다. 도구점·골목·이전 장의 대화·야간 조건이 메모에만 있지 않게 확인했다.
- 레다4장은 미카엘라 장면 → 실제 다른 행동으로1턴 경과 → 도구점 장면 순이다.6장의 알렉산드라 선행 대화·하층 후속을 월말 봉사 뒤에서 장 시작으로 앞당겼다.9장 시로코는 야간 첫 대화와 따라간 뒤 두 번째 대화를 각각 유지했다.
- 디트리히4장은 투기장 앞 미카엘라에게 먼저 말한 뒤 상점가로 간다.8장 야간 장면은 귀환 확인을 추가하고 마지막 기회까지 미루지 않는다.10장은5장 선행 확인 → 야간 귀환·첫 장면 → 통로 안쪽의 추가 표시 확인을 나눴다.12장 파비오·앤서러와 피나의 두 대화도 본문에 유지했다.
- 카이2장은 도적 추격을 선택해 갈렌 요새의 이야기를 확인하는 체크를 추가했다. **기존 북동쪽 계단 장면은 요새 내부가 아니라 다그시온 도착 뒤, 피터르에게 다음 이야기를 진행하기 전**으로 바로잡았다. 게임8은2장, 개인 기록은3장에 적지만 장소와 선행 순서는 같다. 같은 장면을 새 장면으로 중복 세지 않았다.
- 카이6장 벽화는 자유행동이 끝나 메인 진행으로 아므루에 들어갔을 때, 티아라가 안내한 방향을 먼저 조사한다.5/7 관전보다 앞에 놓여 자유행동 시작에 이미 할 수 있는 일처럼 보이던 위치를 고쳤다.

## 귀환·수락·참가를 날짜순으로 분리

- 디트리히9장:8월 준비 →9/1 관전 →9/2 레다 수락 →9/3 세오도라 수락 →9/16 귀환·관전 →9/17 베르트랑 완료 → 남은 제도 표시 확인 → 곤륜 출발. 타리문 두 번째 수주 체크는10/1로 옮겼다.
- 레다10~11장:10/4 관전 →10/5 아나톨리아 접수 →10/16 카이·디트리히 예약 →10/18 오르헬 예약 → 카이 실제 전투일 확인 →10/27 오르헬·11/1 디트리히 완료 →11/3 관전 →11/6 전 신상품4 귀환 보고다.
- 카이10~11장:9/16 관전 →9/17 베르트랑·타리문 접수 →9/24 안나 접수 →9/27·10/4 관전 →10/18 오르헬 접수 →10/21까지 완료다. 다른 루트의 긴 오르헬 기간과 섞지 않는다.
- 카이 외전은 자료에10/22 약속/기한과10/23 출발 표기가 함께 있어 기존10/22 우선 계획을 보존하면서 실제 의뢰창의 수락 마감·출발일을 구분하도록 했다. 아직 확인하지 않은 실제 출발일을 확정하지 않는다.

주간 봉사도 사이에서 나눠 날짜가 역행하지 않게 했다. 기존 봉사 행동ID·완료값은 보존한다. 카이의 기존 ‘첫 주·n번째 일요일’은 영문 달력의 참고 날짜와 연결했으며 현재 게임의 주차·미사용 여부가 우선이다. 날짜가 없는 여분 주차3개는 별도로 두고 실제 추가 일요일이 없으면 봉사를 만들지 않는다.

Windows·Codex에서 공개 원문과 팬 달력의 실제 브라우저 표시·생성 문서를 확인했다. 게임 실행, 모든 버전·난이도, 모든 생일의 실제 참가 가능 여부, 각 날짜의 접수 시간·보상 수치를 재현한 것은 아니다. 현재 게임 표시와 다르면 그 표시를 우선하며 자료의 체크를 실제 게임 완료로 바꾸지 않는다.
