# 팀 화면 4K 검토 결과 · 2026-11-06

대상은 요청한 로컬 팀 화면이다. Windows의 Codex·연결된 Chrome에서3840×2160으로 직접 열어 보고 수정했다. 실제 게임의 보유품·장착·훈련을 바꾼 작업은 아니다.

## 발견한 문제와 수정

1. **작은 그림:**4K에서도 무기·특기 아이콘이17px이었다.4K는40px, 상세 주요 무기는42px로 키웠다. 초상화는80×96에서152×181px, 이름은35px로 키웠다.1920 한눈 보기는22px, 휴대폰은26px 아이콘을 쓴다.
2. **서로 다른 무기 정보 혼합:**사용 가능 종류와 추천 품목이 한 행에 섞여 있었다. 두 보기 모두 ‘사용 가능 무기’와 ‘주요 무기’ 행을 별도로 만든다. 사용 가능은 최종 병과 manifest의 전체 종류를 쓰도록 고쳤다. 이전 목록에는 디트리히·그자람의 창, 카이의 검/도끼처럼 실제 허용 종류가 빠져 있었다. 육성 주력 목록은 별도 원자료에 보존했다.
3. **디트리히 추천 변경:**강화 앤서러는 유지하고 재계의 검을 사검 벨로키네로 교체했다. 한국어 이름과 검술B·도끼술C 조건은 [한국어 도감](https://fire-emblem-fortunes-weave.turam.dev/ko/entry/veroquine/)과 [Game8 상세](https://game8.jp/fe-banshisenko/819519)를 읽어 대조했다. 주보 조건도 함께 표시한다. 다른 인물의 재계의 검과 그 용도는 삭제하지 않았다. 모든 상황에서 무조건 우월하다는 전투 실측 결과로 바꾸지 않았다.
4. **카드 안의 큰 빈 공간:**화면 높이를5행으로 나눈 뒤 내용 크기를 그대로 두던 규칙이 원인이었다. 첫 카드 높이 약366px에 내용은 약135px이었다. 내용 높이의 행으로 바꾸고,4K에서는 전체 병과 이유와 큰 그림·글자를 쓴다. 상세 보기의 병과·경유도 얼굴 옆에 묶어 빈 자리를 사용한다. 서로 다른 내용량에 따른 행 안의 작은 높이 차이는 유지하며, 빈 공간을 채우기 위해 새 게임 사실을 만들지 않았다.

## 실제 확인한 범위

- **통과 —3840×2160:**기본4열과 한눈 보기5열, 밝은/어두운 화면. 한눈 보기에서25명 전체가 화면 안에 표시됐다. 카드 내용 잘림0, 무기 행 가로 넘침0. 카드 높이는 약295~348px이며 마지막 내용 뒤의 추가 빈 공간은 현재25명에서1~54px였다. 종전의 카드별 큰 강제 빈 높이를 제거했다. 격자 아래의 남는 화면 높이는 카드 내부로 분배하지 않는다.
- **통과 —1920×1080:**5열에서25인 전체가 보였다. 마지막 카드의 아래끝은 약1058px였다. 스크롤 높이825와 표시 높이824의1px 차이는 브라우저의 분수 좌표 반올림이며 내용은 잘리지 않았다.4K와 같은 큰 크기를 무조건 축소 적용한 것이 아니다.
- **통과 —390×844:**2열·26px 아이콘·각각의 무기 행 유지. 카드 자체의 잘림과 가로 넘침0, 페이지 바깥 넘침0.25명은 독립 스크롤로 읽는다.
- **통과 —정보 연결:**25개 카드 모두 두 무기 행이 분리되고 주요 품목2개가 표시됐다. 디트리히의 연결 설명 문서도 사검 벨로키네를 표시한다. 병과·문서 버튼의 기존 연결을 유지했다.
- **통과 —색:**새 상세 보기의 어두운 화면에서614개 보이는 글자 요소의 계산 대비를 확인해 지적0이었다. 그림 내부의 색·모든 마우스 상태·모든 문서의 대비를 전수 실측했다는 뜻은 아니다. 밝은 화면도 실제 그림으로 확인했다.
- **통과 —정본 검사:**32명의 대표2개·43개 품목과 그림·마법 학습 조건·12개 비교 조합의50개 배지 검사를 실행했다. 사용 가능 종류가 실제 최종 병과의 전체 종류와 같은지도 확인했다. 이는 자료 검사이며12개 모든 조합을 브라우저와 게임에서 각각 실행한 뜻이 아니다.
- **통과 —빌드·글꼴:**TypeScript와 최종 React 묶기 성공. 글꼴 검사 HTML283개·로컬 글꼴9개 오류0. 고정 색733개 연결 검사와 변경 파일의 Impeccable 정적 검사도 지적0이었다.
- **보존:**최종 편성·부별 목표·행동·공유 상태·구매 계획·전체 진행6개 정본은 작업 전 해시와 같다. 실제 체크 저장 API와 게임 체크박스를 조작하지 않았다. 사검의 실제 획득·장착 완료나 신규 훈련 완료로 기록하지 않았다.

화면 근거는 `team-4k-polish-browser.json`, 실제3840×2160 그림은 `screenshots/team-4k-after-dark.jpg`와 `screenshots/team-4k-detail-light.jpg`다. 다른 브라우저·모든 화면 배율·모든 비교안의 각 해상도 조합을 모두 검증하지는 않았다. 임시 창 크기는 확인 뒤 원래 크기로 돌렸다.

사용자가 정한4K 검토·큰 아이콘·공간 사용·무기 두 행·디트리히 품목 변경은 현재 프로젝트의 `notes/knowledge/team-results-page.md`에 기존 규칙을 고쳐 기록했다. 전역 지식·Hive·외부 서비스에는 기록하지 않았다.
