# 투기장 훈련 · 조를 고르는 순서

**미달인 육성 대상 + 해당 기능이 높은 스승**

![투기장 훈련 메뉴](../assets/guide/arena-training-menu.webp)

Game8의 실제 일본어 화면 예시 · 전투병 훈련의 검·도끼·격투 아이콘 확인 · 현재 저장의 메뉴·가격·인물 상태와 구별

## 다섯 종류

| 종류 | 오르는 기능 |
|---|---|
| 보병 | 검술·궁술·보병술 |
| 전투병 | 검술·도끼술·격투술 |
| 중갑병 | 창술·도끼술·중갑술·지휘술 |
| 마법병 | 흑마술·백마술·지휘술 |
| 기마·비행 | 창술·기마술·비행술·지휘술 |

위 표는 전체 선택지 · 이번 주 실제 메뉴에 열린 종류만 실행 · 종류별 주간 사용 여부·의욕·돈 확인 · 토·일 반값,일요일 갱신

## 따라하기

1. 해당 장의 주간 조표에서 이번 주에 열린 종류 확인
2. 왼쪽 육성자가 실제 합류했고 목표 기능 미달인지 확인 · 영입 전 인물은 훈련 불가
3. 오른쪽 상대의 **지금 기능** 비교 · 높은 쪽을 스승으로,낮은 쪽을 육성자로 사용
4. 목표 달성·미영입이면 다음 후보로 교대 · 둘 다 기능이 낮으면 두 명을 함께 육성
5. 훈련 결과로 목표 C/B를 채웠는지 확인 · 달성하면 다음 주는 다음 인물에게

시로코 세오도라판은 검·물리 보완 · 흑마 A는 레다 기준판에서 준비 · 늦게 영입한 최종25명도 출격 칸이 없다는 이유로 기능 훈련까지 중단하지 않음

## 공개 실측에서 확인한 범위

- 시설Lv·좋은 결과·기능 특기·동행자와의 등급 차이가 기술 경험치에 영향
- 낮은 기능 쪽에 차이 보너스 · 실측표는 반 단계4칸까지 증가하는 것으로 보고
- 기능 특기는 현재 병과와 별개 · 투기장에서 현재 병과로 사용할 수 없는 기능도 훈련 가능
- 시설Lv3 수치를 시설Lv1에 그대로 적용하지 않음 · 현재 명성·훈련 효과 확인
- 토비아스+녹투라 전투병 조의 낮은 결과 보고가 반복돼 기본 조에서 회피 · 모든 나쁜 결과의 원인을 확정한 것은 아님
- 같은 저장을 반복해서 Perfect를 보장한다는 설명은 댓글에서 정정·반론 존재 · 재시도 작업을 필수 일정으로 만들지 않음

## 여관과 구별

| 여관 행동 | 얻는 것 | 쓸 때 |
|---|---|---|
| 실전 | 레벨 경험치·병과 경험치 | Lv20 미만 따라잡기 · Lv20에 중급 전직 후 이어가기 |
| 훈련 | 기술 경험치·병과 경험치 | 레벨보다 C/B 기능이 부족한 교대 인물 |
| 탐색 | 골드·소재 | 준비 완료·보존 전용 동료 |
