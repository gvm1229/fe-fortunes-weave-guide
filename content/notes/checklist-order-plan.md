# 체크리스트 실행 순서 교정 · 2026-11-04

목표: 지금 할 행동이 실제 게임의 선행 조건 뒤에 나타나게 한다. 게임 진행·구매·체크 완료는 변경하지 않는다.

1. 네1부 루트의 축복 구매를 해당 루트 맨 위, 새1장 선택·EXP 점검보다 앞에 둔다.
2. 시작 전의 네 루트 동료 확보·알렉산드라 시험·첫2부 보존 묶음을 분해한다. 이오800G는 실제 교섭을 안내하는 장 직전, 알렉산드라 상급 보류는 해당 루트 영입 행동 바로 뒤, 비탑승 자격·보관은 각1부 종료 전/첫2부 반입 직전에 둔다. 지원 준비처럼 앞서 필요한 행동은 유지한다.
3. 네1부48장·2부·3부의 표시 순서를 대조한다. 영입 전 육성, 원정 전 재료, 날짜별 행동, 최종 동료 점검·주간 봉사보다 앞선1부 완료/다음 루트 선택을 확인한다. 새로 확인되지 않은 영입 날짜·명성은 만들지 않는다.
4. data/playbook.json과 직접 연결된 장별 동선·골드·시점 기록을 함께 맞춘다. 기존 체크ID·명시 체크값·옛 묶음 완료의 연결을 보존하며 새 행동에 옛 완료를 임의 상속하지 않는다.
5. 생성 후 네 루트 첫 블록, 영입→시험 보류, 비용 준비→지급, 종료 전 확인→완료→보상→다음 루트의 상대 순서를 검사한다. Windows 브라우저에서 실제 배열·체크 유지·참고 연결을 확인한다. 전역 지식·Hive는 사용하지 않는다.
