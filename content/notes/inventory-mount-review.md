# 첫 반입·인물 기록·전용 탈것 다시 검토

세오도라 → 레다 → 디트리히 재육성 → 카이 순으로 1부를 모두 끝내고 같은 순서로 2부를 직접 완료한다. 첫 세오도라 2부는 6장 완료 전 보관을 확인하고 이후 장착 자료를 등록한다. 아래는 이전 검토 이력이다. [현재 실행 기준](sequential-routes-apply-review.md), [첫 세오도라 보존](theodora-first-war-preservation.md)

## 새 결정

사용자는 옛 디트리히의 미등록 육성을 포기해도 괜찮다고 밝혔다. 새 장비와 특별 탈것 보존을 반드시 따르기를 원한다. 따라서 **옛 디트리히 2부 선스킵을 기본안에서 제외**한다. 세오도라 시작 전 축복 구매 → 세오도라 1부 → 레다 1부 → 디트리히 1부 하드·캐주얼 재육성 → 준비한 자료로 2부를 진행한다. 기존 디트리히 2부가 이미 완료됐다면 첫 일반 물품 묶음은 별도 분기를 따른다. [현재 이월·완료 상태 기준](carry-hard-review.md).

이전 안내는 옛 능력치를 먼저 지키는 선택의 비용은 적었지만, 사용자에게 중요한 새 물품·전용 탈것을 기본 순서에 충분히 반영하지 못했다. 특히 드라군 시험 권장은 아래의 자동 병종 배정 관찰과 충돌해 수정했다.

## 원문을 읽고 구분한 규칙

- [본문과 작성자의 10/8·10/11 답글](https://forums.serenesforest.net/topic/108432-functions-and-features-when-clearingreclearing-part-1-and-2-for-part-3/): 인물 능력 자료와 반입 물품은 별개다. 같은 루트의 재완료 능력 자료는 보완되지만, 일반 물품은 첫 2부 완료의 묶음이 고정된다. 골드는 높은 기록을 따로 반영한다. 장착 탈것·군단은 교체 갱신이라는 예외다.
- [2쪽](https://forums.serenesforest.net/topic/108432-functions-and-features-when-clearingreclearing-part-1-and-2-for-part-3/page/2/): 같은 루트의 재완료와 다른 주인공 루트판의 파편 300 융합을 구분한다. 3부 영입 후 일반 동료의 갱신에도 비용이 든다. 레벨도 높은 쪽으로 합쳐지므로 높은 레벨만으로 유리하다고 보장하지 않는다.
- [3쪽 Korath88의 10/22 관찰](https://forums.serenesforest.net/topic/108432-functions-and-features-when-clearingreclearing-part-1-and-2-for-part-3/page/3/): 상급 병종에 합격만 하고 현재 중급을 입어도 새 완료 자료가 상급으로 자동 배정될 수 있다. 기준 알렉산드라판은 **상급 시험 합격 자체를 보류**하는 안전한 일정으로 바꿨다. 단일 이용자의 후속 실측이며 사용자 버전에서 재현한 것은 아니다.
- [성궤 글](https://forums.serenesforest.net/topic/108421-drifting-reliquary-feature-for-part-3-part-1-item-catalog/): 늦게 얻은 물품의 목록·재구매는 첫 반입 묶음 무료 교체와 다르다. 전용 말 복사본은 원본과 설명이 다른 ‘형제/새끼’ 이름으로 바뀔 수 있다.

세 페이지의 본문·답글을 읽었다. 사진 주소는 직접 받으려 했으나 접근 오류가 나 도표를 읽었다고 주장하지 않는다. 연결된 실험 영상도 직접 재생·재현하지 않았다. 작성자의 결과, 다른 이용자의 관찰, 내가 선택한 안전한 준비 방법을 구별한다.

## 기존 능력치와 새 장비를 함께 살리는 대안의 한계

옛 12장 시작 부대를 불러와 그 장에서 구할 수 있는 장비를 추가하고 첫 2부를 완료하는 부분 보완은 가능하다. 그러나 현재 2부 군행동 후 수치를 새 1부와 그대로 섞는 무손실 기능은 아니다. 늦은 영입을 일찍 만들거나 놓친 9/17 외전을 회수하려면 더 앞에서 이어 진행해야 한다. 사용자가 원한 네 명 재육성과 새 물품 우선에는 새 1장 계획이 맞는다.

## 보존 절차를 어디에 반영했나

네 1부가 끝나면 세오도라 2부를 먼저 직접 완료해 스킵을 연다. 세오도라는 6장 첫 완료 전에 군단과 특별 탈것을 보관하고, 완료 뒤 장착 자료를 등록한다. 레다·새 디트리히·카이는 각 2부 1장에서 먼저 보관 상태로 스킵하고, 다시 시작해 재장착한 뒤 직접 완료한다. [세오도라 2부 체크](../personalized.html#theodora-war-plan), [레다 2부 체크](../personalized.html#leda-war-plan)

첫 1부 완료 전에 일반 물품·수송대를 준비하고, 2부 첫 완료 전에 실제 보관·병종·장착 상태를 다시 확인한다. 전용 탈것을 이미 가진 인물 자료를 능력 융합만으로 고칠 수 있다고 가정하지 않는다. 3부에서는 실제 마구간 개수·복사본 이름·인물의 장착 상태를 확인한다. 원문의 최대 복사 수를 사용자 저장에서 이미 달성한 결과로 쓰지 않는다.

후속 자동 상위 배정 관찰은 이오에게도 주의한다. 이미 상급 기병 자격이 있으면 낮은 병사로 바꾸는 것만으로 안심하지 않는다. 같은 등급의 비기병 자격을 준비해 완료하는 조건을 추가했다. 알렉산드라의 기준판 상급 합격 보류와는 다른 대비이며, 사용자 저장에서 자동 전직 결과를 재현했다는 뜻은 아니다.

## 화면과 저장

사용자는 초상화·정보 구역·상시 표시하는 행동 목록·대화형 체크 목록을 요청했다. HTML과 JavaScript를 유지하고 작은 Python 표준 라이브러리 서버를 추가했다. 체크 정본은 프로젝트의 `data/checklist.json`이다. `공략 열기.cmd`로 같은 컴퓨터의 로컬 주소를 열면 브라우저별 저장소와 관계없이 같은 JSON을 읽는다. 직접 파일 열기에서는 자동 파일 쓰기를 약속하지 않는다. React는 필요하지 않아 도입하지 않았다.

이 기록은 계획·도구 변경이다. 게임의 실제 완료·구입·재육성·파편 지출은 아직 없다.
