# 참고 문서 모달 · 2026-11-03

- 개인화의 지역 참고 연결 9개를 별도 중앙 모달로 연다. 편집 정본은 Markdown이며, 화면은 이미 만든 UTF-8 HTML의 본문만 불러온다. 서버나 별도 화면으로 이동하지 않는다.
- 문서 안 후속 참고도 같은 모달에서 연다. 이전 문서는 읽던 문서 위치로 돌아간다. 외부 출처와 일반 공략 연결은 새 탭을 사용해 기존 체크 화면을 유지한다.
- 열 때 모든 배경 스크롤 영역의 가로·세로 위치를 저장한다. 닫기·Escape 뒤 원래 초점과 위치를 복구하며 루트·검색·주소는 바꾸지 않는다. 시험 안내 위에서 연 경우에는 시험 안내도 그대로 남는다.
- 불러오는 중 표시, 실패 시 다시 불러오기, 닫을 때 요청 취소와 이전 요청 결과 무시를 구현했다. 배경 클릭 닫기도 구현했지만 이번 검증에서 오류 주입과 배경 좌표 클릭은 실조작하지 않았다.

## 실제 검증 범위

Windows의 Codex 앱 브라우저에서 체크 20995.5546875px·준비 1771.5555419921875px·인물 12999.111328125px에 둔 뒤, 보이는 링크를 클릭하고 문서 끝까지 읽어 닫았다. 세 위치·주소·루트·검색이 전후 동일했다. 키보드 PageDown 이동 중의 중간 수치는 비교 기준에서 제외하고, 정지한 뒤의 실제 클릭을 검증했다.

후속 경로 문서→이전 문서, 시험 안내 위 참고 문서→Escape→시험 안내 복귀도 확인했다. Chrome 1440×1000과 390×844에서 중앙 오차0px, 휴대폰 폭에서 가로 넘침0건이었다. 화면은 `screenshots/reference-reading-modal.jpg`, 수치는 `reference-reader-validation.json`이다.
