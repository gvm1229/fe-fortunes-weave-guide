# 루트 진행과 던전 육성 · 2026-11-12

## 진행 순서

1부 세오도라 → 레다 → 디트리히 재육성 → 카이. 네 1부를 모두 끝내면 같은 순서로 2부를 직접 완료한 뒤 3부로 간다.

레다 1부 첫 보상을 받은 뒤 보유한 병과 경험치 +1을 추가 2,000파편으로 +2까지 올린다. 방첨탑에서 해금과 실제 보유 단계를 확인한다. [축복 단계와 가격](https://annasnotebook.net/en/mechanics/bird-time/)

## 이야기 전투와 던전

- 이야기 출격은 실제 칸 확인 · 보통 진영장 외6~7명,최종전 무렵8명 · 완성 명단 전체가 매 전투에 들어간다고 전제하지 않음
- 현재 세오도라는 세오도라·보나파르트·토비아스·녹투라·릴리안·소피아 유지 · 새 동료 때문에 강제 교체하지 않음
- 1·3부에서 시험 권장 레벨에 가까운데 필수 기능 등급이 모자란 인물만 던전에서 보충한다. 필요한 등급에 닿으면 귀환해 시험을 확인한다. 기마술과 비행술은 훈련이나 지침서로 준비한다.
- 3부에서 장착할 마스터 스킬을 정했으면 해당 병과로 전직해 던전에서 마스터한다. 약한 무기로 피해를 주고 적을 살려 둔 채 늦어도 15라운드에 후퇴한다. 습득 표시가 뜨면 실전 병과로 돌아가 장착한다.
- 3부 4구간부터 신장직 자격은 병종마다 한 명에게 배정한다. 더 블레이드는 검술 S와 요도의 코등이가 필요하고, 마스터 보상은 Divine Insight(속도 +10)다. 다음 인물도 필요하면 자격을 반납하고 돌려받은 전용 아이템으로 그 인물이 시험을 본다. [더 블레이드](classes/the-blade.md), [신장직 자격과 마스터](https://annasnotebook.net/en/mechanics/strategy/salvation-five-teams/)
- 여관 실전은 자투리 턴/일정 조정 · 여관 훈련은 기능·병과 경험치 · 인물 레벨 경험치와 구별
- 출격/막타/MVP와 대기 경험치의 차이 고려 · 모든 동료 같은 레벨/매 장 모든 던전 순회를 필수화하지 않음
- 보존 인물은 추가 이야기/던전 경험치 배분 제외 · 초반 대체 인물은 본대가 실제 역할과 출격 칸을 채울 때 투자 중단 · 부를 바꾸면 해당 부의 출격 일정과 중단 기준 표시

## 2부 준비·군행동

1. 1부에서 중급/필수 기능을 준비한 실제 투입 후보부터 · 상급을1부에서 못 마쳤다고 망친 육성으로 단정하지 않음
2. 평준화 전 목표 성장 병과/탈것 확인 · 실제 상승 결과/예정치 보고 선택 · 전원 고정Lv35 보장 아님
3. Lv35 이상·필수 기능·시험100%인 미합격 자격에 상급 증서 최대5장 · 이미 합격한 사람과 실제 출격하지 않는 선택 예비는 중복 투자 제외
4. 2~4장은 실제 레벨 미달이면 평준화,필요 가호 미달이면 봉사,그 외 기능 보조 · 무작위 강화로 특정 B/A 보장 없음
5. 필요 기능/시험은4장까지 · 5~6장은 준비된 전력으로 전투 · 신장직/최상급은3부 목표와 구별
6. 각 루트 2부 완료 뒤 보상·파편·가호와 장착 자료를 확인하고 다음 2부로 간다. 카이 2부 뒤에는 3부 진입을 준비한다.

## 첫 반입과 장착 자료

첫 세오도라2부는 선스킵 없이 직접 진행 · [처음 직접 완료의 보존 절차](theodora-first-war-preservation.md) 참조 · 마지막 출격 전 군단/특별 탈것의 공용 보관을 확인한 뒤 완료 · 완료 후 같은2부1장 재장착/스킵으로 인물 자료 별도 등록

레다/디트리히/카이는 그 뒤 해금된 스킵으로 첫 보관→재장착→해당 루트2부 직접 완료 · 직접 완주는 유지하고 보관을 위한 스킵은 같은 루트 안의 별도 처리

일반 물품·인물 능력·장착 군단/탈것은 서로 다른 기록 · 첫 일반 물품 묶음이 이후 무료로 추가 갱신된다고 생각하지 않음
