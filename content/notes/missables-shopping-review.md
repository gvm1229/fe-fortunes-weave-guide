# 놓침·축복·무기 구매 대조

2026-11-04 · Game8 공유4문서, 물품37종 상세와 로컬 공략을 대조했다. 실제 게임 구매·시청·획득 완료를 뜻하지 않는다.

## 행동 위치

기한·장소가 있는 장면과 무기 확보는 개인화의 해당 장 체크를 따른다. 이 문서는 구매 판단·수량·조건을 비교할 때만 참고한다. 아래 입수 연결을 누르면 모달을 닫고 해당 체크로 이동한다.

## 놓침 구분

1. **기간·선행 조건:** 기한 의뢰·회수 보상·연속 대화는 장을 끝내기 전에 현재 루트 본문 체크에서 먼저 처리한다.
2. **선택 장면:** 장소·시간·선행 행동은 현재 루트의 장별 체크를 따른다. 체크 연결을 누르면 해당 행동으로 이동한다.
3. **관전·생일·행사:** 선택 콘텐츠와 작은 보상도 확인된 날짜·장소·선행 조건을 본문 실행 체크로 표시한다. 귀환 시간을 남겨 날짜순으로 진행한다. 이미 놓친 일이 있으면 회수 가능 여부를 따로 검토하며, 실제 놓침이 보고되지 않았는데 완료·누락을 추정하지 않는다.
4. **아직 안 본 지원:** 장을 넘기기 전에 현재 열려 있는 지원 대화 확인. 모든 지원 사슬의 개별 마감이 이4문서에 있는 것은 아니므로 전원A·대화100%를 보장하지 않는다.
5. **새 인연:** 영입할 대상에게 첫 선물1회가 필요할 때 먼저 인연을 연다. 대화 선택지 지원점과 장면 발동을 혼동해 모든 NPC에게 선물을 강제하지 않는다.
6. **축복 구매:** 공유·환불 불가. 구매 여부와 실제 적용 효과를 따로 확인.

## 상점에서 결정하는 순서

1. 현재 루트의 소지품·수송대 확인. 옛 디트리히의 무기를 새 루트 재고로 세지 않는다.
2. 필수 영입비·다음 시험비를 남긴다. 파편과 골드를 같은 돈으로 계산하지 않는다.
3. 담당자의 병종·요구 기능·사용 가능 표시와 장착 후 공격 속도를 본다.
4. 아래 목표 미달이면 구매, 이미 있으면 중복 구매 생략. 재고가 없으면 다음 진행으로.
5. 전용 무기·한정 보상은 평가가 낮아도 보관. 고급 무기 상자는 확정 무기 구매가 아니므로 반복 뽑기를 기본 과제로 삼지 않는다.
