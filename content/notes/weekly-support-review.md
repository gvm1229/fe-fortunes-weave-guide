# 주간 지원과 식사

현재 로드가 반드시 동석한다. 첫 인연용 선물1회 뒤 식사를 쓰고, 요구 지원을 채웠으면 다음 조로 넘긴다. 같은 로드와의 이월 지원을 다시 올리지 않는다. 지원 루프는 영입이 실제로 늦어질 때만 선택하며 카이 탈것 포획·먹이 뒤에는 장 재시작을 하지 않는다.

## 세오도라

| 시점 | 동석 인물 | 조건 |
|---|---|---|
| 현재7장 이후 · 남은 지원 준비 | 세오도라·우술라·루루디아 | 단테·리네·시로코·로레타는 이미 영입 완료라 추가 지원 준비 제외 · 우술라/루루디아는 실제 미영입·지원3 미달일 때만,등장·명성·선행 의뢰는 별도 |
| 후반 보존/확보 준비 | 세오도라·이오·누조 | 이오의 지원3이 미달이면 준비 · 누조 지원1이 이미 충분하면 이 자리는 다른 미달 대상 · 실제 영입 요구품/의뢰 확인 |

현재 남은 미영입 대상 지원2 이상 대기열: 우술라 지원3 → 루루디아 지원3 → 이오 지원3. 아직 활동 명단에 없는 사람은 등장까지 대기하고, 선택 영입은 쓰기로 정한 경우만 준비한다.

현재7장에 단테·리네·시로코·로레타 영입 완료 확인 · 같은 대상의 식사·선물 반복 없음 · 아직 등장하지 않은 사람은 명단에 뜰 때 준비

다음 로드 준비: 현재 영입 지원이 끝났고 두 사람이 식사 명단에 있을 때만. 레다–에스메랄다 지원 3을 미리 준비. 시로코는 레다 자동 합류라 선행 작업 불필요.

## 레다

| 시점 | 동석 인물 | 조건 |
|---|---|---|
| 초기부터 | 레다·에스메랄다·소피아 | 둘 다 지원3 · 각 의뢰와 합류 조건 확인 |
| 회복·기동 준비 | 레다·피아나·하르빈 | 둘 다 지원3 · 실제 출격 기능은 부별 목표만 |
| 탈것 보존 | 레다·알렉산드라·자스민 | 둘 다 지원3 · 전투 육성 대상과 보존·확보 대상 구별 |
| 확보 준비 | 레다·사란·이오 | 사란 지원3·이오 지원1 · 이미 요구 지원을 채운 자리는 다음 미달 대상에게 |

첫 다그시온부터 지원2 이상 대기열: 에스메랄다 지원3 → 소피아 지원3 → 피아나 지원3 → 하르빈 지원3 → 알렉산드라 지원3 → 자스민 지원2 → 사란 지원3. 아직 활동 명단에 없는 사람은 등장까지 대기하고, 선택 영입은 쓰기로 정한 경우만 준비한다.

다음 로드 준비: 디트리히–리네의 실제 이월 지원이 부족할 때만. 이미 지원3이면 다른 부족한 본대 조건으로 넘김.

## 디트리히

| 시점 | 동석 인물 | 조건 |
|---|---|---|
| 초기부터 | 디트리히·우술라·리네 | 둘 다 지원3 · 조건 충족 뒤 다음 조로 |
| 늦은 원격 회복 미리 준비 | 디트리히·소피아·피아나 | 둘 다 지원3 · 소피아 명성9를 기다리기 전부터 식사 · 피아나는 명성7·3,000G 합류 뒤 회복 |
| 회복·비행 준비 | 디트리히·피아나·알렉산드라 | 둘 다 지원3 · 피아나 명성7·3,000G · 알렉산드라 명성8 |
| 고유 동료 준비 | 디트리히·게이츠·이오 | 게이츠 지원3·이오 지원2 · 게이츠는12장 조건·베르트랑 외전 확인 |

첫 다그시온부터 지원2 이상 대기열: 이오 지원2 → 우술라 지원3 → 리네 지원3 → 알렉산드라 지원3 → 게이츠 지원3 → 피아나 지원3 → 단테 지원2 → 울턴드 지원3 → 제스터 지원3 → 소피아 지원3. 아직 활동 명단에 없는 사람은 등장까지 대기하고, 선택 영입은 쓰기로 정한 경우만 준비한다.

다음 로드 준비: 카이–미카엘라 지원 3이 부족할 때 유용. 두 사람이 식사 명단에 있으면 미리 준비해 카이 5장 영입·한혈마 육성을 늦추지 않음.
