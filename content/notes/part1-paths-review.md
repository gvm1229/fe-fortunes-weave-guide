# 1부 가입 후 목표 경로 표시

2026-11-03 · 현재 프로젝트만. 실제 게임 진행·영입·전직을 바꾼 기록이 아니다.

## 적용 기준

- 초급부터 육성하는 인물은 초급→중급→상급을 표시한다. 귀족·평민은 첫 추천 초급 전직부터 표시한다.
- 이미 중급으로 합류하면 그 중급→목표 상급만 표시한다. 상급 합류는 상급부터이며 초·중급으로 되돌리지 않는다.
- 도감 기본 병종과 실제 늦은 합류가 다를 수 있다. 실제 합류가 더 높으면 지나온 단계는 생략한다. 디트리히 리네는 사용자가 확인한 지난 경기병 합류를 기준으로 표시한다.
- 기본 병종에서 무기·마법 계통을 바꾸는 경우에는 필요한 초급 전환도 표시한다. 같은 계통의 초급은 불필요하게 바꾸지 않는다.
- 화살표는 초반 육성 흐름이다. 모든 병종을 마스터해야 다음 시험을 볼 수 있다는 뜻은 아니다. 이미 합격한 자격은 다시 응시하지 않는다.
- 알렉산드라는 전용 페가수스 보존 때문에 천익병을 유지하고 상급 시험을 보류한다. 이오의 바딩거는 선택이며, 상급을 택하면 첫 보관용 비탑승 상급도 확인한다.
- 카이 전차병3명·에스메랄다의 상급은 실전용 자격으로 구분한다. 레벨업은 전차병·기갑 타조병의 성장 목적을 유지한다.
- 수집 인물도 전투에 사용할 때의 경로를 보여 주지만, 수집만 하면 추가 육성·시험은 생략한다.

## 확인

Windows Python에서60판을 갱신했고 중급 이상 합류9판의 하위 등급 표시0건을 확인했다. 초급 입력은 주술사→샤먼→바테스, 중급 입력은 아처→스나이퍼, 상급 입력 예시는 바테스만 남았다. 상급 분기는 예시 입력의 로직 검사이며 특정 캐릭터의 실제1부 상급 합류를 새로 확정한 결과가 아니다.

기존 `data/roster-plan.json`·`data/recruitment-build-audit.json`·사용자 관찰과 대조했다. 외부 검색만으로 미확인 상급 합류 인물을 만들지 않았다. 2·3부 목표·운용·융합 데이터는 갱신 도구에서 동일성을 확인하며 보존했다.

Windows Chrome의 1440×1000에서 단테의 초급→중급→상급 아이콘·등급·시험 비용을 시각 확인했다. 866×1000에서도 페이지와 인물 영역의 가로 넘침은 없었다. 중급 리네·이오는 하위 병종이 나오지 않는 것을 확인했다. 실제 게임의 시험·성장 재현은 하지 않았다. 체크 정본의 SHA256이 작업 전과 동일하며 행동 440개·이전 체크 ID 93개를 유지했다. 검증 수치는 `part1-paths-validation.json`, 화면은 `screenshots/part1-class-paths.jpg`에 있다.
