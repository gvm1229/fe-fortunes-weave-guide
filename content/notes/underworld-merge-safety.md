# 명계의 문·유료 융합 준비

## 먼저 지킬 순서

1. 구간 재시작·지원 루프·기준판 변경 작업부터 종료
2. 전투 예고(Foresight)의 적 병종·출격 수·승리/패배 조건 확인
3. 실제 문 전투에 보낼 부대부터 편성
4. 부족한 능력/기능만 비교한 뒤 필요한 유료 융합 확정
5. 주력 부대를 문 위 또는 인접 지점에 모은 뒤 진입

## 재시작과300파편

| 항목 | 확인할 내용 |
| --- | --- |
| 일반 동료 유료 융합 | 추가 자료1개당300파편 ·2회600·3회900 |
| 기준판 선택 |3부 영입 시 사용할 자료를 먼저 선택 ·25명 전원에게300씩 내는 방식과 구별 |
| 주인공4명 | 카이·디트리히·세오도라·레다의 자동 융합은 무료 |
|3부 전용 동료 | 이스마르·홍화·트로이아·후기 진영장 등은1·2부의 다른 루트판을 합치는 대상과 구별 |
| 구간 재시작 | 해당 구간의 융합 결과가 되돌아가도 사용한 파편은 미환급이라는 반복 보고 |
| 수동 세이브·클라우드 | 지출 전으로 복구해 주는 안전장치라고 가정하지 않음 |

필요한 추가판 수를 N으로 정한 뒤 **300×N**만 예산으로 계산 · 작은 능력1~2점과 같은 역할의 중복판을 전부 합치는 작업은 선택 · 실제 증가 능력·새 기능/스킬·합쳐진 레벨을 확인한 뒤 결정

유료 융합 뒤 불리한 전투가 보여도 ‘구간 재시작’을 곧바로 선택하지 않기 · 전투 안의 되감기·가호·안전한 사거리부터 활용 · 진입 전에는 가능한 메뉴 범위에서 편성과 부대 위치 수정

## 어떤 전투인가

3부2구간부터 시작하는 **기한 있는 주요 전투** · 월드맵의 문 주변 장기를 정화한 뒤 진입 · 이후에는 여러 문을 나눠 공략하는 구간도 존재

- 탐색 부대의 위치가 실제 참전 후보를 결정
- 문 위나 인접 지점의 부대가 참가 대상 · 다른 곳의 강한 동료를 자동으로 전원 불러오는 구조가 아님
- 이스마르는 원정부대8명과 별도 · 다그시온에 남아도 전투에 참가 가능한 구세주 역할
- 보통9인 전투는 원정부대8명과 이스마르를 기준으로 준비 · 실제 출격 상한과 참가 명단은 배치창 우선
- 17인 허용 전투는8명 부대2개와 이스마르를 함께 준비 · 둘째 부대가 멀리 있으면 준비한 인원을 못 쓰는 위험
- 최종25인 명단을 만들었어도 모든 문에25명이 동시에 출격하는 것은 아님

이스마르는 별도 참전 확인 · 첫 문은 비행 적이 많아 활2명과 회복2명을 우선 · 신장직8종은4구간 이후 목표이므로 첫 문 준비의 선행 조건으로 만들지 않음

3부2구간에는2부대 편성 · 위 주력8명을 약한 탐색조와 섞지 않고 문 공략조로 구별 · 실제 가입 능력/기능이 부족한 자리는 이미 준비된 같은 역할의 동료로 교체

## 첫 문까지의 동선

1. 2구간 자유행동36턴 안에 기준판 영입·장비·필수 기능 준비
2. 작전이 시작되면 예고의 기한과 남은 행동 수 재확인 · 한국어 공략은 첫 작전16턴, 실제 게임 표시 우선
3. 문 주변4곳의 정화 게이지를 모두0으로 만들기 · 한 단계 제거에1턴 ·3단계 숲은3회 필요
4. 정화/방위를 나눠 맡더라도 문 공략8명은 문 근처로 집결
5. 문 진입 전에 참가 부대 번호·힐러·궁수가 실제 후보에 있는지 확인

세계지도 정화와 전투 안의 장기 제거는 다른 행동 · 전투 안에서는 타일 효과를 읽고, 이스마르의 사용 가능한 블레이즈 아츠로 제거할지 판단 · 비용/범위는 실제 선택창 확인

전투 초반은 후열을 중앙에 두고 몰려오는 비행 적부터 처리 · 전열 없이 힐러/궁수를 바깥에 노출하지 않기 · 장기 위에 금괴 보너스를 노리는 행동은 안전 확보 뒤 선택

17인 전투의 두 번째 부대8명 예시: **세오도라·올림피아·이니오니·로레타·알렉산드라·무우·그자람·단테** · 첫 원정8명과 중복 없음 · 이스마르를 더하면17명

이는 특정 문에 보낼2조의 예시 · 최종25명 전체를 고정3조로 분할한 표가 아님 · 전투가 갈라지면 각 조의 전열·활·마법·원격 회복이 따로 작동하도록 배치 · 한 조의 리브로가 다른 조를 항상 치료할 수 있다고 가정하지 않음

남은 동료와 토비아스·보나파르트·세테스 등 예비는 실제 방위/전투 역할이 있을 때만 활용 ·5부대40명 전원을 새로 완성하는 반복 육성은 필수 아님

## 현재25인의 준비 우선순위

1. 실전 원정조의 활2명·리브로2명·물리 전열·마법 공격부터 준비
2. 가호는 실제 계승 레벨을 확인 · 이미 확보한 아우로라3·포트나 되감기와 공격 가호를 상황에 맞춰 사용 · 위험한 반격을 받는 공격은 행동 전에 대비
3. 재계의 검·엔젤·이스마르의 명부 대응 등을 사용 가능한 병종/기능에 맞춰 배분 · 선더 소드의 마법 피해와 명부 무효/명마 특효는 별개
4. 현재 무기/장신구 장착 상태의 공격 속도·명중·반격 예측 확인 · 무거운 보주를 든 마법사가 안전한지 다시 확인
5. 필수 훈련/시험/새 기능이 필요한 동료만 보완 · 마지막으로 실제 이득이 있는 유료 융합 결정
