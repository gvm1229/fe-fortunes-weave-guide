# 참고 모달 가독성 · 2026-11-03

## 바뀐 표시

- 참고 문서18개와 시험 안내에 같은 읽기 스타일을 적용했다. 본문은 기존17px에서20px, 휴대폰은19px로 키웠다. 제목·항목 이름·본문·기록 정보를 크기와 여백으로 구별한다.
- 긴 인물 표와 편성 목록을 초상화가 있는 한 열 블록으로 바꿨다. 병종·운용·영입·준비, 또는1·2·3부 목표는 행으로 나눈다. 작은 화면에서는 행 이름 위·내용 아래로 쌓인다.
- 기능/병종은 기존 게임 아이콘, 명성·지원·날짜·레벨·비용은 기존 태그로 구분한다. 인물 사진은 블록 머리에58×68, 문장 첫 인물에28×33으로 제한한다.
- 문서 목차와 긴 인물 표의 루트 바로가기를 넣었다. 모든 내용은 열린 상태로 보이며 아코디언·전환 애니메이션은 없다.
- 날짜·작성 범위 같은 기록 정보는 문서 끝으로 모았다. 대상 난이도처럼 판단에 필요한 조건, 출처·예외·미확인은 유지한다.

## 지원 따라하기

공통 준비 머리의 ‘지원 따라하기’는 스크롤 연결 대신 중앙 문서 모달을 연다. 본문을 여섯 단계로 나눴고 식사 화면, 시작/정지 조건, 카이 친밀도 주의, 다음 로드 선행 식사를 함께 표시한다. 공통 준비 안의 중복 장문은 제거했다. 옛 `#support-follow` 주소도 같은 모달로 연결한다.

## 실제 확인

Windows Chrome 1440×1000에서 본문20px·줄 높이36px, 인물60판의 구분·루트 바로가기·아이콘·태그·그림을 확인했다. 390×844에서 본문19px, 인물 행의 위아래 배치, 가로 넘침 없음, 따라하기 모달과 Escape 닫기를 확인했다. 시험 안내도 본문20px와 단계 번호를 사용한다.

따라하기를 열기 전 체크18386px·공통 준비2980.666748046875px·인물8256.6669921875px를 기록했다. 문서 끝까지 이동해 닫은 뒤 세 위치·주소·선택 루트·검색이 같았고 초점은 따라하기 버튼으로 돌아왔다.

`tools/check_reference_reading.py`로 기존 문단·목록·표의2,929개 값을 대조했고, 조건·문구·외부 출처 누락과 없는 이미지0건을 확인했다. 이 숫자는 게임 사실을 새로 실험한 횟수가 아니다. 파일과 표현 구조의 보존 검사다. 글자 검사 도구 결과는 빈 목록으로, 별도 지적이 없었다.

체크ID540개는 그대로다. 작업 도중 체크 정본이 외부에서 갱신되어 시작 시점 해시와 달라졌다. 이 작업에서는 정본에 쓰지 않았고 그 갱신을 되돌리지 않았다. 체크 표시로 실제 게임 진행을 추정하지 않는다.
