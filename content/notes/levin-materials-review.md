# 세오도라 · 선더 소드 재료부터 교환까지

2026-11-05 · 재료가 없는 채 교환·강화를 시키던6장 안내를 고쳤다. 같은 날 후속 대조로 열매의 한국어 이름을 **태양 열매**로 정정했다. 영어 이름의 음역을 우선하던 이전 판단은 [명칭 확인](thry-fruit-name-review.md)이 대체한다. 실제 채집·교환·강화 완료 보고가 아니다.

## 먼저 수량을 정한다

| 새로 교환할 검 | 태양 열매 | 유나메이 | 7장 군비증강30개도 새로 준비할 때 태양 열매 합계 |
|---|---:|---:|---:|
| 1자루 | 10개 | 1개 | 40개 |
| 2자루 | 20개 | 2개 | 50개 |

이미 가진 검·재료와 납품을 마친 군비증강 몫은 뺀다. 교환 한 번의10개·1개를 두 자루 전체 재료라고 쓰지 않는다. 새 두 자루를 모두 교환한다면20개·2개이고,7장 군비증강30개와 합쳐 태양 열매50개다.

## 본문 실행 순서

1. 현재 선더 소드 보유량·실제 사용할 담당·교환 재고를 보고 새 교환 자루 수를 정한다.
2. 남은 관전·행사·메인 기한과 귀환 시간을 확인한다. 특히 아직 남은4/6 특별 시합·4/10 관전을 재료 원정 때문에 놓치지 않는다.
3. **발레리 협곡(아말테아)**에서 태양 열매10개/자루를 모은다. 두 자루를 새로 교환하면20개다.7장 군비증강용30개는 따로 나눈다.
4. **다마센 곶(카스탈리아)**에서 유나메이1개/자루를 모은다. 두 자루면2개다. 두 재료를 같은 곳에서 찾지 않는다. 실제 열린 길·역·탐색/파견 가능 여부와 소지 수량을 확인한다.
5. 제도로 귀환해 반다르 상회의 실제 선더 소드 재고·요구품·교환 가능한 수량을 확인한다.
6. 재고가 있을 때 필요한 자루만 교환하고 실제 검이 늘었는지 확인한다. 재료만 모았다고 교환 완료로 체크하지 않는다.
7. 실제 얻은 검 중 사용할 자루만 강화한다. 한 자루+1은 뇌석2개·기본500G, 두 자루면4개·1,000G다. 이미 강화한 검은 제외한다. 검C와 현재 병종의 검 사용 가능 여부도 확인한다.

각 단계는 개인화 본문에서 별도 체크로 표시한다. 발레리 협곡·다마센 곶의 실제 지도 그림과 세계지도 버튼도 해당 수집 행동에 붙였다. 이미 준비한 물품을 다시 모으지 않으며, 갈 수 없는 길이나 부족한 귀환 기한 때문에 원정이 어려우면 다음 자유행동으로 보완한다.

## 6장 확보를 확정하지 않는다

6장에서 교환소가 열린 것과 그 교환소에 선더 소드가 있는 것은 별개다. 물품 상세에는 비율만 있고 최초 장이 없으며, 다른 물품표에는8장 시작 이후라는 조건도 있다. 현재 게임의 실제 교환 목록을 우선한다.6장 본문은 재료 준비·재고 확인으로 고치고, 재고가 없으면 보관 후 뒤 장에서 다시 확인하도록 했다.

그래서 두 자루 강화비1,000G도6장의 고정 지출에서 빼고 실제 두 자루를 확보했을 때만 추가할 비용으로 나눴다. 두 자루를6장에 반드시 확보하거나 강화하라는 뜻이 아니다.

## 근거와 확인 한계

- [Game8 유나메이](https://game8.jp/fe-banshisenko/817018): 다마센 곶 등의 채집, 선더 소드1자루의 태양 열매10·유나메이1 교환을 본문에서 확인했다.
- [GameWith サンノミ](https://gamewith.jp/fefw/578035): 탐색 입수와 교환 용도를 확인했다. 프로젝트의 `assets/guide/valeri-map.jpg`는 영어 목록이며 Thry Fruit를 표시한다. 영어 목록만으로 한국어 이름을 정하던 이전 판단을 폐기하고, 사용자 게임 화면 보고와 한국어 도감을 대조해 태양 열매로 정정했다. `damasen-map.jpg`의 Yuna Mei는 별도 재료인 유나메이다.
- [Anna’s Notebook 유나메이 표](https://annasnotebook.net/ja/items/it-315/): 같은 교환 비율과8장 이후라는 입수 조건이 있어6장 재고를 단정하지 않았다. 다른 표의 세부 월 표시와 게임 내 실제 재고를 새로 재현한 것은 아니다.
- 지도 그림은 기존 [Game8 지도](https://game8.co/games/Fire-Emblem-Fortunes-Weave/archives/624208)에서 준비된 자료다. 그림의 선택 루트를 현재 사용자 기록으로 보지 않으며 실제 세오도라의 길을 확인한다. 새 핀 좌표·주소를 임의로 만들지 않았다.
- Exa 검색은 무료 이용 한도로 실패해 원문 읽기와 다른 검색 경로로 확인했다. 계정·API 키 발급이나 설치를 요청하지 않았다.

Windows·Codex에서 공개 원문·로컬 지도·정본 수량·체크 순서를 대조했다. 게임 실행,6장 선더 소드 재고, 희귀 소재의 탐색 횟수·수확량은 실측하지 않았다. 기존 체크ID·상속·완료값과 실제 진행은 보존하며 새 수집·교환 체크는 과거 완료를 자동 상속하지 않는다.
