# 행동 체크·인물 패널 확인

2026-11-03 · 로컬 Windows · 현재 프로젝트만.

## 완성한 화면

- 개인화의 가로 여백을 줄여 왼쪽 한 열 행동 체크·오른쪽 공통 준비/현재 루트 인물을 함께 표시한다. 준비·인물 전용 탭은 없앴다. 600px 이상 두 열, 더 좁은 휴대폰은 한 페이지 안에 위아래 배치다.
- 역할 → 큰 얼굴 초상화 → 이름 → 하트 지원 조건 → 반짝 명성 조건 순서다. 주전·보완·선택·수집은 구별되는 진한 바탕으로 표시했다. 자동 합류와 미확인을 구분하고, 도감의 누락 지원 조건을 보완했다.
- 93개 묶음을 440개 작은 행동으로 나눴다. 단순 설명·막타 방침·주의는 완료 과제로 강제하지 않고 메모로 남겼다. 준비물별 확인과 여행·수락·수령·복귀·보고를 나눴다. 초상화를 누르면 같은 페이지의 해당 인물로 이동한다.
- 로컬 도감62명·개인화 고유35명의 가입 병종·자격·마스터 부담을 자료상 검토했다. [세부 검토](late-recruit-review.md). 알렉산드라 천익병 유지·보관용 비탑승 자격 예외, 늦은 리네 가디언 직접, 전차병 성장 목적을 구분한다.

검사 범위는 Windows의 공략 화면·체크 파일 저장이다. 게임에서 모든 인물을 시기별로 영입하거나 모든 병종의 능력·마스터·최단 동선·노멀 경험치 배율을 실측한 것이 아니다. 실제 게임 진행·영입·레벨·자원은 바꾸지 않았다. 일시 화면 크기는 해제했고 저장 도구는 로컬127.0.0.1에서 유지한다.
