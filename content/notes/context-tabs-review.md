# 공통 준비·인물 탭 · 2026-11-04

오른쪽의 공통 준비와 인물은 상자 하나를 공유한다. 위의 두 가로 탭에서 하나를 선택하면 그 내용만 상자 전체 높이에 표시한다. 선택한 탭은 청록 배경·흰 글씨로 구별한다.

- 두 탭은 스크롤 위치를 각각 기억한다. 인물 검색·부·루트 선택 상태도 단순 탭 전환으로 초기화하지 않는다.
- 화살표 왼쪽/오른쪽과 Home/End로 탭을 전환한다. 선택한 탭만 일반 Tab 키 순서에 둔다.
- 기존 왼쪽·오른쪽 위의 표시 버튼은 해당 탭을 열거나 현재 상자를 숨긴다. 숨김 복원은 선택한 탭과 읽던 위치를 유지한다.
- 공통 준비의 초상화를 누르면 인물 탭을 열고 해당 인물로 이동한다. 지원 따라하기·시험 안내 등 모달을 닫으면 기존 탭과 읽던 위치를 유지한다.
- 루트를 바꾸면 인물 탭은 새 루트의 위쪽부터 보여준다. 지난 루트의 저장된 스크롤 위치를 덮어 적용하지 않는다.
- 실제 게임 진행·구매·인물 수치·체크 정본은 표시 변경과 별개다.

검증은 Windows Chrome 대표 화면과 HTML 구조를 대상으로 한다. 게임 조작이나 실제 영입·구매·전투 완료를 실행하지 않는다.
