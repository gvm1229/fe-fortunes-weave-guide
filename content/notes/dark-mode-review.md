# 어두운 화면 · 2026-11-05

범위는 현재 프로젝트다. Windows에서 작업했으며 전역 Hive·외부 서비스·진행 체크 JSON은 변경하지 않았다.

- 공통 `theme.js`와 `theme.css`를 224개 HTML에 연결했다. 처음에는 컴퓨터 화면 설정을 따르고, 버튼으로 고른 값은 화면 설정 전용 로컬 저장소에 보관한다. 선택값은 같은 출처의 다른 문서에도 이어진다.
- 개인화·팀 구성·참고 문서 생성 도구에 같은 연결을 넣었다. `tools/theme_support.py`를 다시 실행해도 연결이 중복되지 않는다. CSS·JS 내용이 바뀌면 연결 주소의 버전도 바뀐다.
- Windows의 실제 앱 내 브라우저에서 일반 개요·개인화·팀 구성·중앙 참고 문서의 어두운 화면을 보았다. 버튼 클릭, Enter 전환, 새로고침, 다른 페이지에서 선택 유지도 확인했다. 좁은 화면은 브라우저가 보고한 너비480px에서 확인했으며 실제 휴대폰390px 재현을 주장하지 않는다.
- Node.js에서 컴퓨터 설정 기본값, 저장값 우선, 잘못된 값, 전환·저장, 다른 창 변경, 저장 차단을 검사했다. 모두 통과했다. 이는 설정 처리 검증이며 실제 운영체제 테마를 바꾸거나 실제 브라우저 저장 권한을 차단한 실험은 아니다.
- Python에서 모든224개 HTML의 연결과 연결 도구의 중복 방지, 변경한 Python 파일의 문법을 확인했다. 글꼴 검사224개 HTML·9개 파일 오류0. 글꼴 파일 검사는 실제 모든 페이지의 화면 확인을 대신하지 않는다.
- 화면 점검 도구에서 새 공통 스타일·스크립트에 지적 사항이 없었다. 모든 문서·모달·색상 조합을 일일이 눈으로 검사하거나 모든 글자의 명암비를 측정한 결과는 아니다.
- 별도 정적 시험 서버를 사용해 진행 저장 API를 제공하지 않았다. 따라서 시험 화면의 저장 연결 안내는 예상된 상태이며 실제 공략 저장 기능의 오류로 판정하지 않았다. 게임 진행 체크는 조작하지 않았다.

사용자의 명시적인 화면 요구는 `knowledge/interface.md`에, 출처는 `knowledge/sources.md#dark-mode-20261105`에 기록했다.
