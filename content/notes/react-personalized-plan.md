# 개인화 두 화면 React 전환 · 2026-11-06

범위: 현재 프로젝트만. 외부 게시·Hive 실행 없음.

1. 현재 개인화 공략·팀 구성의 내용, 체크 식별자, 저장 API, 모달·필터 동작을 조사한다. 공략 정본·진행·구매·체크 파일을 보존한다.
2. 공식 배너의 출처와 실제 색을 확인하고, 읽기 쉬운 밝은/어두운 색 조합을 사용자에게 제안한다. 선택 전에는 내용 추출·상태 보존 등 색상과 무관한 작업을 한다.
3. 요청한 web-artifacts-builder의 React·TypeScript 작성 및 묶기 방식을 사용한다. 공식 초기화/묶기 스크립트를 보관하고 Windows에 필요한 실행 방식만 조정한다. React 화면은 개인화 공략·개인화 팀 구성 두 개다.
4. 기존 공략·도감은 원래 HTML을 유지하고 참고 보관 메뉴에서 연다. 새 앱의 메뉴·오른쪽 정보·백마법·탭·필터·읽던 위치는 브라우저 화면 설정으로 저장한다. 체크는 기존 로컬 서버와 data/checklist.json을 사용한다.
5. 햇빛/달 아이콘으로 밝은/어두운 화면을 바꾼다. 버튼의 접근 가능한 이름·현재 상태·키보드 조작을 제공한다. Pretendard와 실제 게임 그림을 유지한다.
6. Windows에서 빌드·글꼴·내용/체크 식별자 보존을 확인한다. 실제 진행 JSON에 쓰지 않는 임시 저장소로 체크·실패/재시도·새로고침·화면 이동·색상·모달·화면 크기를 검증한다.
7. 결과와 확인 한계를 기록하고, 새 사용자 선호를 notes/knowledge/에 중복 없이 기록한다.

## 완료 기준

- 두 개인화 화면이 실제 React로 실행되고 기존 내용·기능을 제공한다.
- 새로고침과 두 화면 전환 뒤 사용자가 선택한 표시 상태가 유지된다.
- 색 전환은 아이콘 버튼이며 두 색상에서 읽을 수 있다.
- 기존 참고 HTML을 앱에서 열 수 있고 React 변환 대상에 포함하지 않는다.
- 실제 진행·체크·편성·구매 정본이 변경되지 않는다.


## 완료 · 2026-11-06

두 화면·화면 설정 기억·아이콘 색 전환·기존 자료 보관과 체크 연결을 완료했다. [결과와 검증 범위](react-personalized-review.md)를 따른다. 서버 재시작은 자동 승인 검토에서 차단되어 실행하지 않았고, 기존 서버의 두 주소를 새 묶음으로 연결했다. 남은 에이전트 소유 작업은 없다.
