# 어두운 화면의 남은 색 수정 · 2026-11-06

경기병 표시의 밝은 배경과 연보라 글자가 겹치던 문제를 수정했다. 기존 공략 CSS에 고정된 밝은 색과 새 React 화면의 어두운 색이 섞인 것이 원인이었다.

## 바꾼 범위

- `tools/theme_content_css.mjs`가 가져온 CSS의 고정 색733개 선언을 어두운 화면용 공통 색에 연결한다. 병과·등급·기능·역할·준비·선물·주간 훈련·할 일·재료·팀·문서 모달이 같은 색을 따른다.
- `personalized-app/src/content-theme.css`에서 배경·글자·선택·관계·금색·경고와 기존 CSS 변수의 어두운 값을 정한다. 원래 밝은 값은 대체값으로 남겨 밝은 화면을 유지한다.
- 상태 오류 문구와 표시점도 어두운 화면에서 읽을 수 있게 바꿨다.
- 원본 그림 내부의 색·그림 주소·문구·크기·선택자·기능·실제 체크에는 수정 명령을 보내지 않았다. 참고 보관의 원본 HTML과 iframe 내부 스타일은 이번 수정 대상이 아니다.

## 확인 결과와 한계

모든 실행은 Windows의 Codex 호스트에서 했고, 브라우저는 연결된 Chrome이다. 게임 자체를 실행·조작한 검증은 아니다.

- **통과 — 색 변환 보존 검사:** `node tools/check_content_theme.mjs` 실행. CSS733개 선언의 색 연결과 원래 밝은 값 복원을 검사했다. 전체 선언의 선택자·중요도·나머지 값이 같고, 그림 주소와 크기도 유지됐다. 초기 검사에서 Windows 줄바꿈 차이가 발견되어 줄바꿈을 정규화한 뒤 통과했다. 줄바꿈을 게임 화면의 변경으로 취급하지 않는다.
- **통과 — 인물:** 전체61개 인물판을1·2·3부로 나누어 실제 브라우저의 글자와 배경을 조사했다. 각각9,005·6,429·6,476개 글자 요소에서 낮은 대비·밝게 남은 배경이 검출되지 않았다. 같은 인물의 여러 글자를 센 것이며 독립 인물이나 게임 실측 횟수로 부풀리지 않는다.
- **통과 — 진행 구간:** 세오도라·레다·디트리히·2부 보존·카이·3부의 할 일·공통 준비·재료18개 보기를 확인했다. 브라우저에서 보이는 내용의 계산 색 기준으로 지적0이었다.
- **통과 — 팀:** 편성3개·백마법·비교/근거·루트 편성의 보이는 색에서 지적0이었다. 루트 편성은 숨김 내용을 포함한882개 글자 요소의 계산 색도 검사했다. 숨긴 모든 내용을 각 화면에 직접 펼쳐 그림으로 확인했다는 뜻은 아니다.
- **통과 — 문서와 선물:** 인물 근거·병과·지원 따라하기·구매표·시험 모달, 펼친 선물 목록을 확인했다. 본문 모달의 숨김 문맥도 계산 색 검사에 포함했다. 연결 문서 전체를 하나씩 열어 본 검증은 아니며 공통 CSS 연결이 적용되는 범위를 확인했다.
- **통과 — 첨부 사례:** 경기병 배경은 밝은 흰색에서 어두운 읽기 배경으로, 등급·기능 등급 배경은 어두운 조작 배경으로 바뀌었다. 실제 화면 그림은 `screenshots/dark-mode-colors-fixed.jpg`다.
- **통과 — 밝은 화면:** 밝은 화면으로 바꾸어 병과·등급·역할·준비 배지의 기존 밝은 값을 확인하고 다시 어두운 화면으로 돌렸다. 모든 밝은 화면의 모든 상태를 사진으로 대조한 검증은 아니다.
- **통과 — 빌드·글꼴:** TypeScript와 최종 React 묶기 실행이 성공했다. `python tools/check_fonts.py`가 HTML283개와 글꼴9개를 확인해 오류0이었다.
- **내용 보존:** React 내용 JSON·전체 진행·최종 편성·부별 목표·행동·공유 상태·구매 계획의 작업 전 해시가 유지됐다. 작업 중 실제 체크 JSON과 백업의 변경을 관찰했으나 원인을 확정하지 않았다. 기존 값으로 되돌리지 않았고, 이번 색 검토에서는 체크박스·체크 저장 API를 조작하지 않았다.

계산 검사는 투명한 배경을 부모 배경에 합친 뒤 일반 글자4.5:1·큰 글자3:1을 기준으로 했다. 그림 안 글자·브라우저가 그리는 기본 선택 메뉴·모든 마우스 상태·다른 브라우저·보조기기·원본 보관 iframe의 색을 모두 검증하지는 않았다. 계산 색의 결과는 실제 그림 검토를 대신하지 않으므로 경기병 사례와 전체 화면을 함께 확인했다.

새 선호는 현재 프로젝트의 `notes/knowledge/interface.md`에 기존 색 규칙과 합쳐 기록했다. 전역 Hive나 외부 서비스에 기록하지 않았다.
