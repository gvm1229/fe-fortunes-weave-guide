# 1부 준비와2부 군행동

## 현재 실행 기준 · 2026-11-12

세오도라 → 레다 → 디트리히 재육성 → 카이 순으로 1부를 모두 끝내고 같은 순서로 2부를 직접 완료한다. 첫 세오도라 2부는 6장 완료 전 보관을 확인하고 이후 장착 자료를 등록한다. [현재 실행 기준](sequential-routes-apply-review.md), [첫 세오도라 보존](theodora-first-war-preservation.md)


**1부에서 기능·중급 자격 준비 → 2부에서 레벨 보충 → 상급 시험**

## 먼저 구별할 것

| 항목 | 의미 |
|---|---|
| 본대 | 현재 부의 완성 편성 · 미합류 구간은 시작 동료가 대체 |
| 보완 | 교대·공백 대체 또는2부 본대 예약 · 최종25명 준비를 안 한다는 뜻 아님 |
| 기준 육성 | 3부에서 먼저 채택할 성장 자료 · 전투 경험치 우선 |
| 능력·기능 보완 | 기준판과 다른 스탯·기능 준비 · 표시한 목표 완료 뒤 추가 투자 중단 |
| 실전 회복 | 그 루트에서 필요한 힐러 · 같은 비숍이어도 영입 가치 유지 |
| 보존·수집 | 탈것·물품·대화 확보 · 별도 성장 작업과 구별 |

## 1부 종료 전 · 최종25명 준비

1. 권장 영입 장 전에 요구 지원 준비 · 실제 등장·명성·의뢰 조건 충족 즉시 영입
2. Lv20 미만인 육성 대상은 안전한 막타·여관 **실전**으로Lv20까지 · 목표 기한은 인물 표 확인
3. Lv20에서 실전 레벨업을 멈추고 중급 시험 · 이미 중급 이상·Lv20 합류면 소급 시험 생략
4. 상급 시험의 필수 기능 B와 보조 조건을1부12장 주 전투 전까지 준비 · 투기장·여관 **훈련**·해당 무기 실전 활용
5. 늦게Lv27 등으로 합류한 동료의 이미 지난 레벨은 되돌릴 수 없음 · 이후 성장 병과·시험 기본치 보완
6. 1부 주전은Lv35~40·로드40 이상을 권장 목표로,예약 동료는Lv20·중급·기능부터 · 이 수치는 평준화 공식이나Lv35 보장 조건이 아님

**모든 중급직이 모든 스탯에 우월한 것은 아님** · 맡긴 능력의 성장 보정·속도/마방 손실을 보고 선택 · 중급 자격을 갖췄다고 모든 병과 마스터를 요구하지 않음

## 평준화는 항상Lv35인가

**고정Lv35 아님 · 정확한 계산식 미확인**

- 사용자 옛 디트리히판: 최고Lv46·최저Lv16에서 낮은 동료들이Lv35 도달
- 다른 플레이어: 같은2부1장에서도Lv33·Lv38 등 다른 결과 보고
- 평균을 기준으로 한다는 공략,상위 인물에 가깝게 올린다는 설명이 공존 · 전체 평균·상위 몇 명·차감·반올림 공식은 입증되지 않음
- 낮은 인물을 일부러 더 영입하면 유리하다는 근거 없음 · 계산식 조작용 영입은 제외

미리 보기가 있으면 실행 전 예정 레벨 확인 · 없다면 결과창에서 실제 수치 확인 · 옛 판의Lv35를 새 판의 보장값으로 사용하지 않음

## 2부1장 · 실행 순서

1. 이미Lv35 이상이고 기능·해금·시험100%를 갖춘 미전직자만 먼저 상급 시험
2. Lv20~34는 목표 중급,상급 합류자는 보유 상급으로 배치 · 성장용 탈것·친밀도 확인
3. 기본 군행동 **레벨 평준화** · 상승 대상이 없으면 전군 기술 훈련
4. 결과Lv35 이상·기능·시험100%를 채운 미전직자에게 상급 증서 사용 · **한 장에서 최대5명** · 이미 합격자는 생략하고 다음 후보
5. Lv35 미만이면 현재 중급으로 실전 · 다음 장까지 따라잡고 다시 시험 · 상급이 됐다고 가정하지 않음

전원 즉시 상급은 레벨·기능 외에 증서 제한도 존재 · 1부에 이미 상급이 된 인물은 새5장 예산에서 제외

## 장별 기본 선택

| 2부 | 기본 | 바꾸는 조건 |
|---|---|---|
| 1장 | 레벨 평준화 | 상승 대상이 없으면 전군 기술 훈련 |
| 2장 | 전군 기술 훈련 | 실제 출격 본대가 아직Lv35 미만이면 평준화 우선 · 준비 완료 후 필수 가호 부족만 봉사 |
| 3장 | 전군 기술 훈련 | 본대Lv35 미달이면 평준화 우선 · 임의의2기능이므로 특정 B/A 보장 없음 |
| 4장 | 레벨 평준화 | 성장할 후보가 없으면 전군 기술 훈련 · 마지막 시험·시설 준비 |
| 5~6장 | 군행동 없음 | 4장까지 준비한 전력으로 진행 · 시설을 찾아다니지 않음 |

현재 루트 부대에만 적용 · 다른 루트 인물까지 한꺼번에 레벨이 오르는 기능 아님 · 지원·가호·명성·레벨·기능 경험치는 각각 별개
