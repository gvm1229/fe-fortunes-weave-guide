# 경험치 보너스 점검을 체크로 표시

2026-11-04 · current-project. 실제 게임의 축복 설정·구매를 수행한 기록이 아니다.

## 새 항목

네 루트1부48장에 ‘권장 레벨 전후 경험치 설정’ 한 항목씩을 추가했다. 기존 장별 점검의 권장Lv5/20/35와 명성1/4/8을 사용한다. 주력이 점검선을 넘기기 전 아직 해당 시점의 목표 성장 병과를 준비하지 못했으면 추가 효과0%(OFF), 전직했거나 이미 목표 병과면 원래 쓰던 값(ON)을 확인한다. 현재 개인화 기본은+10%이며 더 높은 효과를 쓰게 되면 그 값으로 복구한다.

레벨 도달 시 확인할 행동으로 표시하며, 기본 경험치는 계속 들어온다는 주의를 남겼다. 좋은 성장률 때문에 중급직을 의도적으로 유지하는 인물을 상급직으로 강제하는 규칙이 아니다.

기존 ID1,163개와 체크 JSON은 보존했다. 새48개 행동은 inheritLegacy=false로 두어 옛 묶음 완료를 상속하지 않는다. 총ID1,259개·현재 행동932개다. 진행 파일을 바꾸지 않고 임시 HTML과 임시 JSON으로 새ID의 저장·다시 읽기를 확인했다. 실제 브라우저에서는 활성·미체크 상태를 확인했으며 완료 표시를 누르지 않았다.

## 로컬 상위 단계

- [디트리히 한눈에](../dietrich.html#한눈에): 세오도라·레다1부 뒤 축복2단계 경험치30%를 전제로 설명한다.
- [디트리히 다음으로 넘어가기 전](../dietrich.html#다음으로-넘어가기-전):1부 완료 보상 뒤 경험치50% 등 축복3단계를 구매하도록 적는다.
- [2부 한눈에](../part2.html#한눈에): 경험치50% 등을 안고 들어가는 상태를 전제로 한다.
- [출처 검토 C-202·C-460](../sources.html#s1):10→30→50%와10→20→30→40% 자료가 다르며,30%의 해금에 필요한1부 완료 수에도 차이가 있다.20%는 이 비교에서 확인한다.

따라서 상위 경험치 구매 안내는 로컬에 있다. 정확한 단계·해금·현재 가격은 이 확인만으로 확정할 수 없다. 개인화의 기존 구매 예산을 임의로 상위 단계로 바꾸지 않았다. 기존 ‘명성·성장 기준’ 모달에도 이 근거를 추가했다.

Windows Chrome 표시, 실제 저장 코드를 쓴 임시 JSON 저장,191개 참고 문서·문구9,381개·체크ID1,259개 검사를 통과했다.48장·명성13행 진행 검사도 통과했고 보호 정본8개는 불변이다. 실제 게임 설정과 상위 축복 해금·가격은 재현하지 않았다.
