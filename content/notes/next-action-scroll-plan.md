# 다음 할 일의 스크롤 범위 수정 · 2026-11-06

1. 버튼을 누르기 전후 페이지·머리글·할 일·오른쪽·메뉴 위치와 화면 선택을 비교해 재현한다.
2. 요소와 모든 부모를 움직일 수 있는 scrollIntoView 대신, 현재 할 일 상자의 scrollTop만 계산해 바꾼다. 초점 이동·해시·탭·필터·체크 변경은 추가하지 않는다.
3. 같은 브라우저에서 데스크톱·좁은 화면, 반복 클릭과 완료 숨김 상태를 확인한다. 빌드·글꼴과 내용 보존을 검증한다.

범위: 현재 프로젝트의 개인화 공략 ‘다음 할 일’ 버튼만. 실제 체크 조작·Hive·외부 게시 없음.


## 완료

할 일 상자만 직접 이동하도록 수정했다. 재현·데스크톱·반복 클릭·휴대폰/완료 숨김·빌드·글꼴 확인을 마쳤다. [결과와 한계](next-action-scroll-review.md)를 따른다. 남은 에이전트 소유 작업 없음.
