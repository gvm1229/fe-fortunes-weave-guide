# 문서 연결과 중앙 모달 · 2026-11-03

- 개인화에서 Markdown으로 직접 연결하던 9개 링크를 HTML로 바꿨다. 그 안의 후속 문서까지 16개의 UTF-8 HTML 읽기 화면을 만들었다. Markdown은 편집 정본으로 유지한다.
- `tools/render_reference_pages.py`가 기존 Markdown의 제목·목록·표·인용·출처를 HTML로 만들며, `tools/workspace_ui.py`가 화면 생성 때 실행한다. 실행 중인 공략 서버에 새 패키지나 기능을 추가하지 않았다.
- 모든 개인화 모달은 화면 50% 지점에서 자신의 가로·세로 절반만큼 이동한다. 시험 모달은 최대 높이를 제한하고 긴 내용만 안에서 스크롤한다.
- 변경된 CSS·JS는 파일 내용으로 주소의 버전을 바꾼다. 이전 화면이 같은 버전 주소에 남는 문제를 줄인다. 문서 스타일도 같은 방식이다.

## Windows에서 실제 확인

- Codex 앱 브라우저에서 지원 근거를 클릭해 `weekly-support-review.html`의 UTF-8 한글 제목·본문이 정상으로 열리는 것을 확인했다. 뒤로 가기 뒤 디트리히 루트와 기존 주소가 유지됐다.
- Chrome 1440×1000, 390×844에서 모달 중심 오차는 가로·세로 0px였다. 앱 브라우저 866×2916의 측정에서는 가로 0.334px·세로 0px로 반올림 범위다. 서로 다른 환경의 화면 크기를 하나로 가정하지 않았다.
- 휴대폰 폭에서도 모달 내용과 근거 문서의 가로 넘침이 없었고 Escape로 모달이 닫혔다. 긴 내용의 내부 스크롤을 확인했다.
- 개인화와 생성 문서에서 직접 Markdown 연결 0개, 없는 지역 문서 연결 0개다. 체크 정본 SHA256과 revision7·완료0개가 작업 전후 동일하다.
- 실제 게임의 영입·전직·지원·전투를 실행한 결과가 아니다. 검증 수치는 `reference-modal-validation.json`, 화면은 `screenshots/centered-modal.jpg`다.
