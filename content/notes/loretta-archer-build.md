# 로레타 · 명중·회피 따라하기

**최종 마스터 아치 · 난사 명중 우선**

| 맡길 판 | 목표 | 멈출 기준 |
|---|---|---|
| 세오도라 | 검 A 아지랑이 · 속도 · 보병술 C 모면 | 실제 출격 자리가 없으면 중단 · 2부 출격 때 재개 |
| 카이 | 전차병의 힘·기술·수비 · 궁술 A 난사 | 필요한 능력·기능 충족 뒤 성장 반복 중단 |
| 3부 | 마스터 아치의 활 명중+15 · 난사 | 이미 갖춘 기능·시험 반복 생략 |

## 1. 세오도라 · 검·회피 기능

1. 명성5·지원3 충족 뒤 철의 검3개로 영입
2. 현재 병과·기능부터 확인 · 이미 상위 자격이면 투사·검사 시험 소급 생략
3. 실제 출격할 때 검 A 아지랑이 준비 · **처치 뒤** 다음 자기 페이즈까지 회피+20
4. 여유가 있으면 보병술 C 모면 · **활·마법 상대만** 회피+5
5. 로그 마스터 그림자숨기는 추가 회피가 필요한 경우만 · 다음1회 전투 회피+10 · 필수 반복 과제 아님

## 2. 카이 · 전차병 물리·궁술판

1. 제도 자유행동부터 로레타 지원3 준비 · 현재 카이와 동석 식사
2. 명성7 전에 철의 검3개 확보 · 조건 충족 뒤 스카우트
3. 궁술 C·기마술 D·전차병 해금과 실제 시험창 확인 · 미보유 중급 증서만 사용
4. 본인이 돌본 탈것 탑승 · 먹이·숙박으로 친밀도5 목표 · 성장용 탈것 보정과 시험 조건 구별
5. 전차병 출격에서 안전한 활 막타 배분 · 궁술 A 난사까지 준비
6. 실전 명중이 부족하면 스나이퍼 자격 선택 · **마스터 후 사격의 달인 장착**으로 활 명중+15

**전차병은 회피 불가 · 활만 사용**

전차병은 성장 보완용 · 아지랑이·검 회피를 같은 병과에서 실행 불가 · 위험한 강제 전투는 현재 보유한 실전 자격으로 교체

## 3. 3부 · 난사 명중 준비

1. 등록된 세오도라판과 카이판의 실제 능력·기능 비교 · 다른 루트 능력 융합은 파편 가격 확인 뒤 선택
2. 3부1구간 완료 뒤 궁술 A·최상급 증서·시험 합격률100% 확인 → 마스터 아치
3. 병과 **활 명중+15** 확인 · 장착한 **사격의 달인+15**는 별도 · 병과를 바꾸면 병과 명중+15는 소실
4. 난사의 명중-50을 포함한 적별 전투 예측 확인 · 병과 보정만으로 전 타격 명중 보장 없음
5. 궁술 Lv 스킬과 필요한 명중 장비 우선 · 무게 때문에 공격 속도를 잃는지도 확인
6. 근접 반격이 필요하면 미니 보우1~2칸 · 마스터 아치에서는 검 사용 불가

피터르·이니오니·교체 후보 아스완의 마스터 아치 유지 · 로레타는 그 셋의 병과를 바꾸지 않고 추가하는 명중 중심 궁수

## 4. 회피 준비 · 전투별 선택

### 활 전투 · 마스터 아치 유지

1. Lv35 절호조+ 장착 · HP최대에서 공격+3·회피+10
2. 개인 스킬은 HP절반 이상에서 회피+10 · HP최대일 때 두 효과를 함께 활용
3. 보유·장착한 모면은 활·마법 상대만 적용 · 저격 회피+는 보병술 S·적과3칸 이상일 때만 추가 후보
4. 부상하면 공격 전에 회복 · 회피가 충분한지 적별 예측 확인 · 회피 스킬을 갖췄다는 이유로 포위 진입 금지

### 검 회피가 필요한 전투 · 보유한 검 병과로 교체

1. 이미 가진 소드 마스터·섀도 시커 등 **검 사용 가능 자격** 선택 · 이 운용만을 위한 추가 최상급 시험은 필요할 때만
2. HP최대로 개인 스킬+10·절호조+10 유지
3. 아지랑이로 적을 처치한 **뒤** 회피+20 활성화 · 그 공격의 첫 반격에는 미적용
4. 질풍의 검의 기본 회피+10은 **실제 장착 중일 때만** 합산 · 활로 바꾸면 검의 회피 보정 제외
5. 위 조건의 회피 보정 합계50은 최종 회피 수치가 아닌 추가 보정 · 적 명중0 보장 없음

아지랑이와 난사는 각각 한 행동 · 검·활을 모두 쓸 수 있는 병과인 전투에서 같은 턴에 둘 다 쓰려면 재행동 필요 · 전차병의 회피 불가와 구별
