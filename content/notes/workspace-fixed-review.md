이 검증은 Windows의 공략 화면·연결·저장 이력 보존 범위다. 모든 게임 버전1.1.0 영입·지원 루프·성장 최적값·부별 전직 가능성을 직접 재현한 검사가 아니다. 자료와 사용자 가정이 다른 최상급 해금은 [부별 근거](phase-goals-review.md)로 구분했다. RPG Site 원본 그림 주소는403이었지만 같은 원문의 article 그림을 받아 세 명 식사 예를 직접 확인했다. 외부 업로드·Hive 사용·게임 저장 변경은 하지 않았다.

도구 접근 보완: 이전 검토 탭 핸들이 만료돼 새 검토 탭으로 연결했다. 검색 입력은 일반 textbox가 아닌 search 입력이어서 해당 입력으로 다시 접근해 필터를 검증했다. 서비스·저장 파일의 실패로 세지 않으며 실제 UI 검증은 새 탭을 기준으로 한다.
