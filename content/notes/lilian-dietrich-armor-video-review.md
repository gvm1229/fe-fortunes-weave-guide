# 릴리안 디트리히 중갑판·지정 영상 종합 검토 · 2026-11-07

범위: 조사·비교 제안만 · 공략/편성/체크 정본 미수정 · 실제 게임 실험 미실행

## 결론

디트리히 중갑판은 목적이 분명한 두 번째 육성판 후보 · 세오도라 궁수판의 속도·기술·궁술과 디트리히판의 수비·힘을 합치는 구조는 타당 · 다만 현재 본대 정원과 늦은 명성8 영입을 고려하면 기본 필수보다 조건부 추천

지원2 충족은 사용자 확인값 · 식사 반복 비용은 사라졌지만 창/도끼·중갑 기능 훈련,중갑에서 레벨을 올릴 기회,영입금5,000G·시험·융합300파편은 별도

## 숫자로 보는 이득

다른 스킬·탈것·장비 보정 제외 · 본체 성장률+병과 성장률의 단순 비교

| 병과 | 수비 성장 | 힘 성장 | 속도 성장 | 기술 성장 |
| --- | --- | --- | --- | --- |
| 아처 |35% |35% |50% |70% |
| 중갑 보병 |55% |45% |35% |60% |
| 스나이퍼 |35% |40% |50% |75% |
| 헤비 아머 |60% |50% |30% |60% |

- 스나이퍼 대비 헤비 아머:10회 레벨업에서 수비 상승 기댓값+2.5,20회에서+5 · 확정 상승량 아님
- 실제 융합 이득은 max(중갑판 기본 수비−궁수판 기본 수비,0) · 두 판 수비를 합산하지 않음
- 예시: 궁수판 수비22·중갑판28이면 융합 수비28,증가6 · 중갑판20이면 수비 증가0 · 설명용 수치이며 사용자 실측 아님
- 늦은 영입의 출발 수비·남은 레벨업 횟수·초기 병과가 다르므로 위 성장률 차이를 그대로 최종 이득이라고 계산하지 않음
- 헤비 아머 장착 중 수비+9는 병과의 임시 보정 · 기본 수비와 분리해 비교 · 중갑판의 속도 손해는 궁수판의 높은 기본 속도를 합칠 때 보완 가능
- 합격 시 최저 보장과 성장 보정은 별개 · 시험만 합격하면 수비 성장60%가 과거 레벨에 소급되지 않음 · 중갑을 마스터해야만 최저 보장이나 성장 보정을 얻는 것도 아님

## 영입 시기·훈련

1. 디트리히의 명성8부터 검토 · 지원 요구는 이미 충족 · 명성 도달 장을 고정하지 않고 실제 교섭창 확인
2. 5,000G·등장·실제 영입 조건 확인 · 합류창의 레벨·기능·자격·기본 수비를 먼저 비교
3. 중갑 보병은 중갑 E+와 창 C/도끼 C 중 하나 · 헤비 아머는 중갑 D와 창 B/도끼 B 중 하나 · 권장Lv20/35·명성4/8·해당 증서·합격률 함께 확인
4. 릴리안은 궁술·보병 특기 · 창·중갑은 보통,도끼/격투 등의 특기와 혼동하지 않음 · 둘 중 현재 더 높은 무기 기능을 택해 새 훈련량 줄이기
5. 이미 상급으로 합류했고 헤비 아머 시험 조건을 갖췄다면 초급/중급 시험 역주행 생략 · 수비10 최저 보장만 얻으려 하급 마스터 반복 금지
6. 중갑 보병·헤비 아머는 활 사용 불가 · 이 판은 궁수 출격이 아니라 창/도끼 물리 전열 육성 · 기존 활 기술/명중 스킬이 그대로 전투를 해결한다고 가정하지 않음
7. 1부 늦은 영입만 하고2부 스킵 등록만으로 끝내면 중갑 성장 횟수 부족 가능 · 직접2부 육성/여관/군행동을 늘리는 시간이 실제 비용
8. 레벨 평준화는 고정Lv35 보장으로 계산하지 않음 · 실행 전 목표 성장 병과 설정,화면의 상승 예정치와 실제 기능 조건 우선

중갑 시험 기본 예산은 미보유 자격만:중급500G·상급3,000G · 지급 증서 활용 시 구매 감소 · 훈련비 별도 ·3부 유료 추가판 융합300파편 · 같은 루트 무료 재등록과 구별

## 출격 정원·누구 대신 키우는가

현재 디트리히1부 본대9명:디트리히·에스메랄다·파비오·미카엘라·우술라·리네·알렉산드라·게이츠·소피아

- 위 명단이 완성된 뒤 릴리안을 더하면1부10명/9칸,2부14명/13칸 · 영입했다고 추가 출격 칸이 생기지 않음

- 루트 전용 게이츠를 추가 보완판 때문에 무조건 배제하지 않음
- 교대 후보는 디트리히판 도끼·격투 기능 목표를 이미 마친 미카엘라 등 역할 준비가 끝난 인물 · 미카엘라의 필수 기능이 미완이면 교대 보류 · 실제 전투의 필요한 화력/회복 우선
- 출격시키지 않고 유료 훈련만 반복해도 전투 레벨업의 수비 성장 횟수는 생기지 않음 · 기능 준비와 능력 성장을 구별

추천 판단: 명성8에서 영입창 비교 → 세오도라판보다 수비가 실제 높거나,남은 직접 플레이에서10~20회 중갑 레벨업을 무리 없이 확보할 때 선택 · 이 횟수는 투자 규모를 가늠하는 예시,필수 할당량/성능 보장 기준 아님 · 준비된 본대 한 명을 교대할 수 없으면 보류

## 영상 전체 요약

### 1. 목적과 우선순위

모든1부 동료를 적어도 한 루트에 배치해 영입하고 사용해보기 · 최강25명 만들기나 능력 융합 최적화 영상과 구별

우선순위:전원 영입 → 네 루트로 분산 → 요구 지원이 낮은 루트 → 빠른 합류 → 지원 대화 관계를 동점 판단에 사용

명성은 전투/의뢰/장 진행으로 쌓이는 공동 수치,지원은 상대별 식사·선물 준비가 필요하므로 지원 부담을 더 중시 · 무한 식사 재시작은 전원 영입을 가능하게 해도 재미·출격 정원을 해결하지 못한다는 설명

단,주요 영입 재료 조달·병과별 전투 균형·개인 적성·루트 특수 육성은 대부분 계산에서 제외했다고 제작자가 명시 · 하르빈의 카이 대추야자 어려움만 큰 예외
