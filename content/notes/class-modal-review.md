# 병과 상세 모달

2026-11-04 · current-project. 실제 게임의 전직·숙련 달성·스킬 사용을 실행한 기록이 아니다.

## 표시와 자료

- 개인화의 병과 이름을 기존 크기의 버튼으로 바꾸고 공용 중앙 참고 모달에 연결했다. 기본 문장용 병과 태그와 가입 후 목표 모두 같은 연결을 사용한다.
- 모달 제목은 해당 병과의 실제 그림38×38px와 병과 이름이다. 그림은 장식용으로 읽기에서 제외하고 이름은 제목으로 한 번 읽는다. 다른 참고 문서를 열면 병과 그림과 전용 제목 모양은 사라진다.
- 기존 병과 그림27×32px·이름14px와 아래 무기/특성 아이콘 줄을 유지한다.
- 58개 문서를 data/class-details.json에서 만든다. 편집 자료와 화면은 분리하며 Markdown을 직접 브라우저에 연결하지 않는다.
- 시험 조건은 로컬 classes.html·기존 manifest의 권장 레벨, 명성, 필수 기능, 선택 기능, 증표, 별도 해금을 구별한다. 조건의 기능은 실제 아이콘·등급, 명성은 기존 회색 태그를 쓴다. 권장 레벨을 응시 하한으로 바꾸지 않는다.
- 신장직은 시험 증표 대신 전용 아이템과 한 병종 한 명 조건을 표시한다. 이미 공유된 해금의 반복 의뢰는 요구하지 않는다.

## 스킬과 보상

[Game8 병과 목록](https://game8.co/games/Fire-Emblem-Fortunes-Weave/archives/620256)에서58개 상세 페이지의 Class Ability·Master Ability와 효과를 브라우저로 직접 읽었다. 문서마다 해당 원문으로 연결한다. 효과는 짧은 한국어, 이름은 확인된 로컬 이름을 사용하며 한글 이름을 모르는 보상은 원문 이름을 유지한다.

초급직 중 전용 스킬이 없는 병과의 마스터 보상을 병과 스킬에 중복 표시하지 않는다. 전투 기술이라고 로컬에서 확인된 보상과 일반 보상을 구별한다. 피해·확률·지속 시간·조건을 새로 추정하지 않았다.

- 드래곤 마스터 전투 기술 장비: 로컬+1 / Game8+2.
- 배틀 마스터 전투 기술 장비: 로컬+2 / Game8+3.
- 위 두 항목은 로컬 수치와 자료 차이를 스킬 표 옆에 남겼다. 실제 게임에서 어느 값인지 재현하지 못했다.
- 칼라드리오스 기마술 D/B에 대한 기존 로컬 주의도 조건 옆에 보존했다.
