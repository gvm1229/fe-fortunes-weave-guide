# 디트리히 현재 부대 상세

마지막 갱신: 2026-11-03 (한국 시간)
근거: 사용자가 26개 확인 질문에 직접 답한 현재 상태. 외부 공략의 추천 수치가 아니다.
범위: 현재 프로젝트만. 전역 지식 저장소·Hive 사용 금지.

## 수치의 뜻

- 현재 지점은 하드·캐주얼, 2부 1장 첫 전투 전이다. 준비에 약 10분을 썼다.
- 첫 군행동에서 레벨 올리기를 이미 사용했다. 35 미만이던 유닛은 모두 35가 됐다. 같은 장의 군행동을 다시 쓸 수 있다고 안내하지 않는다.
- 2부에서 받은 상급 전직 증서 5장을 이미 사용했다. 대상은 무우·미카엘라·하르빈·단테·소피아다.
- 디트리히·에스메랄다·파비오는 1부 11장에 지금 병종으로 전직했다. 다른 현재 전직에는 2부에서 한 준비가 포함된다. 지금의 부대를 1부 12장 종료 자료와 동일하게 기록하지 않는다.
- 아래 능력치는 **모든 장비를 해제한 화면 수치**다. 스킬 보정은 포함한다. 병종 보정을 뺀 개인 기본 능력치로 바꾸어 해석하지 않는다.
- HP·실제 장비 상태의 공격 속도는 아래 네 명에 대해 추가 확인했다. 그 밖의 HP·공격 속도와 현재 전투 기술은 미확인이다.
- 장비·마법·스킬 이름은 사용자의 한국어 화면 표기를 우선한다. 아래 목록은 소지·교체용을 포함하며 모든 항목이 동시에 장착된 것이 아니다.
- 파비오는 엽독의 보주만 장착 중이다. 같은 종류인 마독의 뼈 사슬은 동시 장착할 수 없고 상황에 따라 교체하려고 소지한다. 두 무게를 더하지 않는다.

- 주로 쓰는 12명과 예비 12명으로 현재 확인 명단은 24명이다. 예비의 정확한 레벨·병종·장비·기능은 대부분 미확인이다. 군행동 적용 후 레벨 하한은 35다.

## 사용자 전투 경험

- 디트리히·에스메랄다·리네 외에는 반격이나 적 공격에 크게 다치는 경험이 잦다.
- 비주력은 명중·화력도 부족해 여러 명이 나눠 처치하는데, 먼저 공격하는 동료가 반격으로 빈사 또는 전투 불능이 되는 일이 많았다.
- 과거 사례: 검사 시로코 34레벨이 27레벨 적(HP 40)에게 선공했으나 절반 정도만 깎고 자신은 HP 2가 남았다. 당시 적 병종·무기·공격 속도·공격 횟수·필살·시로코 장비는 미확인이다. 현재 바테스 시로코 수치로 이 과거 전투를 재현하지 않는다.
- 오르헬 외전과 마스 전투가 특히 어려웠다.
- 미카엘라가 반드시 궁수여야 한다거나, 시로코가 반드시 물리 공격수여야 한다는 전제로 운용을 짜지 않는다.
- 가호는 대비해서 해금·설정해 뒀으나 **평소에는 쓰지 않는다**. 명부의 가호가 있는 적은 재계의 검·엔젤, 또는 디트리히·에스메랄다의 화력으로 처리해 왔다. 가호를 자주 써 온 상태로 가정하지 않는다.

## 사용자 선호

- 본 진행은 하드를 유지한다. 도전은 좋아하고 불합리하게 느껴지는 상황을 줄이려 한다. 이후 새 발화에서 디트리히 재진행의 빠른 완료용 노멀은 경험치 손해가 없다는 조건 아래 검토한다고 밝혔다. 아직 난이도를 변경하지 않았다.
- 네 주인공의 이야기를 모두 본다. 처음 보는 1부·컷신은 건너뛰지 않는다.
- 2부는 겹치는 부분을 생략하고 싶지만, 육성 이득이 충분하면 네 번 직접 해도 괜찮다.
- 전투에 쓰고 싶은 동료: 리네·우술라·알렉산드라·단테. 여성 캐릭터 중심을 선호하나, 전투에 더 유리한 대안이 있으면 추천받는다.
- 나머지 동료는 대화만 봐도 만족하지만, 수집도 어느 정도 챙기고 싶어 불가피하지 않다면 놓치고 싶지 않다. 게이츠를 꼭 원하는지는 별도 답변 없음.
- 길 찾기·영입 준비·주간 활동에 시간을 많이 썼고, 처음 보는 이야기 감상도 큰 비중을 차지했다. 자동 전투는 사용하지 않는다. 전투 연출은 아군만 켠다.
- 짧은 훈련·장 재진행·능력치 작업도 필요하다면 허용한다. 이것을 모두 의무 작업으로 만들지 않는다.
