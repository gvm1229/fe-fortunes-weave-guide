# 개인화 공략 열기

1. 이 폴더의 **공략 열기.cmd**를 더블클릭한다. Python 3가 필요하며 현재 컴퓨터에서 실행을 확인했다.
2. 열린 화면에서 현재 단계를 고른다. 인물 초상화를 누르면 선물·병종 정보로 이동한다.
3. 일을 마쳤으면 체크한다. ‘JSON 저장 완료’가 뜨면 `data/checklist.json`에 기록된 것이다.
4. 다른 브라우저에서도 [같은 공략 주소](http://127.0.0.1:8766/personalized.html)를 열면 같은 상태를 읽는다. 열린 다른 창에는 약 3초 안에 반영되고, 새로고침하면 바로 다시 읽는다.

서버가 꺼져 있으면 실행 파일을 다시 연다. 파일을 직접 여는 방식으로는 자동 JSON 저장이 되지 않는다. React나 별도 패키지 설치는 필요 없다. 같은 컴퓨터 안에서 쓰는 방식이며 다른 기기로 자동 공유하지는 않는다.

저장 중에는 창을 닫지 않는다. 실패 문구가 보이면 ‘저장 다시 시도’를 누른다. 저장 파일이 손상되면 원본을 지우지 않고 오류를 표시한다. 마지막 온전한 이전 기록은 `data/checklist.backup.json`이다.

체크는 이 공략의 개인 메모다. 게임 저장 파일을 읽거나 게임의 진행을 바꾸는 기능은 없다. 개인 기록은 이 폴더 안에만 저장한다.

## 플레이 중 사용

- 위에서 루트를 고르면 왼쪽 행동과 오른쪽 인물이 함께 바뀐다. 공통 준비는 계속 남는다.
- 행동 하나를 마칠 때마다 체크한다. ‘다음 할 일로’는 현재 루트의 첫 미완료 행동으로 이동한다.
- 목록의 얼굴 초상화를 누르면 오른쪽에서 그 인물을 바로 볼 수 있다. 심장 모양은 요구 지원, 반짝 모양은 요구 명성이다.
- 기존 묶음 완료는 같은 행동에만 이어받는다. 새로 보완한 행동은 직접 확인하며, 한 행동을 해제한 상태는 새로고침 뒤에도 유지한다.
- 큰 화면과 앱 패널(600px 이상)은 두 열이다. 더 좁은 휴대폰에서는 공통 준비·인물·행동이 한 페이지에 위아래로 놓인다.

## 고정된 영역으로 읽기

- 스크롤은 체크·준비·인물 상자 안에서 한다. 각 머리의 ‘맨 위로·맨 아래로’는 그 상자만 움직인다.
- 위의 ‘메뉴·공통 준비·인물’ 버튼으로 필요한 영역만 남긴다. 휴대폰은 체크 우선이며 준비 또는 인물 한 개를 함께 볼 수 있다.
- 인물 검색에 이름을 입력하면 그 인물만 남는다. 1·2·3부 버튼은 목표를 바꾸며 ‘기준 루트’는 비교할 판을 고른다.
- 시험 안내는 별도 창으로 뜬다. 닫기나 Escape로 닫아도 인물을 읽던 위치는 유지된다.
- 공통 준비의 주간 조 얼굴은 해당 인물 표로 연결된다. 다음 로드 선행 조를 누르면 인물 쪽 기준 루트만 바뀌고 왼쪽 공략은 유지된다.
- ‘지원 따라하기’는 공통 준비 안의 짧은 절차로 이동한다. 요구 지원이 이미 충분하면 반복하지 않는다.
